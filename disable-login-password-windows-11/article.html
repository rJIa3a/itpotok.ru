Чтобы Windows 11 при включении компьютера открывала рабочий стол без ввода пароля и PIN-кода, настройте автоматический вход через netplwiz или Microsoft Sysinternals Autologon. Пароль учётной записи при этом сохраняется. Запрос после выхода из сна отключается отдельно в параметрах входа; удалять PIN для автоматического входа не нужно.

Автоматический вход открывает вашу учётную запись любому, кто включит компьютер. Станут доступны файлы и приложения, а также уже открытые сеансы почты и других сервисов. Для ноутбука, общего или рабочего ПК разумнее оставить Windows Hello: отпечаток пальца или распознавание лица позволяют входить без набора пароля, сохраняя проверку пользователя.

Что проверить перед настройкой

Откройте Параметры → Учётные записи → Ваши данные и определите, используете ли вы локальную запись или аккаунт Microsoft. Для автоматического входа понадобится текущий пароль именно этой записи. PIN-код Windows Hello его не заменяет, даже если вы давно входите только по PIN.

Для локальной записи используется её имя на компьютере, для личного аккаунта Microsoft — данные этого аккаунта. Если у аккаунта Microsoft удалён пароль и настроен вход без пароля, вводить PIN в поле пароля Autologon нельзя. Не рассчитывайте на эти инструкции как на способ автоматического входа в такую запись.

Убедитесь, что знаете действующий пароль, и сохраните работу перед перезагрузкой. Настройка требует прав администратора. На компьютере организации доступность входа может определяться политиками: не отключайте рабочую запись и не обходите ограничения реестром.

Отключить запрос при включении через netplwiz

Начните с этого способа, если в окне управления пользователями доступен флажок «Требовать ввод имени пользователя и пароля». Настройте один способ автоматического входа и проверьте его, прежде чем пробовать другой.

  1. Нажмите Win + R, введите netplwiz и нажмите Enter. Другой вариант команды для того же окна — control userpasswords2.
  2. На вкладке «Пользователи» выберите учётную запись, которая должна открываться автоматически. Особенно внимательно проверьте выбор, если на ПК несколько пользователей.
  3. Снимите флажок «Требовать ввод имени пользователя и пароля» и нажмите «Применить».
  4. В окне автоматического входа проверьте имя пользователя. Для аккаунта Microsoft укажите полный адрес электронной почты аккаунта. Введите его текущий пароль в оба поля пароля. Для локальной записи используйте её имя и локальный пароль.
  5. Подтвердите изменения кнопкой ОК, закройте окно и перезагрузите компьютер.

Ожидаемый результат — открытие рабочего стола выбранного пользователя без ручного ввода. После проверки перезагрузки отдельно проверьте обычное выключение и включение: это тот сценарий, ради которого вы меняете настройку. Если появилась ошибка имени или пароля, войдите обычным способом и исправьте сохранённые данные по разделу ниже.

Если флажка нет

Откройте Параметры → Учётные записи → Варианты входа (в некоторых версиях — «Параметры входа»). В дополнительных параметрах найдите переключатель «Для повышения безопасности разрешите вход Windows Hello для учётных записей Майкрософт на этом устройстве». Если он включён и доступен, выключите его, закройте и заново откройте netplwiz.

Этот переключатель разрешает использование пароля на устройстве; он не удаляет PIN и сам по себе не включает автоматический вход. Microsoft предупреждает, что состав параметров зависит от конфигурации устройства. Если переключателя нет, он недоступен или флажок не появился, не меняйте наугад параметры PasswordLess в реестре. Для личного компьютера с известным паролем рассмотрите Autologon; на управляемом ПК обратитесь к администратору.

Связь отсутствующего флажка с обязательным Windows Hello разобрана в ответе сообщества Microsoft. Это рекомендация для конкретного случая, а не гарантия одинакового поведения всех сборок Windows 11.

Настроить автоматический вход через Sysinternals Autologon

Autologon — утилита Microsoft для настройки встроенного механизма автоматического входа. В отличие от ручного создания DefaultPassword в реестре, она сохраняет пароль как секрет LSA. Это не делает пароль недоступным: пользователь с правами администратора может извлечь и расшифровать его. Такая настройка подходит только при осознанном отказе от проверки пользователя при запуске.

  1. Откройте официальную страницу Autologon на Microsoft Learn, скачайте архив по ссылке Download Autologon и распакуйте его.
  2. Запустите подходящий для вашей системы исполняемый файл Autologon, подтвердите запрос администратора и ознакомьтесь с лицензионными условиями.
  3. Проверьте Username — имя пользователя, Domain — компьютер или домен, и введите текущий пароль в Password. Для локальной записи имя компьютера служит областью учётной записи. Не заменяйте его придуманным доменом.
  4. Нажмите Enable, затем сохраните работу и перезагрузите ПК.

В интерфейсе утилиты названия полей английские. Не ищите переведённую стороннюю сборку. Для аккаунта Microsoft внимательно проверьте, какую запись утилита определила: её страница не описывает отдельную универсальную схему заполнения полей для всех вариантов Microsoft-аккаунтов. При неудаче используйте netplwiz с полным адресом аккаунта либо сохраните обычный вход.

Autologon не проверяет правильность введённых данных и право пользователя входить на этот компьютер. Нажатие Enable ещё не доказывает, что вход сработает: проверкой служит следующий запуск Windows. Не передавайте пароль в командной строке — он может остаться в истории команд или журнале запуска.

Для отмены откройте Autologon с правами администратора и нажмите Disable. Если нужно один раз пропустить автоматический вход, удерживайте Shift перед тем, как Windows выполнит вход. Это временный пропуск, а не постоянное выключение настройки.

Убрать запрос после выхода из сна

  1. Откройте Параметры → Учётные записи → Варианты входа.
  2. В дополнительных параметрах найдите список «В случае вашего отсутствия через какое время Windows должна потребовать выполнить повторный вход?». Формулировка может немного отличаться.
  3. Выберите «Никогда», если этот вариант доступен.
  4. Переведите компьютер в сон через меню питания «Пуск», разбудите его и проверьте, что вернулись к рабочему столу без ввода пароля или PIN.

Теперь оставленный спящий компьютер сможет открыть другой человек. Для возврата защиты выберите требование входа при выходе из сна либо прежний интервал. Настройка сна не заменяет автоматический вход после перезагрузки и не отменяет ручную блокировку Win + L.

Если список отсутствует, недоступен или не предлагает «Никогда», доступность может зависеть от Windows Hello, конфигурации устройства и политик безопасности. Справка Microsoft отдельно указывает, что политика может блокировать этот список. Не отключайте защитные политики организации ради появления пункта.

Нужно ли удалять пароль или PIN

Для автоматического входа удалять пароль не требуется: система использует его без вашего участия. Удаление PIN тоже не решает эту задачу. Если убрать PIN и оставить обычный вход, Windows может запросить пароль учётной записи. При необходимости пароль можно поставить или изменить по отдельной инструкции для Windows 11.

Удаление пароля локальной записи — более широкое изменение защиты, чем пропуск запроса при запуске. Оно не удаляет отдельно настроенные способы Windows Hello, может быть запрещено политикой и влияет на сценарии, где нужен пароль, в том числе сетевой доступ. Поэтому для задачи «сразу открыть рабочий стол» здесь используется настройка автоматического входа.

У личного аккаунта Microsoft пароль связан с онлайн-аккаунтом. Не пытайтесь удалить его пустыми полями по инструкции для локальной записи. Режим Microsoft «без пароля» использует другие способы подтверждения личности; он не означает, что любой человек сможет включить ПК и войти без проверки.

Если автоматический вход не работает

  • После запуска сразу появляется «Неправильное имя пользователя или пароль». Выберите свою обычную запись и войдите известным паролем или PIN. Отключите автоматический вход и настройте его заново, проверив имя, раскладку, Caps Lock и именно пароль вместо PIN. Если пароль недавно изменился, сохранённые данные нужно обновить.
  • На экране два похожих пользователя. Не удаляйте профиль: причиной может быть ошибочное имя в настройках автоматического входа. Сначала отмените настройку и перезагрузитесь; удаление пользователя рискует затронуть его данные.
  • После перезагрузки вход свободный, после сна всё ещё нужен PIN. Проверьте отдельную настройку повторного входа после сна.
  • На рабочем ПК настройка игнорируется. Автоматическому входу могут мешать политики, в том числе баннер входа и ограничения пароля Exchange ActiveSync. Для доменных и Microsoft Entra-устройств возможны дополнительные сетевые условия; настройку должен определять администратор.
  • До загрузки Windows требуется PIN BitLocker или пароль прошивки. Эти запросы относятся к другому уровню защиты. netplwiz и Autologon их не отключают.

Ручной способ через Winlogon\DefaultPassword здесь не используется: по документации Microsoft, он хранит пароль в реестре открытым текстом. Для той же задачи доступна утилита с хранением секрета LSA, хотя и она не защищает сохранённый пароль от администратора.

Как вернуть запрос при включении

Если использовали netplwiz, откройте его, включите «Требовать ввод имени пользователя и пароля» и примените изменения. Если использовали Autologon, нажмите в нём Disable. Затем перезагрузите компьютер и убедитесь, что Windows просит подтвердить вход. Не проверяйте отмену только блокировкой Win + L: блокировка могла требовать подтверждение и при включённом автоматическом входе.

Если ранее выключали разрешение входа только через Windows Hello, после отмены автоматического входа можете вернуть переключатель в прежнее положение. Требование повторного входа после сна также возвращается отдельно. Не отключайте шифрование диска или UAC: для возврата обычного входа это не нужно.
