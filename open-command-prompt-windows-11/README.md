Два собственных русских кадра получены в предварительной Windows 26300.9457: меню файла cmd и кнопка Диспетчера задач. Не сняты поиск cmd, Выполнить, выбор профиля Terminal и результат обычного/повышенного запуска. Это сохраняющиеся ограничения иллюстраций, перечисленные в illustrations.md. Computer Use запрещает автоматизировать терминальные приложения и окно Выполнить; обход не применялся. CLI-проверки ver, COMSPEC и среднего уровня прав выполнены отдельно; они не заменяют тест интерфейса. Документация и границы — factcheck.md.
