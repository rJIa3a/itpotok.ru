## План и недостающие кадры

1. Поиск cmd: результат «Командная строка» с обычным запуском и пунктом от администратора. Нужен русский кадр выпущенной Windows 11. Доступная автоматизация не предоставляет отдельное целевое окно Start/Search; попытка выбрать поле из снимка Проводника отклонена как другое окно. Обход не применялся.
2. «Выполнить»: введён только cmd. Не снят: Computer Use прямо запрещает использовать окно Выполнить.
3. Terminal: меню профилей с «Командная строка» и отдельный результат cmd с видимым признаком повышенных прав. Не сняты: Computer Use запрещает автоматизацию терминальных приложений. Макет не подставлялся.
4. Диспетчер задач: верхняя кнопка снята; заполненная форма и результат запуска не проверены.
5. cmd.exe: меню запуска снято; успешный запуск не проверен.

Поиск внешних русских кадров не дал источника с подтверждённым правом повторного использования для нужных шагов. Снимки конкурента не загружались и не включались в Git. Недостающие кадры остаются ограничением готовности; опубликованная статья не названа полностью иллюстрированной.
