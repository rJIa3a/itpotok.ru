Чтобы удалить приложение в Windows 11, откройте Параметры → Приложения → Установленные приложения, найдите его и выберите ⋯ → Удалить. Для настольных программ есть и другой путь — «Программы и компоненты» в Панели управления. Удаление ярлыка с рабочего стола или открепление значка в «Пуске» оставляет само приложение установленным.

Что проверить перед удалением

Сохраните открытые документы и закройте программу. Если в ней есть локальные заметки, проекты, игровые сохранения или другие важные данные, сделайте резервную копию либо экспорт средствами приложения. Удаление может затронуть его данные; повторная установка не гарантирует их возврат. Например, Microsoft предупреждает, что удаление «Записок» без предварительного входа в аккаунт удаляет локальные заметки. Подробнее — в справке о записках.

Если хотите только исправить сбой, сначала рассмотрите восстановление программы: это отдельная операция, которая может помочь без удаления. Варианты описаны ниже в разделе об ошибках.

Удалить через «Установленные приложения»

  1. Нажмите Win + I или откройте «Параметры» из меню «Пуск».
  2. Выберите Приложения → Установленные приложения.
  3. Введите название в поле поиска. Если нужной записи нет, очистите поиск и проверьте фильтр дисков.
  4. Нажмите кнопку с тремя точками справа от нужной записи и выберите Удалить.
  5. Подтвердите действие, если Windows запросит подтверждение. Если появился мастер удаления программы, выполните его шаги до сообщения о завершении.

Не закрывайте мастер сразу после запуска. Для некоторых программ он предлагает сохранить настройки, удалить дополнительные компоненты или перезагрузить компьютер. Прочитайте, какие данные будут удалены, прежде чем соглашаться.

Удалить из меню «Пуск»

  1. Откройте «Пуск» и найдите приложение в списке всех приложений.
  2. Щёлкните его правой кнопкой мыши и выберите Удалить.
  3. Подтвердите удаление или, если открылись «Программы и компоненты», выберите программу в этом списке и запустите её удаление.

Команда «Открепить от начального экрана» убирает закреплённый значок. Для удаления установленной программы нужна именно команда «Удалить».

Удалить настольную программу через Панель управления

Этот способ пригодится для программ с собственным мастером установки. Если нужного приложения здесь нет, вернитесь к «Установленным приложениям»: оба списка не обязаны совпадать.

  1. Введите Панель управления в поиске на панели задач и откройте найденное приложение.
  2. При просмотре по категориям выберите Программы → Программы и компоненты. При просмотре значками откройте «Программы и компоненты» напрямую.
  3. Выберите нужную программу и нажмите Удалить или Удалить/Изменить. Можно также открыть её контекстное меню.
  4. Выполните инструкции мастера. Если запрошены права администратора, на рабочем или учебном компьютере обратитесь к ответственному за устройство.

Пути через «Пуск», Параметры и Панель управления описаны в инструкции Microsoft. Настольная программа при разных способах запуска может открывать один и тот же деинсталлятор.

Когда нужен собственный деинсталлятор

Если разработчик предусматривает отдельный пункт удаления в папке программы в «Пуске» или специальную утилиту, используйте его инструкцию. Название файла и расположение зависят от продукта: случайный файл с именем uninstall.exe из интернета не подходит.

Порядок такой: закройте программу, найдите официальную справку по её удалению, запустите указанное средство и завершите мастер. Не удаляйте папку установленной программы вместо этого: запись в списке и отдельные компоненты могут остаться. Если деинсталлятор отсутствует или повреждён, дальнейшие действия нужно выбирать по инструкции разработчика.

Например, для установленного Firefox Mozilla указывает собственный файл helper.exe. Если обычное удаление не открыло мастер:

  1. Закройте Firefox.
  2. В Проводнике откройте папку C:\Program Files\Mozilla Firefox\uninstall. Для установки в 32-разрядную папку путь может начинаться с C:\Program Files (x86).
  3. Откройте helper.exe, затем в мастере выберите «Далее», «Удалить» и «Готово».

Это пример только для Firefox из установщика. Сверьте расположение со своей установкой и инструкцией Mozilla; для других продуктов имя файла будет другим.

Почему кнопка «Удалить» отсутствует или не работает

Кнопка недоступна у встроенного приложения. Некоторые компоненты Windows нельзя удалить обычным способом. Наличие приложения в системе само по себе не означает, что оно удаляется: проверяйте доступную команду для конкретной записи. Не применяйте массовые команды удаления системных пакетов ради одной программы.

Настольная программа не удаляется из Параметров. Проверьте её в «Программах и компонентах». Если она есть, запустите удаление оттуда. Отсутствие пункта в одном списке ещё не означает, что приложение системное.

Запрошены права администратора или удаление запрещено организацией. Используйте учётную запись с необходимыми правами либо обратитесь к администратору. Не пытайтесь обойти ограничения рабочего компьютера.

Мастер сообщает об ошибке. Запишите её текст и код. Сохраните работу, перезагрузите компьютер и повторите штатное удаление. Если ошибка возвращается, проверьте официальную поддержку разработчика; для программ из Microsoft Store используйте справку Microsoft Store.

Если цель — вернуть работоспособность, откройте меню приложения в Параметрах и проверьте Дополнительные параметры → Восстановить, если такая возможность есть. У настольной программы в Панели управления могут быть команды Восстановить или Изменить. Они доступны не у всех программ; порядок описан в справке по восстановлению. Кнопка «Сбросить» — другая операция: для упакованных приложений она удаляет данные и настройки, поэтому сначала сохраните важное.

В актуальном разделе Microsoft для Windows 11 рекомендуются перезапуск, доступные средства восстановления и рекомендации, появившиеся при ошибке. Отдельное скачиваемое средство Program Install and Uninstall troubleshooter описано на той же странице в разделе Windows 10. Не принимайте старую инструкцию за универсальный способ для Windows 11. Как проверить результат и вернуть программу

После завершения мастера снова откройте список, из которого удаляли программу, и найдите её по названию. Выполните предложенную перезагрузку, если она была частью удаления. Одна оставшаяся папка или ярлык ещё не доказывает, что программа установлена: это могут быть пользовательские файлы или следы прежней установки.

Не стирайте незнакомые папки в Program Files, ProgramData и AppData и не чистите реестр наугад. Если запись осталась в списке, разберите ошибку с разработчиком. Если нужно освободить больше места, отдельно проверьте файлы по руководству по очистке диска C.

Отменить завершённую деинсталляцию кнопкой «Назад» нельзя. Чтобы вернуть приложение, установите его из Microsoft Store или скачайте установщик с официального сайта разработчика. Для платного продукта могут понадобиться прежняя учётная запись и лицензия. Затем верните данные из резервной копии или выполните вход для синхронизации, если приложение её поддерживает. Повторная установка возвращает программу, но не заменяет резервную копию удалённых данных.
