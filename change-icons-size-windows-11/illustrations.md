# План и происхождение иллюстраций

План составлен до WordPress, 29.10.2026: (1) меню «Вид» рабочего стола, (2) меню «Просмотреть» Проводника, (3) результат мелких значков в демонстрационной папке, (4) отдельная обложка 16:9.

- images/originals/explorer-view-ru.png — собственный реальный снимок русского меню Проводника, Windows 11 26H2 build 26300.9711, Computer Use 29.10.2026. Сохранена отдельная безопасная область меню, предоставленная инструментом, 235×385. Личных данных нет. Не снимок веб-страницы. Открывается оригинал.
- images/originals/explorer-small-ru.png — собственный реальный фрагмент результата в специально созданной папке C:/Users/Public/Pictures/Icon-size-demo с тремя пустыми демонстрационными папками. Обрезано всё, кроме области списка, 500×100. UI не переводился и не ретушировался. Полный приватный снимок вне репозитория.
- images/icons-size-cover-20261029.jpg — built-in imagegen, редакционная иллюстрация, 1600×900, 16:9. Создана для статьи, не имитирует интерфейс и не является доказательством. Большая и маленькая папки, мышь и Ctrl; важных надписей по краям нет. Визуально проверена после генерации.
- evidence/site-*.png — только доказательства проверки веб-страницы, не скриншоты Windows.

Недостаёт обязательного кадра меню рабочего стола. Средство native Computer Use периодически сообщает active request и захватывает чужое переднее окно; безопасная съёмка рабочего стола не выполнена. Найденный файл на русской справочной странице Microsoft содержит явно локализованную графику с неестественными надписями, поэтому в качестве настоящего русского снимка не использован. Чужие изображения не включены. Пакет остаётся unverified-draft до съёмки и повторного прогона.

Аннотации не добавлены: меню и так показывает искомые размеры. Права на собственные редакционные кадры — редакция; права на интерфейс — Microsoft. В публичный Git идут только безопасные итоговые фрагменты.
