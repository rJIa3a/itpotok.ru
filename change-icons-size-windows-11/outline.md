# Карта объяснения

Отрывок — охват; начало — прямой ответ C1/C2.
1. Рабочий стол через меню → три размера, проверка, возврат C1.
2. Ctrl+колесо → более точный выбор, правильный фокус, отмена C2.
3. Папка Проводника → меню «Просмотреть», независимая настройка, виды, возврат C3.
4. Таблица → выбор по месту изменения; затем только существенные отличия масштаба C4 и панели задач C5/C6.
5. Диагностика → ошибка места действия и исчезнувшие значки C7.
6. FAQ → один значок, отсутствие колеса, два места настройки, возврат промежуточного размера.
