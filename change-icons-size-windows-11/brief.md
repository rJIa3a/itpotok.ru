# Бриф

Ключ: как уменьшить иконки на рабочем столе в windows 11. Очень точная частотность: 519 (ввод пользователя, самостоятельно не измерена).
Конкурент: https://remontka.pro/change-icons-size-windows-11/
Формат: manual. Читатель — пользователь Windows 11, желающий уменьшить значки без изменения всего интерфейса.
Результат: выбрать размер рабочего стола или папки, увидеть изменение и вернуть прежний вид.
Границы: рабочий стол, Проводник, различие с масштабом и панелью задач; без реестра и твикеров.
Проверка дублей 29.10.2026: авторизованный REST, status=any, три поиска «значк», «иконк», «рабочий стол», до 100 записей на поиск; duplicate-check.json. Подходящего материала Windows 11 нет. ID 1958 — Windows XP, ID 6407 — Windows 7 и нестандартные иконки; не обновлять. Новая запись, исходную опубликованную версию сохранять не требуется.
Критерии: отдельные настройки не смешаны, понятны исходное место, шаг, результат и возврат; нет непроверенных гарантий; русский интерфейс; штатный FAQ; WordPress только draft; отдельная ветка GitHub.
