В WordPress: ID 12193, статус draft, обложка 12188, меню 12189, результат 12191. FAQ берёт метаданные самой записи 12193; зависимого черновика нет. Не удалять запись, пока используется этот FAQ.

Реальный шаблон проверен авторизованным браузером: заголовок, отрывок, обложка, содержание, начало, изображения, подписи, увеличение, FAQ. 1366×900 и 390×844; обложка отображается высотой около 339 и 189 CSS px, основные объекты видны. На мобильном таблица прокручивается внутри контейнера без горизонтального расширения страницы. Доказательства веб-проверки находятся в `evidence/`; они не являются снимками Windows.

## Что осталось

1. Снять безопасное настоящее русское меню «Вид» именно рабочего стола. Подходящего кадра нет: Computer Use выдаёт active request и иногда захватывает другое переднее окно. Внешняя локализованная картинка Microsoft отвергнута как неубедительное доказательство реального интерфейса.
2. Выполнить полный initial и rerun по текущему тексту, включая Ctrl+колесо, проверку и возврат. Практически подтверждены только меню Проводника и выбор мелких значков в специально созданной папке с тремя пустыми папками. Масштаб и панель задач описаны по документации, не испытаны.
3. После добавления кадра синхронизировать исходник и WordPress, обновить реестр, контрольные точки и check. Публикация требует отдельного поручения пользователя.

`package-report.json` честно фиксирует незавершённые проверки. Локальный `preview.html` — редакционная оболочка, реальная проверка темы описана в `site-check.json`.
