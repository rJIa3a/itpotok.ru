# Иллюстрации

## План до загрузки черновика

| Место | Что требуется | Статус |
|---|---|---|
| Обложка | Горизонтальная редакционная иллюстрация Shift, безопасные поля | Создана imagegen, назначена медиазапись 12105, 1600×900 |
| Основные шаги, после отключения функции | Настоящая русская страница «Специальные возможности → Клавиатура», строка «Залипание клавиш» | Не получена, остаётся обязательной редакционной доработкой |
| Запрет пяти нажатий | Настоящая русская страница «Залипание клавиш», переключатель сочетания и его пояснение про Shift | Не получена, остаётся обязательной редакционной доработкой |

## Происхождение и условия

- `assets/sticky-keys-cover-crop-safe-20261016.png` — оригинальная сгенерированная редакционная иллюстрация. `assets/sticky-keys-cover-crop-safe-20261016.jpg` — полная композиция, приведённая к 1600×900 (16:9); это назначенная обложка. Built-in imagegen; запрос в cover-prompt.txt. Иллюстрация не изображает интерфейс и не служит доказательством шага. Допускается хранение в редакционном репозитории. Название Windows 11 используется для обозначения темы, логотип Microsoft не добавлялся.
- Собственные кадры не сняты: инструмент Computer Use вернул «Computer Use was not approved to use systemsettings». Другими инструментами ограничение не обходилось.
- Проверен официальный файл https://support.microsoft.com/ru-ru/accessibility/media/windows-11-accessibility-settings.png из справки Microsoft. Отклонён: смешанный русский/английский интерфейс, нужной настройки не видно; не включён ни в WordPress, ни в GitHub.
- Проверены кадры https://lumpics.ru/how-to-disable-sticky-keys-in-windows-11/ . Реальный русский интерфейс подходит, однако https://lumpics.ru/privacy-policy-and-terms-use/ , п. 6.3, требует письменного согласия на копирование. Разрешение не получено; файлы не скопированы и не встроены удалённо.
- Проверена политика Microsoft https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions . Разрешение на изображения Microsoft не распространялось автоматически на чужие оформленные кадры. Кадры конкурента с неизвестными условиями не использованы.

Читательский текст не содержит заглушек картинок. Отсутствие скриншотов означает, что полный запрос по иллюстрациям пока не выполнен. Перед публикацией нужно снять два кадра в доступной тестовой Windows 11 на русском, без личных данных, добавить увеличение оригиналов, точные alt и подписи, синхронизировать WordPress и эту ветку.

Кадры в `evidence/`, если присутствуют, показывают проверку шаблона сайта, а не интерфейс Windows.
