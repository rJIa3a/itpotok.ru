## Границы

Факты сверены по первичным источникам Microsoft; уточнён выход при сочетании двух клавиш — после нажатия нужно отпустить модификатор. Практические испытания Windows не проводились. Два реальных русских скриншота Windows отсутствуют: Computer Use отклонил управление SystemSettings. Об отсутствии кадров пользователь был уведомлён до прямого поручения публикации. Чужие кадры без права копирования и макеты интерфейса не добавлены. Это остаётся редакционной доработкой, а не блокировкой уже выполненной публикации.
