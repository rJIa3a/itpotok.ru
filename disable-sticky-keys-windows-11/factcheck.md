# Фактчекинг — 16 октября 2026 года

## Повторная сверка перед публикацией

По прямому поручению пользователя повторно открыты первичные источники Microsoft. Подтверждены путь к настройкам, различие активной функции и её горячей клавиши, пять нажатий Shift и правый Shift восемь секунд, двойное нажатие модификатора, фильтрация коротких и повторных нажатий. Уточнён момент выхода при двух клавишах: после сочетания нужно отпустить модификатор (SKF_TWOKEYSOFF). Это единственная фактическая правка при повторной сверке. Публикация разрешена пользователем после фактчекинга; отсутствие двух русских скриншотов было сообщено до этого разрешения. Проверка по документации не объявляется практическим испытанием Windows.

## Первичные источники

1. Microsoft Support: https://support.microsoft.com/ru-ru/accessibility/windows/make-your-mouse-keyboard-and-other-input-devices-easier-to-use — Windows 11, путь «Специальные возможности → Клавиатура», назначение залипания и фильтрации ввода. Различены последовательное нажатие модификаторов и игнорирование коротких/повторных нажатий.
2. Microsoft Support: https://support.microsoft.com/en-gb/accessibility/windows/windows-keyboard-shortcuts-for-accessibility — пять нажатий Shift переключают залипание; правый Shift восемь секунд переключает фильтрацию ввода. Английский первичный источник использован для фактов, его изображения в статье не используются.
3. Microsoft Learn: https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-stickykeys — независимые состояния SKF_STICKYKEYSON и SKF_HOTKEYACTIVE, двойное нажатие SKF_TRISTATE, выход при сочетании модификатора с другой клавишей SKF_TWOKEYSOFF и звук SKF_AUDIBLEFEEDBACK. Значения реестра в инструкцию не перенесены. Устаревшие флаги индикатора и подтверждения, помеченные Windows 95/98/2000, не выданы за описание современного интерфейса.
4. Microsoft Support: https://support.microsoft.com/ru-ru/accessibility/windows/use-a-screen-reader-and-keyboard-to-navigate-the-windows-accessibility-flyout — современное описание функции в Windows 11; быстрые настройки не добавлены как ещё один обязательный способ, поскольку не решают запрет повторного вызова.

## Проверка интерфейсных формулировок

Русские названия «Сочетание клавиш для залипания клавиш», путь и дополнительная страница сверены по реальным внешним кадрам Windows 11 в https://lumpics.ru/how-to-disable-sticky-keys-in-windows-11/ (автор Виктор Бухтеев, дата публикации 03.10.2022, обновление 02.08.2025) и https://remontka.pro/disable-sticky-keys-windows/ (02.06.2023). Это вторичные источники для вида интерфейса, не замена документации о поведении функции. Кадры не скопированы. Дополнительные пункты в статье описаны по действию, с оговоркой о различиях сборок; не выданы за дословную стенограмму текущей сборки.

## Разбор конкурента

Страница remontka.pro доступна с завершающим слешем. Сильные стороны: показаны клавиатура, быстрые настройки, Параметры и классическая Панель управления; есть объяснение последовательного ввода. Для нашего материала выбрана структура по двум задачам: выключить активный режим и запретить повторный вызов. У конкурента второй вопрос раскрыт через реестр; в нашем тексте он решается сразу через отдельный переключатель. Не перенесены Flags=506, проверка по одному нажатию Win, а также лишние способы ради количества. Добавлены независимые опции, различия с фильтрацией ввода и аппаратным заеданием, проверка и возврат.

## Границы проверки

- Практический прогон Windows, пятикратного Shift и возврата не выполнен. Computer Use отклонил запуск SystemSettings; обхода ограничения не было.
- Не проверены перезагрузка, экран входа, другие учётные записи, корпоративные политики, игры и аппаратные неисправности. Гарантий для этих условий нет.
- Тест Shift → A предложен как проверка читателя, а не как выполненное испытание редакции. Caps Lock оговорён.
- Поведение в Параметрах без кнопки «Применить» и классическое окно сверены по доступным интерфейсным материалам; не заявлена проверка на последней сборке Windows.
- Точная частотность 987 взята из переданного редакционного плана, не измерялась заново; позиции в поиске не обещаются.
