## Ограничения

Page.captureScreenshot несколько раз завершался тайм-аутом; снимков веб-страницы получить не удалось. Последняя попытка через Windows Computer Use остановлена самим инструментом: он не смог уверенно определить URL браузера для проверки политики. После остановки UI-ввод не продолжался.

Нет полноценной визуальной проверки широкого и узкого экрана, обрезки обложки, переноса таблицы, раскрытия всех FAQ и увеличения снимков. Их нельзя считать проверенными по DOM. Изображения тела имеют lazy loading; при первом чтении они вне viewport, полная загрузка в шаблоне не подтверждена. Адреса и сами файлы проверены отдельно. Папка verification/ не содержит вымышленных доказательств.

Перед публикацией завершить эти проверки в доступном браузере. Сброс Windows, облачная загрузка, удаление и перезагрузка не выполнялись. Проверка публичной опубликованной страницы не применима к draft.
