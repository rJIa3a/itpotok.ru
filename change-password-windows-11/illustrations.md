Собственные кадры искались через Computer Use. SystemSettings.exe не предоставил целевое окно; повторное перечисление окон не обнаружило его. Изменение паролей не выполнялось. Запущенной тестовой QEMU-среды не найдено.

Проверен файл из [русской справки Microsoft](https://support.microsoft.com/ru-ru/accounts-billing/security/sign-in-options-in-windows): https://support.microsoft.com/ru-ru/accounts-billing/media/sign-in-options.png . На изображении видны признаки переведённой/скомпонованной иллюстрации («&gt;», разный набор переводов), портрет, имя и демонстрационный адрес. Он не подтверждает настоящий русский интерфейс и исключён из статьи и публичного GitHub. Мелкие изображения сброса пароля относятся к другой задаче и не использованы.

Чужие кадры конкурента не копировались: право распространения в публичном репозитории не установлено. [Правила использования скриншотов Microsoft](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions) изучены; они не дают основания объявлять перевод изображения собственным реальным кадром.

Обложка создана imagegen, собственная редакционная иллюстрация, не снимок Windows и не доказательство шага. Исходник 1672×941, практически 16:9. WordPress отдаёт изображение 1280×720. Содержит надпись «Пароль Windows 11», замок, ключ, условные точки пароля. alt обозначает редакционную иллюстрацию.

Размеры по DOM шаблона: на экране 1280 px — 370×289,44 px, object-fit:cover; на экране 390 px — 335,2×188,65 px. В широком варианте тема обрезает стороны. Текст исходника расположен внутри центральной области, однако фактическая визуальная читаемость после обрезки не подтверждена: захват страницы завершился ошибками 0 width и тайм-аутом. Перед готовностью нужен визуальный контроль в работающем браузере. Кадров доказательства сайта нет; изображения сайта не выдавались за Windows.

Для завершения нужны доступная русская тестовая Windows 11 и обезличенный тестовый Microsoft-аккаунт либо разрешённые внешние кадры того же шага. Не заменять требование генерацией или иностранным интерфейсом.
