# FAQ

Штатный блок webnavoz_faq. Данные хранятся у самой итоговой записи, дополнительный черновик-источник не создаётся. ID записи и источника данных — 12084. Пять ответов сохранены и прочитаны обратно. Не удалять запись, пока используется её FAQ.

## Можно ли поставить пароль только на этот компьютер с аккаунтом Microsoft?

У аккаунта Microsoft пароль общий для аккаунта. Для входа на конкретном устройстве можно использовать PIN Windows Hello: он привязан к этому устройству. Это другой способ входа, а не отдельный пароль Microsoft для одного ПК.

## Почему после смены пароля Windows по-прежнему принимает PIN?

PIN Windows Hello и пароль — разные данные. Чтобы проверить новый пароль, на экране входа выберите «Варианты входа» и вход по паролю. Ввод PIN проверяет только PIN.

## Нужны ли права администратора для смены своего известного пароля?

Для обычной смены пароля своей локальной записи через «Параметры» повышение до администратора не требуется. Изменение чужой записи администратором — другая операция; в этом руководстве она не рассматривается.

## Можно ли изменить пароль, если помню только PIN?

PIN позволяет войти на устройство, но не заменяет текущий пароль в форме его смены. Если пароль неизвестен, требуется отдельная процедура восстановления доступа. Эта статья описывает смену известного пароля.

## Защитит ли новый пароль вход после включения компьютера?

Пароль задаёт данные для входа в запись, однако автоматический вход может оставаться настроенным. Проверьте вход после блокировки и отдельно после перезагрузки. Одна смена пароля не гарантирует отключения автоматического входа.
