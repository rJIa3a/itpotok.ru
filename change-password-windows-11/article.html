Чтобы поставить пароль в Windows 11, откройте Параметры → Учётные записи → Варианты входа → Пароль. У локального пользователя без пароля выберите Добавить, а для смены существующего — Изменить. Если вы входите с аккаунтом Microsoft, меняется пароль этого аккаунта; сделать это можно и на сайте Microsoft.

Далее разобраны установка и смена известного пароля своей записи. Если вы забыли пароль или хотите отключить его запрос при включении компьютера, это другие задачи. Описанные действия подходят для Windows 11 Home и Pro; на рабочем или учебном компьютере способы входа может ограничивать организация.

Определите тип учётной записи и способ входа

Нажмите Win + I и откройте Учётные записи → Ваши данные. Для локального пользователя Windows показывает, что запись локальная, и предлагает вместо неё войти с учётной записью Microsoft. При подключённом личном аккаунте Microsoft доступен обратный переход — вход с локальной записью. Сам по себе вход в Microsoft Store или Outlook ещё не означает, что для входа в Windows используется тот же аккаунт.

Пароль и PIN — разные данные. PIN Windows Hello связан с конкретным устройством. Пароль аккаунта Microsoft используется для самого аккаунта, в том числе при входе в его службы с других устройств. Поэтому работающий PIN не подтверждает, что вы помните пароль, а смена пароля не является командой смены PIN.

Как поставить пароль локальному пользователю

Войдите в ту локальную запись, которую хотите защитить. Менять другую запись через администратора для этой задачи не требуется.

  1. Нажмите Win + I, откройте Учётные записи → Варианты входа. В некоторых версиях и в справке Microsoft раздел называется «Параметры входа».
  2. Раскройте Пароль и нажмите Добавить. Если вместо этого появилась кнопка «Изменить», пароль уже задан: переходите к следующему разделу.
  3. Введите новый пароль и повторите его в поле подтверждения. Заполните подсказку так, чтобы она помогала вспомнить пароль, но не раскрывала его посторонним.
  4. Нажмите Далее, затем Готово.

Не оставляйте поля пароля пустыми: ваша цель — добавить пароль. Используйте отдельную длинную комбинацию или фразу, которую не применяете на других сайтах. До проверки входа сохраните её в надёжном месте.

После завершения в разделе «Пароль» будет доступна смена уже заданного пароля. Проверка настоящего входа описана ниже: одна кнопка в настройках ещё не показывает, какой способ Windows использует на экране входа.

Как поменять известный пароль локальной записи

  1. Войдите в свою запись и откройте Параметры → Учётные записи → Варианты входа.
  2. Раскройте Пароль и нажмите Изменить.
  3. Введите текущий пароль и нажмите Далее. В этом поле нужен пароль записи, а не PIN Windows Hello.
  4. Введите новый пароль, повторите его и заполните подсказку. Нажмите Далее → Готово.

Изменяется пароль этой локальной записи на этом ПК. Пароли почты, сайтов и аккаунта Microsoft, в который вы отдельно вошли в приложении, от этого не меняются.

Если текущий пароль неизвестен, не заменяйте эти шаги командами администратора или пунктом «Задать пароль» в оснастке пользователей. Административный сброс — отдельная операция со своими рисками для защищённых данных; здесь он не рассматривается.

Как изменить пароль аккаунта Microsoft

Понадобятся интернет и доступ к способу подтверждения личности, если Microsoft его запросит. Новый пароль относится к аккаунту целиком, а не только к одному компьютеру. В Outlook.com используется тот же пароль, поэтому учитывайте это перед изменением.

В Windows можно открыть Параметры → Учётные записи → Варианты входа → Пароль → Изменить и выполнить подсказки Microsoft. Если раздела «Пароль» нет или удобнее использовать браузер, откройте безопасность аккаунта Microsoft:

  1. Войдите именно в тот личный аккаунт, который используется для входа в Windows. Проверьте его адрес перед продолжением.
  2. Выберите Изменить пароль. При необходимости подтвердите личность предложенным способом.
  3. Введите текущий пароль и новый пароль в соответствующие поля, повторите новый, если форма просит подтверждение.
  4. Нажмите Сохранить.

На устройствах и в приложениях, где появится новый запрос пароля этого аккаунта, используйте новую комбинацию. Не считайте продолжающий работать PIN признаком неудачной смены: это другой способ входа. Официальная инструкция Microsoft описывает смену известного пароля.

У аккаунта Microsoft, настроенного для работы без пароля, нет старого пароля для такой смены. Если вы хотите добавить его обратно, откройте дополнительные параметры безопасности аккаунта, найдите Учётная запись без пароля, выберите Отключить → Далее и следуйте процедуре добавления пароля. Это изменение режима аккаунта; оно не равнозначно появлению кнопки «Пароль» в Windows. Справка Microsoft об аккаунте без пароля.

Проверьте вход с новым паролем

  1. Сохраните открытые документы. Если меняли пароль Microsoft, подключите компьютер к интернету.
  2. Нажмите Win + L, чтобы заблокировать компьютер, и перейдите к экрану входа.
  3. Если показано поле PIN, выберите Варианты входа и способ входа по паролю. Введите новый пароль и убедитесь, что открывается ваш рабочий стол. Если способ входа по паролю отсутствует, сначала прочитайте раздел ниже о Windows Hello: отсутствие этого способа не доказывает, что смена не сохранилась.

Если новый пароль не принимается, сначала проверьте выбранного пользователя, способ входа, язык клавиатуры и Caps Lock. Для аккаунта Microsoft отдельно проверьте вход с новым паролем на его сайте в отдельном окне браузера: это помогает отличить смену онлайн-пароля от проблемы входа на конкретном компьютере. Не выполняйте подряд несколько сбросов вместо этой проверки.

Установка или смена пароля не гарантирует отключение автоматического входа. Если Windows после включения сразу открывает рабочий стол, пароль может существовать, а автоматический вход — оставаться настроенным. Проверка после блокировки подтверждает приём пароля; поведение после включения нужно проверить отдельно, сохранив работу и перезагрузив ПК. Настройка автоматического входа выходит за рамки этой статьи.

Чтобы заменить неудачно выбранный новый пароль локальной записи, повторите обычную смену, указав его как текущий. У Microsoft тоже выполняется новая смена с учётом требований, показанных в форме аккаунта: отдельной кнопки отмены уже сохранённого изменения нет.

Если раздел «Пароль» отсутствует

Для аккаунта Microsoft Windows может разрешать на этом устройстве только вход через Windows Hello. В дополнительных параметрах входа проверьте настройку, которая разрешает вход с Windows Hello только для учётных записей Microsoft. Она влияет на доступность входа по паролю на ПК, но не меняет пароль аккаунта на сайте Microsoft. Для смены самого пароля можно использовать браузер, не меняя эту настройку.

На компьютере организации доступность способов входа определяется также её правилами. Не пытайтесь обходить ограничения реестром или отключением рабочей учётной записи: обратитесь к администратору. Личные аккаунты Microsoft и рабочие или учебные записи используют разные процедуры управления паролем.
