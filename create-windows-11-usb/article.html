Чтобы сделать загрузочную флешку с Windows 11, используйте средство создания носителя Microsoft или запишите официальный ISO-образ через Rufus. Первый вариант удобен, если образа ещё нет, второй — если ISO уже скачан или нужны дополнительные параметры. Ниже — подготовка накопителя, запись и проверка загрузки без установки системы.

Здесь речь об установочной флешке: с неё запускают установщик, а Windows размещают на внутреннем диске. Это отличается от переносной системы, которая работает непосредственно с USB-накопителя.

Что подготовить перед записью

  • Флешку от 8 ГБ. Это минимум для средства Microsoft. Практичнее взять 16 ГБ или больше: конкретный ISO может не поместиться на небольшой накопитель.
  • Рабочий компьютер с Windows и правами администратора. Для актуального Rufus нужна Windows 8 или новее; проще готовить носитель на Windows 10 или 11.
  • Интернет и свободное место на диске. При записи готового ISO через Rufus повторно скачивать Windows не нужно.
  • Копию нужных файлов с флешки. Программы записи удаляют её содержимое. Проверьте, что скопированные документы открываются с другого диска.

Отключите лишние внешние накопители и запомните название, букву и объём нужной флешки. Это поможет не перепутать устройство при записи.

Флешку можно подготовить на одном компьютере, а использовать на другом. Совместимость проверяйте у того ПК, на который будете устанавливать систему: создание носителя само по себе её не подтверждает. Требования включают совместимый процессор, TPM 2.0 и UEFI с поддержкой Secure Boot; подробности есть в справке Microsoft.

Создание флешки через средство Microsoft

Этот вариант подходит для стандартной установки на ПК с процессором x64. Media Creation Tool загружает установочные файлы и подготавливает USB-накопитель.

  1. Откройте страницу загрузки Windows 11. Найдите раздел «Создание установочного носителя Windows 11» и скачайте средство. «Помощник по установке» предназначен для обновления текущего ПК, а не записи флешки.
  2. Подключите накопитель и запустите скачанный файл. Подтвердите запрос администратора, ознакомьтесь с лицензией и примите её, если согласны.
  3. Выберите язык и выпуск системы. Для другого компьютера снимите использование рекомендуемых параметров, если они не подходят. Для русскоязычной установки выберите русский язык.
  4. На экране выбора носителя укажите «USB-устройство флэш-памяти», а не ISO-файл.
  5. Выберите нужный съёмный накопитель по букве и объёму. Если он не появился, обновите список. Перед продолжением ещё раз проверьте устройство.
  6. Дождитесь окончания загрузки и записи. Не извлекайте флешку в процессе. Когда средство сообщит о готовности носителя, нажмите «Готово».

Ожидаемый результат — накопитель с файлами установщика. Продолжительность зависит от интернета и скорости USB; фиксированное время обещать нельзя.

Запись ISO-образа через Rufus

Скачайте Windows из раздела ISO на сайте Microsoft, выбрав язык и подходящую архитектуру. Для большинства ПК на Intel и AMD нужен x64. ARM64 — отдельный вариант для соответствующего оборудования.

Если на странице доступна проверка загрузки, сравните SHA-256 скачанного образа с опубликованным значением именно для этого выпуска, языка и архитектуры. В PowerShell команда выглядит так; вместо пути-примера укажите свой:

Get-FileHash -Algorithm SHA256 -LiteralPath "C:\ISO\Windows11.iso"

Затем скачайте Rufus с официального сайта разработчика. Портативный вариант не требует установки.

  1. Запустите Rufus и в поле «Устройство» выберите нужную флешку.
  2. В поле «Метод загрузки» нажмите «ВЫБРАТЬ» и откройте скачанный ISO. Проверьте, что в поле отображается его имя.
  3. В параметрах образа выберите «Стандартная установка Windows». Windows To Go — другой сценарий.
  4. Для обычного современного ПК выберите GPT и UEFI (non-CSM). Файловую систему и размер кластера оставьте предложенными программой после выбора ISO.
  5. Нажмите «СТАРТ». Если появится окно настройки установки Windows, для стандартного носителя отключите ненужные изменения, включая обход требований и автоматическую настройку учётной записи.
  6. Подтвердите удаление данных только после проверки выбранного устройства. Дождитесь успешного окончания записи без сообщения об ошибке.

Статус «Готов» нужно оценивать после записи. Программа может показывать готовность к работе ещё до нажатия «СТАРТ»; одного такого слова при открытии Rufus недостаточно для проверки созданного носителя.

Нужно ли выбирать MBR или FAT32

GPT и UEFI в Rufus относятся к создаваемому носителю. Выбор этих параметров не преобразует внутренний диск компьютера. Если установщик позднее сообщит о неподходящем стиле разделов внутреннего диска, это отдельная задача; не удаляйте разделы ради устранения ошибки без резервной копии.

MBR и режим BIOS/CSM нужны для другого сценария загрузки и не являются универсальным решением для Windows 11. Официальные требования предусматривают UEFI. Переключать рабочий компьютер в Legacy только ради флешки не следует.

FAT32 ограничивает размер отдельного файла 4 ГБ. Поэтому ручное копирование содержимого образа может остановиться на большом install.wim. Microsoft описывает разделение WIM на части, но для обычной подготовки проще использовать средство записи. Если Rufus предложил NTFS, не заменяйте её автоматически на FAT32: для загрузки UEFI программа использует соответствующий механизм.

Флешка без проверки TPM: что можно сделать в Rufus

После выбора ISO Windows 11 и нажатия «СТАРТ» Rufus может предложить отключить требования к TPM 2.0, Secure Boot и объёму оперативной памяти. Названия и доступность опций зависят от версии программы и образа. Если такой пункт есть, его выбирают перед подтверждением записи.

Обход проверки установщика не добавляет отсутствующие возможности процессора и не устраняет несовместимость драйверов. Его работа в одном выпуске не гарантирует работу в следующем. Разработчик поясняет эти ограничения в FAQ Rufus.

Microsoft не рекомендует такую установку: компьютер не получает официальной поддержки, а обновления, включая обновления безопасности, не гарантированы. Сначала проверьте, нет ли на ПК поддерживаемого, но отключённого TPM — он может называться Intel PTT или AMD fTPM. Инструкцию для конкретной модели ищите у производителя.

Для отмены настройки заново запишите ISO в Rufus с отключённым обходом. Это заменит файлы на флешке, но не отменит уже выполненную установку Windows.

Как проверить загрузку с готовой флешки

Наличие setup.exe и папок sources, boot, efi — предварительная проверка. Она не доказывает, что конкретный компьютер сможет загрузиться с USB.

  1. Сохраните открытые документы и оставьте флешку подключённой к компьютеру, на котором хотите проверить запуск.
  2. Перезагрузите ПК и откройте разовое меню загрузки — Boot Menu. Клавиша зависит от модели; часто это F12, F11 или Esc. Точную комбинацию проверьте в руководстве производителя.
  3. Выберите USB-накопитель. Если доступны два пункта с одинаковым именем, для носителя GPT/UEFI выбирайте вариант с пометкой UEFI.
  4. Дождитесь начального экрана установщика. Для проверки не переходите к удалению разделов, форматированию и установке.
  5. Завершите работу установщика, выключите компьютер и извлеките флешку. Затем загрузитесь с внутреннего диска.

Появление установщика подтверждает загрузку носителя на этом ПК, но ещё не подтверждает успешную установку, активацию и наличие всех драйверов. Дальнейшие действия разобраны в статье «Как установить или переустановить Windows 11».

Разовое Boot Menu обычно удобнее постоянного изменения порядка загрузки. Если вы всё же меняли приоритет в UEFI, верните первоначальный после проверки.

Как снова использовать флешку для файлов

После завершения работы скопируйте с USB всё нужное. В Rufus выберите этот накопитель, в «Методе загрузки» — «Незагрузочный», задайте файловую систему и запустите форматирование. Оно удалит установочные файлы и созданные программой дополнительные разделы.

Для хранения файлов больше 4 ГБ подойдут exFAT или NTFS; совместимость с телевизором, магнитолой и другими устройствами проверьте в их документации. После форматирования убедитесь, что виден ожидаемый объём и на флешку можно скопировать и прочитать тестовый файл. Прежние файлы, удалённые при создании установщика, форматирование не восстановит.
