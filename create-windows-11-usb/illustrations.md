## Удалённые внешние кадры

- `https://rufus.ie/pics/screenshot1_ru.png` — русский Rufus 3.20.1929 с Windows 11 22H2. Был подключён в предыдущем черновике с подписью версии. В [rufus-web](https://github.com/pbatard/rufus-web) отсутствовала явная лицензия, GitHub API возвращал `license: null`. GPL приложения не перенесена на снимки отдельного сайта. 09.10.2026 удалён из статьи и WordPress; в GitHub файл не копировался.
- `https://skillbox.ru/upload/setka_images/23425503092026_d0e289e355555cb39f9d7f499b6888c389473c54.png` — русский выбор USB в MCT, [Skillbox Media](https://skillbox.ru/media/code/ustanovka-windows/), 04.09.2026. Общие [условия Microsoft для скриншотов](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions) не подтверждают разрешение автора чужого снимка. Прежнее обоснование было недостаточным. 09.10.2026 кадр и утверждение о разрешении удалены из статьи; чужой файл в публичный GitHub не включён.

Не использовать иностранный интерфейс, переведённый макет, пустое окно со словом «Готов» или снимок веб-страницы вместо нужного результата. 09.10.2026 по прямому поручению пользователя после фактчекинга опубликована текущая версия с обложкой и собственным кадром установщика. Публичная страница содержит оба изображения; alt, подпись и увеличение проверены. Кадры Rufus и MCT ещё отсутствуют — не считать комплект завершённым. При их добавлении снова проверить соответствующие шаги, подписи и увеличение. `proof/published-*.jpg` — доказательства проверки сайта после публикации.
