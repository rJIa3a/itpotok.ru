Предпросмотр открывается, начало и содержание прочитаны. FAQ сохранён видимой кнопкой штатной формы: пять вопросов остаются после перезагрузки, все ответы присутствуют на странице. Первая гармошка раскрыта по умолчанию. Обложка 11992 назначена через уже авторизованный REST API. Первый вариант с текстом плохо обрезался темой, заменён квадратной иллюстрацией без надписей; основные объекты сохранены в обрезке. Разрешение Edge для загрузки файлов больше не требуется.

Добавлен русский внешний кадр MCT с выбранным USB (Skillbox Media); условия Microsoft проверены. Таблицы помещены в контейнеры горизонтальной прокрутки. Все пять FAQ последовательно раскрыты и показывают нужные ответы. REST подтвердил точное совпадение тела и отрывка с файлами. Осталось: завершить кадры Rufus и результата, подтвердить права на внешний Rufus либо заменить его, проверить узкий экран, опубликовать и проверить страницу без авторизации. Попытка режима 390×844 не изменила фактическую ширину браузера (1028): мобильная проверка не засчитывается.

Официальный Rufus 4.15 portable скачан вне репозитория, подпись Akeo Consulting действительна. Запуск потребовал UAC и был отменён; собственный кадр не снят.
