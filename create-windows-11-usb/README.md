## Что сделано

Основным способом стал Rufus; Media Creation Tool оставлен альтернативой. Уточнены GPT/UEFI, NTFS, различие установочной флешки и Windows To Go, дополнительные параметры и ограничения обхода требований. Добавлено предупреждение об автоматическом стирании диска при тихой установке. Надпись «Готов» до записи не представлена как доказательство результата.

Запись 11989 и её URL сохранены, новый черновик не создан. Опубликованная статья об ISO [12015](https://itpotok.ru/download-windows-11-iso/) связана внутренней ссылкой. Статья об установке [11476](https://itpotok.ru/how-to-install-windows-11/) не менялась. Поиск WordPress не выявил отдельной опубликованной инструкции на тот же запрос.

REST подтвердил точное совпадение сохранённых тела и отрывка с исходниками, итоговый статус `publish`, обложку 12023 и ключ `rufus windows 11`. Все пять штатных FAQ раскрыты и сверены; шорткод получает данные из самой записи 11989. Зависимости от другого черновика нет.

Обложка — редакционная иллюстрация `windows-11-usb-cover-wide-20261009.png`. Проверены её назначение и обрезка темы. На ширине 390 пикселей нет горизонтального переполнения всей страницы; первая таблица имеет отдельную горизонтальную прокрутку. Кадры в `proof/` подтверждают проверку веб-страницы, а не работу Rufus или загрузку с USB.

После публикации сокращён alt снимка установщика: длинная подпись перекрывала его в мобильном увеличении. Повторная проверка и REST-сверка после правки пройдены.

## Что осталось

Нужны реальные русские кадры Rufus с выбранными ISO и накопителем, дополнительных параметров и выбора USB в MCT. Собственный кадр языковых параметров установщика снят после загрузки официального ISO в тестовой виртуальной машине и добавлен в статью (media 12020). Это не проверка физической флешки. Старые внешние изображения Rufus 3.20 и Skillbox удалены: право повторного использования не подтверждено. План оставшихся кадров — в `illustrations.md`.

Официальный русский ISO скачан вне репозитория; SHA-256 совпал с опубликованным Microsoft. Rufus 4.15 portable имеет действительную подпись Akeo Consulting. Ранее наблюдалось русское окно с «Обнаружено устройств: 0»; при продолжении открытого окна не обнаружено. Пользователю отправлен запрос ручного открытия и подключения флешки только для кадров. Запись накопителей не разрешалась и не выполнялась.

Практическая запись USB, загрузка физического ПК, обход требований и установка Windows не проверены. Пользователь прямо поручил «фактчекинг сделай и публикуй». Повторная сверка Microsoft и Rufus не выявила существенных ошибок. Опубликована текущая версия с собственным кадром установщика; неподтверждённые чужие изображения не возвращались. В браузере после публикации проверены пять раскрывающихся ответов, изображение и его увеличение, обычная ширина 1280 и узкая 390. Анонимный HTTP-запрос подтвердил страницу, изображения, FAQ и отсутствие панели администратора и видимого шорткода. Другие опубликованные записи не менялись.
