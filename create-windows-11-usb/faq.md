# FAQ

## Можно ли просто скопировать ISO на флешку?

Для описанных способов — нет. Media Creation Tool или Rufus должны подготовить загрузчик и установочные файлы. Копирование одного ISO обычным способом этого не делает.

## Хватит ли флешки на 8 ГБ?

Для Media Creation Tool Microsoft указывает минимум 8 ГБ. Для конкретного ISO проверьте размер образа и доступное место. Практичнее использовать 16 ГБ или больше.

## Запись флешки удалит Windows с компьютера?

Запись удаляет данные выбранного USB-накопителя. Внутренний диск изменяется на последующих этапах установки, а не при подготовке флешки. Поэтому важно правильно выбрать устройство.

## Можно ли использовать одну флешку для разных компьютеров?

Да, если архитектура образа, режим загрузки и оборудование подходят каждому ПК. Создание флешки не переносит лицензию и не гарантирует совместимость всех компьютеров.

## Rufus обходит все ограничения Windows 11?

Нет. Дополнительные опции снимают часть проверок установщика, но не добавляют возможности оборудования и не обеспечивают официальную поддержку или гарантированные обновления.
