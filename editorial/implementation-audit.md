# Внедрение и границы

Дата сверки источников: 2026-10-16.

## Что было в проекте

Git-репозиторий расположен в itpotok.ru/, родительская рабочая папка содержит множество отдельных исследовательских скриптов и дополнительных checkout. В репозитории статьи разложены по папкам: README, HTML, фактчекинг, illustrations, WordPress/FAQ JSON. AGENTS.md определяет русские кадры, отдельный черновик, сохранение URL/ID, FAQ, GitHub и проверку темы. Централизованного координатора и версионируемой .agents/skills в текущем checkout не было. Установленный itpotok-writing содержит SKILL.md и два справочника; скопирован без изменения текста.

Существовавшие незакоммиченные изменения AGENTS.md (формат обложек) и create-windows-11-usb/illustrations.md сохранены вне коммита системы. Разовые скрипты из родительской папки не перенесены: их доступы, частные данные и действия публикации не нужны координатору.

## Реализовано

- 13 SKILL.md: координатор, 11 этапов, существующий редактор текста. Общая политика, контракты и примеры структур доказательств вынесены отдельно.
- CLI init/checkpoint/check/preview/refresh на стандартной библиотеке Python. Контрольные точки с хешами, реестр оснований, отдельные initial/rerun, проверка текущей версии текста, ссылки и границы файлов.
- Шаблоны брифа, редакторской проверки и объектов доказательств. Инициализатор создаёт отдельный README первым и отказывается перезаписывать существующую папку.
- Три коротких внутренних материала с источниками, реестром, текстом, локальным preview и метриками. CLI-мануал реально прогнан дважды. Полный производственный цикл с визуалами не аттестован.
- Десять тестов существенных блокировок; положительная аттестация в тесте явно синтетическая.

## Что не заявляется работающим

Нет автономного генератора статей: CLI обслуживает артефакты, работу выполняет координатор ИИ доступными инструментами. Нет автоматического мониторинга изменений сайтов: refresh выявляет сроки реестра, исследователь проверяет изменения.

WordPress API, тема сайта, FAQ и публикация в этой задаче не вызывались. Сценарий Playwright не добавлен как якобы универсальный захват: конкретные состояния продукта, локаторы, русская среда и разрешённый браузер требуют отдельного прогона. Доступность такого инструмента зависит от сессии. Инструкции screenshot-capture описывают необходимые результаты и остановку; настоящая съёмка здесь не испытана. Графики из чисел и аннотации не испытывались. Три коротких пилота не заменяют проверку полных статей человеком; время такой проверки неизвестно.

Штатный quick_validate.py не запустился: отсутствует PyYAML. Вместо него выполнены ограниченные проверки frontmatter и существования ссылок для всех 13 навыков, результат в evaluation/skill-validation.json. Это не эквивалент полной проверки штатным валидатором. Runtime системы сторонних пакетов не требует.

Скопированный itpotok-writing совпадает с установленной копией; исходник для последующих согласованных изменений теперь в .agents/skills/itpotok-writing/. Новые модульные навыки живут только в проекте: их не следует глобально устанавливать без общей политики и относительных ссылок.
