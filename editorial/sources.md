# Исследовательская основа

Сверено 2026-10-16 через открытие страниц web. Это короткие выводы для архитектуры, не перенос стандартов чужой редакции на сайт.

| Источник | Проверенное основание и границы |
|---|---|
| [Ahrefs](https://ahrefs.com/blog/how-i-do-content-engineering-with-claude-code/) | Автор описывает 23 skill-файла, этапы, собственные инструменты и редакционное решение. Съёмка и аннотации браузером в описанной версии обозначены экспериментом. Это опыт автора, не контролируемое доказательство превосходства архитектуры. |
| [Noy и Zhang, Science](https://doi.org/10.1126/science.adh2586), [опубликованная аннотация](https://pubmed.ncbi.nlm.nih.gov/37440646/) | DOI при прямом открытии вернул 403. Прочитана аннотация публикации: профессиональные письменные задания, рандомизированный эксперимент. Не доказывает фактологическую надёжность автоматически подготовленных инструкций. Ранний SSRN содержит другую выборку (444 против 453 в опубликованной аннотации); версии не смешивать. Полный текст Science не проверен. |
| [AP](https://www.ap.org/the-definitive-source/announcements/ap-updates-newsroom-standards-for-artificial-intelligence/) | На странице дата 2026-07-23. Допускаются отдельные вспомогательные задачи, сохраняются ответственность журналиста, проверка и редактура; генеративная новостная фотография запрещена. Это правила AP, здесь используется принцип ответственности и проверки. |
| [Google Procedures](https://developers.google.com/style/procedures) | Последовательные действия, контекст и результат шага, отличение необязательных действий. Используем как руководство по изложению, не как доказательство работоспособности продукта. |
| [Diátaxis](https://diataxis.fr/) | Различает tutorial, how-to, reference и explanation. Сравнение — наш редакционный формат, а не пятый тип Diátaxis. |
| [Google Search](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content) | На странице обновление 2026-10-01. Нужны точность, качество, релевантность и ручная проверка, включая метаданные. Массовое создание без пользы может нарушать правила спама; гарантий ранжирования нет. |
| [Anthropic Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills) | Папки инструкций, ресурсы и код; постепенная загрузка. Модули не требуют отдельного агента каждый. |
| [Playwright Screenshots](https://playwright.dev/docs/screenshots) | Документированы снимки страницы и отдельного элемента, fullPage. Возможность API не подтверждает установленный браузер или разрешение применять его в текущей среде. |

Архитектура, статусы и пороги блокировки — решение редакции по заданию пользователя. Регулярно перепроверять источники при пересмотре политики; не переписывать дату без открытия страниц.
