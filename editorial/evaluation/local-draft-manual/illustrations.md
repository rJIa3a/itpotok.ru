# Иллюстрации

Для короткого пилота иллюстрации не требуются: интерфейс продукта не описан. В CLI-мануале нужны команды и результаты, сохранённые в evidence/. Настоящие скриншоты, графики и обложка не создавались; их производственный цикл этим пилотом не проверен. Для публикационного пакета потребуется отдельный план обложки и проверка темы.
