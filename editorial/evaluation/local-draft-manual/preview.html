Локальный предпросмотр; тема WordPress не проверена.

Короткий внутренний материал для проверки редакционного процесса и его ограничений.

Как создать локальный редакционный черновик

Из корня репозитория запустите init для новой папки, затем check и preview. Вы получите заготовку и локальную страницу для чтения.

Подготовка

Нужны Python 3.10 или новее и этот репозиторий. Команды ниже используют новую папку sample-article. Если такая папка уже есть, выберите другое имя: init не перезаписывает существующую папку.

  1. Запустите python editorial/workflow.py init sample-article --format explanation --keyword "Пример". В новой папке должны появиться README.md и workflow.json.
  2. Запустите python editorial/workflow.py check sample-article. Для пустой заготовки ожидается код возврата 1, статус unverified-draft и список блокировок в package-report.json. Это ожидаемый результат: содержимое ещё не подготовлено.
  3. Запустите python editorial/workflow.py preview sample-article. Откройте sample-article/preview.html в браузере. Файл создаётся локально и не подтверждает вид темы WordPress.

Если команда не сработала

При отсутствии Python проверьте установленный интерпретатор. Если init сообщил о существующей папке, выберите новое имя, сохранив текущие материалы. Пустой исходник нужно заполнить до проверки готовности.

Возврат

Если заготовка больше не нужна, сначала проверьте её содержимое. Удалять можно только созданную для этого примера папку, если в ней нет нужных материалов. Команды не меняют WordPress.
