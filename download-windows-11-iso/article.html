Оригинальный образ Windows 11 на русском языке можно бесплатно скачать на сайте Microsoft: выберите ISO, затем язык «Русский» и подходящую архитектуру. Для обычного ПК нужен x64, для компьютера с процессором ARM — отдельный образ Arm64. Ещё один официальный способ получить ISO на компьютере с Windows — Media Creation Tool.

Бесплатно предоставляется установочный файл. Для использования Windows нужна подходящая лицензия; загрузка ISO не выдаёт ключ продукта и не активирует систему. Условия активации описаны в справке Microsoft. Установка Windows 11 описана отдельно.

Скачать русский ISO с сайта Microsoft

  1. Откройте официальную страницу «Скачать Windows 11». Номер текущего выпуска указан вверху страницы.
  2. Прокрутите до раздела «Скачивание образа диска Windows 11 (ISO) для 64-разрядных устройств». Не нажимайте кнопку помощника по установке в начале страницы.
  3. Выберите в списке ISO-файл Windows 11 с несколькими выпусками и нажмите «Скачать».
  4. В появившемся разделе «Выберите язык продукта» укажите «Русский» и нажмите «Подтвердить». Русский язык самой веб-страницы не заменяет этот выбор.
  5. Нажмите кнопку загрузки для 64-разрядной системы, выберите место сохранения и дождитесь завершения. Результат — файл с расширением .iso, а не архив с отдельной программой-загрузчиком.

Ссылка, которую создаёт Microsoft, действует 24 часа. Если срок истёк, повторите выбор выпуска и языка, чтобы получить новую. Не сохраняйте такую ссылку как постоянный адрес загрузки.

Образ содержит несколько редакций. Для переустановки выбирайте редакцию, соответствующую вашей лицензии: например, лицензия Home не активирует Pro. Корпоративные выпуски и сборки Insider — отдельные варианты загрузки, а не замена обычному образу для домашнего ПК.

Если нужен образ Arm64

Перейдите на официальную страницу Windows 11 для ПК с процессорами ARM и выполните тот же выбор образа и языка. MCT для Windows 11 создаёт носители x64, поэтому для ARM выбирайте отдельный ISO. Microsoft предупреждает, что для загрузки с установочного носителя на ARM-устройстве могут понадобиться драйверы производителя.

Скачать Media Creation Tool и сохранить ISO

Этот способ рассчитан на работу в Windows; для запуска инструмента нужны права администратора. В браузере на macOS или Linux используйте прямую загрузку ISO. Если нужна только копия инструмента, достаточно первого шага и проверки его подписи.

  1. На странице загрузки Windows 11 найдите раздел «Создание установочного носителя Windows 11» и нажмите «Скачать». Будет сохранён исполняемый файл Media Creation Tool — это ещё не образ Windows.
  2. Проверьте цифровую подпись файла по инструкции ниже, затем запустите программу. Если Windows попросит разрешение администратора, проверьте издателя Microsoft.
  3. Прочитайте лицензионное соглашение. Если согласны с условиями, нажмите «Принять». Если появится выбор действия, укажите «Создать установочный носитель для другого компьютера».
  4. На экране выбора параметров образа укажите русский язык. Если параметры недоступны, снимите флажок использования рекомендуемых параметров для этого компьютера, затем выберите язык и продолжите. Это особенно важно, когда скачиваете образ для другого ПК.
  5. При выборе носителя отметьте «ISO-файл». Для этой задачи не выбирайте USB-накопитель: запись на него удаляет содержимое выбранного устройства.
  6. Укажите папку и имя файла, дождитесь загрузки и создания образа. Когда программа сообщит о завершении, закройте её. Предложение записи DVD использовать не обязательно.

В отличие от прямой загрузки, MCT формирует ISO из скачанных файлов. Поэтому хеш готового образа из MCT не следует сравнивать с хешем готового ISO на веб-странице: это разные файлы. Если вам нужна именно проверка по опубликованной контрольной сумме Microsoft, выберите прямую загрузку.

Чтобы остановить получение образа, отмените загрузку в браузере или закройте MCT через его обычную команду отмены. Получение ISO само по себе не переустанавливает Windows. Ненужный завершённый образ можно удалить как обычный файл; перед этим убедитесь, что он больше не понадобится.

Что делать, если загрузка из России не проходит

Проверяйте, на каком этапе произошёл сбой: не открывается страница Microsoft, не создаётся ссылка на ISO, сервер отказывает в выдаче файла или ошибку показывает MCT. Это разные ситуации. Код 403 означает отказ сервера, но сам по себе не доказывает, что причина связана именно с вашим регионом.

  • Страница открывается, но ссылка не создаётся. Если Microsoft предлагает повторить запрос позже, подождите и попробуйте снова. Запишите сообщение и код ошибки. Если уже используете VPN или прокси, проверьте доступ через другое разрешённое подключение: сервис загрузки может отклонять отдельные адреса.
  • Ссылка получена, а файл не скачивается. Проверьте её срок действия. Получите новую ссылку на той же официальной странице и попробуйте другое доступное подключение. Загрузка самой страницы не подтверждает доступ к серверу, который выдаёт ISO.
  • MCT скачался, но не получает образ. Сначала проверьте свободное место и доступ в интернет, сохраните полный код ошибки. Успешная загрузка .exe не гарантирует работу следующих запросов программы. Прямая загрузка ISO позволяет проверить другой официальный путь.

Работающий способ у другого пользователя не гарантирует результат у вашего провайдера. Rufus/Fido тоже запрашивает ссылки у Microsoft, поэтому его функция загрузки не гарантирует обход отказа сервера. Старые инструкции с Telegram-ботами, Internet Archive, сторонними облаками и скриптами не подтверждают сегодняшнюю доступность официальной загрузки.

Если прямой доступ получить не удалось, можно скачать образ через доступное разрешённое подключение на другом компьютере и перенести файл. Перед использованием сравните его SHA-256 с данными Microsoft для того же выпуска, языка и архитектуры. Не заменяйте оригинальный ISO сборкой с неизвестными изменениями и не отключайте защиту ради загрузчика.

Как проверить скачанные файлы

Контрольная сумма ISO

После завершения прямой загрузки раскройте на странице Microsoft блок «Проверка скачивания». Найдите хеш для русского языка и нужной архитектуры. SHA-256 — контрольная сумма содержимого файла: совпадение с доверенным эталоном показывает, что получены те же данные.

  1. Найдите через поиск Windows программу Windows PowerShell и откройте её. Для чтения доступного вам ISO права администратора обычно не нужны.
  2. Выполните команду, заменив пример на полный путь к своему файлу. Кавычки нужны, если в пути есть пробелы:
Get-FileHash -LiteralPath "C:\ISO\Windows11.iso" -Algorithm SHA256
  1. Дождитесь результата и сравните всю строку в столбце Hash со значением Microsoft. Используйте эталон именно скачанного выпуска: при обновлении образа контрольная сумма меняется.

При несовпадении сначала перепроверьте выпуск, язык, архитектуру и выбранный файл. Если сравниваете один и тот же образ, скачайте его заново. Одно вычисление хеша без сравнения с доверенным эталоном не подтверждает подлинность. Открытие ISO в Проводнике тоже не заменяет эту проверку.

Описание команды: Get-FileHash в документации Microsoft. Для образа из MCT можно сохранить хеш после создания и сравнить с ним копию после переноса — это проверит сохранность копирования, но не заменит эталон Microsoft.

Цифровая подпись Media Creation Tool

Нажмите скачанный файл .exe правой кнопкой мыши, откройте «Свойства» → «Цифровые подписи», выберите подпись Microsoft и нажмите «Сведения». Проверьте, что подпись действительна. Если вкладки нет или проверка сообщает проблему, не запускайте файл до выяснения причины; повторно скачайте инструмент с официальной страницы.

Проверку можно выполнить и в PowerShell:

Get-AuthenticodeSignature -LiteralPath "C:\ISO\MediaCreationTool.exe" | Format-List Status,SignerCertificate

Ожидаемый статус корректно проверенной подписи — Valid, подписант — Microsoft Corporation. Если указан другой статус, посмотрите сведения об ошибке: она может быть связана как с файлом, так и с проверкой сертификата. Команда описана в документации Microsoft. Эта проверка относится к программе, а не к ISO, который она впоследствии создаст.

Что делать после скачивания

Сохраните проверенный образ до подготовки установочного носителя. Для установки следуйте отдельному руководству; для обновления текущей Windows — инструкции по переходу с Windows 10. Не запускайте setup.exe только ради проверки того, что ISO открывается: этот файл начинает сценарий установки.
