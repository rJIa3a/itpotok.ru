Дата сверки: 08.10.2026, Europe/Moscow. Публикация не разрешена; итоговый статус — черновик.

## Реально выполнено

1. На русской странице Microsoft в браузере выбран многоредакционный ISO x64, язык «Русский». Сервис выдал ссылку на домене software.download.prss.microsoft.com. Временная подписанная ссылка сохранена только вне Git-репозитория и не вставляется в материал.
2. На выданную ссылку выполнен HTTP HEAD: ответ 200, Content-Type application/octet-stream, Content-Length 8 748 939 264 байта. Это проверяет ответ сервера и объявленный размер, но не завершённую загрузку содержимого.
3. Раскрыт блок Microsoft «Проверка скачивания», прочитана строка русского x64. В статье нет зафиксированного хеша, чтобы не приписывать его последующим выпускам. Увиденный эталон: 3DD71E8F84BFDC0054E1C4383DB2EAC921D21952AC03B2231CB6E9610A2F7423. Собственного полного ISO для сравнения нет.
4. По кнопке MCT с официальной страницы (go.microsoft.com/fwlink/?linkid=2156295) скачан MediaCreationTool.exe вне репозитория. Размер 21 591 048 байт. Get-AuthenticodeSignature вернул Valid, сертификат Microsoft Corporation. Версия файла 10.0.26100.7019 (ge_release_svc_prod3.251023-1855). Это данные конкретного файла, а не подтверждение выпуска ISO, который он может создать.
5. Сняты русские кадры выбора языка и официального раздела MCT. Внутри статьи это снимки веб-страницы, а не снимки Windows или работающей программы.
6. Проверены опубликованные записи сайта и смежные ID 11476, 11544. Отдельная целевая публикация о скачивании Windows 11 ISO не обнаружена. USB остаётся отдельным черновиком 11989.

## Границы проверки

- Не выполнены полная загрузка ISO и сравнение его хеша, открытие/установка образа, сборка ISO в MCT, загрузка ARM-образа, создание USB или установка Windows.
- Пользователь 08.10.2026 выбрал продолжение без запуска MCT. Повторно не запускать его ради этой задачи. Собственные кадры экранов выбора языка/ISO внутри MCT отсутствуют; план и ограничение зафиксированы в illustrations.md.
- Ранее инициированный запуск MCT не дал целевого окна. Экраны программы, лицензионное соглашение и повышение прав не проходились. Испытание MCT не засчитывается.
- Тип маршрута текущего подключения и доступность из сетей разных российских провайдеров не установлены. VPN/прокси не переключались. Успех получения ссылки и MCT относится только к текущему подключению. Нет заявления «из РФ без VPN проверено».
- Не проверены обходы через Telegram, Internet Archive, облачные посредники, Fido/Rufus и сторонние скрипты. Они не представлены как работающие способы на дату статьи. Смена разрешённого подключения описана как диагностика с неопределённым результатом.
- Страница Microsoft на момент чтения называла текущим выпуском 26H2. В читательском тексте номер не зафиксирован; предлагается проверить его на странице. Версия MCT и текст веб-страницы не использованы как доказательство совпадения конкретного выпуска.
- Команды в статье сверены с документацией. Get-AuthenticodeSignature практически выполнен для скачанного MCT; Get-FileHash для полного ISO не выполнен.

## Редакционные исправления относительно распространённых советов

Не обещана бесплатная лицензия. Язык сайта отделён от языка образа. x64 отделён от Arm64 и от общей совместимости. Прямая временная ссылка не опубликована как постоянная. Архивная копия или репутация посредника не названы доказательством оригинальности. Права администратора нужны MCT, но не объявлены обязательными для чтения доступного ISO. Несовпадение хеша MCT с retail ISO не названо повреждением. Проверка exe не подменяет проверку ISO.
