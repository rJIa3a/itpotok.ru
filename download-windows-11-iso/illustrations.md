## Недостающие кадры и исключения

- MCT: русский экран параметров с выбранным языком, экран выбора «ISO-файл». Эти кадры помогли бы найти элементы внутри программы, но собственная съёмка не выполнена. Пользователь прямо выбрал продолжение без запуска MCT 08.10.2026. Иностранного кадра или сгенерированного окна вместо них нет. Шаги сверены с официальной инструкцией; практический прогон не заявлен.
- Свойства MCT / «Цифровые подписи»: полезный дополнительный кадр. Не снят; действительная подпись конкретного .exe подтверждена командой. В статье даны меню и команда, без заявления о проверке окна.
- PowerShell с SHA-256 полного ISO: не снят, полный ISO не скачан. Демонстрационный хеш не выдаётся за контрольную сумму полученного образа.

Чужие кадры конкурентов и старые изображения из usb-research не используются. Непроверенных условий распространения чужого файла в публичном GitHub нет.

## Доказательства сайта

Кадры предпросмотра после загрузки хранятся в assets с именами draft-*.png и описываются в verification.md. Это доказательства проверки шаблона WordPress, не иллюстрации шагов Windows.


08.10.2026 после замечания пользователя встроенный imagegen пересобрал обложку в горизонтальный формат 1672 × 941. Назначено медиа 12018, квадратное медиа 12012 больше не используется. Старый файл сохранён как история исходного варианта, не текущая обложка. На опубликованной странице проверены отображение и центральные объекты. Кадры published-*.png — доказательства публикации.
