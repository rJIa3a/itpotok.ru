# Сверка с itpotok.ru

Дата: 08.10.2026, Москва.

## Как проверено

1. Прямые HTTPS GET к публичному WordPress REST API. Полный каталог: `https://itpotok.ru/wp-json/wp/v2/posts?per_page=100&_fields=id,link,title,slug,date,modified,status&page=N`, четыре страницы, **317 опубликованных записей**. Это весь публичный каталог posts, а не первые 100 результатов поиска.
2. Аналогичный каталог pages: **21 страница**. В нём служебные страницы, старые разделы и карта сайта; отдельные целевые руководства Windows 11 не выявлены.
3. Дополнительный поиск точной фразы «Windows 11» через `/wp-json/wp/v2/posts?search=%22Windows%2011%22&per_page=100`: среди результатов обнаружено руководство о файле подкачки ID 9878 с заголовком для Windows 10.
4. Через API прочитаны названия и H2/H3 16 связанных публикаций: 11541, 11476, 11994, 11544, 11508, 9938, 9935, 9878, 9871, 8727, 8646, 9220, 7434, 7381, 6511, 4511.
5. Дополнительно прочитан текст ID 9878; состояние подготовленных материалов сверено с локальными README четырёх папок статей. Статус публичных публикаций основан на актуальном API.

`published-posts.json` содержит публичные метаданные всех записей. Пароли, авторизованные ответы, приватные черновики и персональные снимки в пакет не входят.

## Границы проверки

- Проверена представленность тем, URL, ID, статус опубликованных записей и структура выбранных статей. Не проведён полный аудит каждой из 317 публикаций.
- Подробный сравнительный разбор всех 17 страниц remontka.pro и технический фактчекинг будущих 14 работ не выполнялись. URL конкурента и показатели сохранены как исходные данные пользователя.
- Частотности не суммировались; источники и период статистики неизвестны. Актуальные позиции сайта и конкурента не проверялись.
- Данные Search Console, Яндекс Вебмастера, Метрики, трафика, ссылок и индексации недоступны в рамках этой проверки. Порядок работ — редакционная рекомендация по исходному спросу, представленности тем и зависимостям.
- Визуальная проверка всех страниц, FAQ и узкого экрана для этой задачи не выполнялась; контент-план не требует изменения WordPress.
- Часть ответов инструмента веб-поиска содержала старую извлечённую версию страницы установки и ошибки доступа к очистке C. Для актуальных статусов и структуры использован прямой GET WordPress API.

## Дополнение: расширенный список

8 октября 2026 года пользователь предоставил расширенный список и затем заменил файл версией с поисковыми запросами. Сверено: 249 строк и 92 разных URL; показатели и URL в двух версиях совпадают. Используется последняя версия с запросами, сохранённая в expanded-source.json.

Каталог из 317 опубликованных записей получен повторно. Прочитаны актуальные H2/H3 ID 11548, 11544, 11476, 9878, 8699, 9903 и 11467. Прямыми HTTPS GET открыты все 92 страницы конкурента, прочитаны заголовки с учётом кодировки; HTTP-статусы и итоговые адреса сохранены в competitor-pages.json. Подробный технический аудит каждого текста не проводился.

По поисковым запросам назначены 82 темы: 66 новых, четыре работы с существующими публикациями, один черновик на завершение, восемь тем в резерве и три покрытые темы. Проверено, что все 249 строк назначены по одному разу, все 92 URL присутствуют, показатели перенесены без изменений. Частотности не суммировались.

Тема определяется запросом: общий запуск диспетчера не подменён возвращением классического интерфейса, обновление Windows 11 не сведено к 24H2, отключение BitLocker не подменено ожиданием активации. Переименование папки пользователя отделено от отображаемого имени. Неоднозначные фразы отмечены в расширенном плане. Границы проверки и назначения — expanded-content-plan.md.
