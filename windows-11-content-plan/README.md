# Контент-план Windows 11

Дата сверки: 8 октября 2026 года (Москва).

Статус: актуален расширенный план по последнему файлу пользователя с поисковыми запросами: 249 строк, 92 страницы конкурента, 82 темы. Рекомендация: 66 новых тем, четыре работы с существующими публикациями, завершение одного черновика, восемь тем в резерве. Три темы уже покрыты. Сверены 317 опубликованных записей itpotok.ru через публичный WordPress REST API; ранее проверен каталог из 21 страницы.

- [Актуальный расширенный план](expanded-content-plan.md): все 82 темы, приоритеты, существующие страницы, ссылки конкурента и назначение всех 249 запросов.
- [Выполнение плана](execution.md): правило названий чатов, порядок работ и созданные чаты материалов.
- [Исходные данные расширенного списка](expanded-source.json): запросы, показатели и ссылки из последнего файла пользователя. Ранее отправленный файл без запросов заменён уточнённым вводом.
- [Распределение запросов по темам](expanded-topics.json): соответствие каждой строки, целевые URL и редакционные решения.
- [Проверка страниц конкурента](competitor-pages.json): названия, адреса и статусы ответов всех 92 страниц.
- [Предыдущий план по 28 запросам](content-plan.md) и [его исходные данные](queries.json): сохранены как отдельный ранний набор, не заменяют актуальный расширенный план.
- [Сверка сайта](site-check.md): метод, ссылки, пересечения и границы проверки.
- [Снимок каталога публикаций](published-posts.json): публичные метаданные на дату сверки.
- [Ветка GitHub](https://github.com/rJIa3a/itpotok.ru/tree/editorial/windows-11-content-plan-20261008/windows-11-content-plan).

План не подтверждает текущие поисковые позиции, трафик и техническую точность всех старых руководств.
