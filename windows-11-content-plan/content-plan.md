## Пересечения и внутренние ссылки

- BIOS/UEFI → Secure Boot → системные требования → установка.
- Установка → существующий черновик USB → диагностика Media Creation Tool. Черновик USB 11989 не считать опубликованной статьёй; состояние известно из его README от 04.10.2026.
- Установка ↔ сброс ↔ безопасный режим. Основные шаги каждого сценария должны находиться на его целевой странице.
- Очистка C → удаление приложений и файл подкачки. В общей очистке достаточно краткого объяснения и ссылки на подробности.
- Имя пользователя → настройки входа. Отличать имя, пароль, PIN и папку профиля.
- Брандмауэр ↔ Defender. Ссылки допустимы как пояснение разных компонентов защиты.
- В новых статьях для Windows 11 дать ссылки на материалы для Windows 10 там, где это помогает читателю выбрать свою версию. Старые URL сохранять.

В каталоге уже есть две статьи с одинаковым названием про отключение пароля Windows 10 и две близкие страницы о командной строке Windows 10. Их возможное объединение — отдельная задача: перед изменением нужны данные о трафике, ссылках и выбранной целевой записи. Сам план не является разрешением на перенос URL или удаление страниц.

## Порядок выпуска

1. Первая очередь: брандмауэр, BIOS/UEFI, обновление файла подкачки, сброс.
2. Вторая очередь: командная строка, безопасный режим, имя пользователя, удаление приложений.
3. Третья очередь: Связь с телефоном, залипание, Secure Boot, ошибка MCT, скрытые папки, автоматический вход.
4. Существующие скриншоты, установка и очистка C: проверить результаты в аналитике и поисковых инструментах после обновлений; повторную полную переработку не назначать без обнаруженного пробела.

Это очереди работ, а не календарные обещания. Secure Boot зависит от подготовки подходящего тестового устройства; ошибка MCT — от точного сценария и подтверждения способов. Короткие инструкции про залипание и скрытые папки можно готовить между более сложными материалами, сохраняя порядок приоритетов.

Для каждой будущей статьи: проверить первичные источники, подготовить реальные русские кадры, сохранить полный пакет в отдельной папке и ветке, загрузить проверенный черновик WordPress. Публикация требует отдельного прямого поручения пользователя.
