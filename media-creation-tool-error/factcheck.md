# Фактчекинг

Дата сверки: 16.10.2026. Маркер и частотность 840 взяты из строки 20 expanded-content-plan.md проекта; частотность самостоятельно не измерялась.

## Проверка дублей

WordPress REST: поиск опубликованных записей по «0xc1900500» — пустой результат; по «Media Creation» — смежные записи 11989 (USB), 12015 (ISO), 11544 (обновление), 11476 (установка), 8770 и 8685 (Windows 10). По общей фразе найдены нерелевантные руководства, отдельного совпадающего заголовка нет. В плане тема отмечена новой. Создаётся новая запись; существующие ID и URL не меняются. Архивирование исходной опубликованной версии не требуется.

## Первичные источники и выводы

1. [Microsoft: Скачать Windows 11](https://www.microsoft.com/ru-ru/software-download/windows11). Прочитана веб-инструментом и открыта в браузере. В текущем заголовке — 26H2. Подтверждены разные разделы помощника, MCT и прямого ISO, права администратора для MCT, носители x64, отдельный Arm64 ISO, USB от 8 ГБ с удалением данных, выбор языка и ограниченный срок ссылки. В браузере пройден выбор многоредакционного ISO до языка «Русский»; многогигабайтный ISO не скачивался. Нельзя обещать доступ для любой сети или региона. Текст страницы может содержать обобщённые шаги для нескольких поколений MCT; точные экраны мастера не воспроизводились.
2. [Microsoft: Windows 11 Arm64 ISO](https://www.microsoft.com/ru-ru/software-download/windows11arm64). Ссылка подтверждена непосредственно на основной официальной странице; архитектуры не смешиваются.
3. [Microsoft: обновление TLS/WinHTTP](https://support.microsoft.com/en-us/topic/update-to-enable-tls-1-1-and-tls-1-2-as-default-secure-protocols-in-winhttp-in-windows-c4bd73d2-31d7-761e-0178-11268bb10392). Это материал о старых системах, не доказательство причины 0xc1900500 в Windows 11. Правка TLS/реестра в руководство не включена.
4. [Microsoft Learn: журналы обновления](https://learn.microsoft.com/en-us/windows/deployment/upgrade/log-files) и [расположение журналов](https://learn.microsoft.com/en-us/troubleshoot/windows-client/setup-upgrade-and-drivers/windows-setup-log-file-locations). setupact.log/setuperr.log и Panther относятся к этапам установки, не обещаются при раннем отказе MCT. Не предлагается удалять журналы или запускать SetupDiag без начала установки.
5. [Microsoft: условия скриншотов](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions). Полные кадры, без изменения интерфейса, с требуемой атрибуцией и активным источником; собственные снимки русской страницы.

## Код ошибки: степень уверенности

Официальной нормативной расшифровки 0xc1900500 — 0x20000 и универсального исправления в изученных документах не найдено. Нельзя интерпретировать отсутствие найденной справки как доказательство отсутствия внутреннего значения кода. Требования Microsoft (администратор, сеть, место, подходящий носитель) подтверждены, но не объявлены установленными причинами конкретного случая.

На Microsoft Q&A есть сообщения с этим кодом: https://learn.microsoft.com/en-us/answers/questions/5966843/how-to-solve-the-error-0xc1900500-0x20000 и https://learn.microsoft.com/en-us/answers/questions/5618975/i-have-problems-with-media-creation-tool . Ответы Independent Advisor не являются бюллетенями разработчика. Предложения отключить антивирус/VPN и включить TLS 1.1 не перенесены в статью как подтверждённое лечение. Региональная причина из пользовательского вопроса также не принята за установленную.

## Конкурент

[remontka.pro](https://remontka.pro/0xc1900500-0x20000-media-creation-tool/) прочитан. Основной текст: работа MCT 25H2 после CountryCode RU→US в CBS с изменением владельца и разрешений, возврат значения после использования. Автор оговаривает демонстрационный характер и неизвестность серверной причины. Сильное: конкретное наблюдение и предупреждение о правах. Пробел: читатель может принять локальный опыт за универсальный диагноз, а возврат значения не отменяет смену ACL. В нашем материале нет пошагового захвата прав CBS, Telegram-ботов и непроверенных постоянных прямых ссылок. Вместо этого — официальная загрузка, версии, диагностика по этапу, варианты ISO/USB. Формулировки и порядок разделов написаны самостоятельно.

## Практические границы

Существующая локальная копия iso-research/MediaCreationTool.exe имеет FileVersion 10.0.26100.7019. Попытка открыть её через штатный Computer Use завершилась тайм-аутом launch_app; последующий список окон не содержит MCT. Ошибка 0xc1900500 не воспроизведена, работа мастера и создание носителя не проверены. Настройки защиты, TLS, CountryCode и права реестра не менялись. Два кадра статьи показывают официальный веб-интерфейс загрузки, не Windows и не работающий MCT. Отдельный кадр ошибки не получен и не имитируется.
