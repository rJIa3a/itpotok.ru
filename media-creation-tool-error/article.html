Если Media Creation Tool сообщает «По неизвестной причине запуск этого средства на вашем компьютере не удался», сначала запишите полный код ошибки и скачайте свежую копию средства с сайта Microsoft. Для получения Windows 11 необязательно добиваться запуска MCT: официальный ISO можно скачать прямо в браузере. Код 0xc1900500 — 0x20000 сам по себе не доказывает ни повреждение Windows, ни блокировку антивирусом.

Уточните, какое средство и на каком этапе не работает

Одинаковая фраза сопровождает разные ошибки. Сверьте обе части кода: например, 0x80072F8F — 0x20000 — это другой код, и советы для него нельзя автоматически переносить на 0xc1900500 — 0x20000.

Media Creation Tool создаёт установочный носитель или ISO. «Помощник по установке Windows 11» — другая программа для обновления текущего компьютера. Средства для Windows 10 и Windows 11 также не взаимозаменяемы: выбирайте загрузку именно на странице нужной системы.

Проверьте файл и условия запуска

  1. Закройте окно ошибки и откройте страницу загрузки Windows 11 Microsoft. В разделе «Создание установочного носителя Windows 11» нажмите «Скачать». Кнопка в разделе помощника выше загружает другую программу.
  2. Дождитесь окончания загрузки. Нажмите файл правой кнопкой мыши → «Свойства». На вкладке «Подробно» запишите версию файла. Если есть вкладка «Цифровые подписи», проверьте подпись Microsoft; при недействительной подписи не запускайте файл и скачайте его заново с официальной страницы.
  3. Запустите средство с правами администратора. Microsoft прямо указывает это требование. Если это рабочий компьютер и таких прав нет, обратитесь к администратору.
  4. Проверьте, открывается ли официальный сайт, и достаточно ли места там, куда планируется загрузка. Если ошибка повторяется, попробуйте прямой ISO по инструкции ниже. Открытие страницы ещё не доказывает доступность всех серверов загрузки.

Если новая копия доходит до выбора языка или носителя, ошибка раннего запуска больше не повторяется в этой попытке. Это ещё не означает, что скачивание и запись завершатся успешно. Повторный запуск не требует отката настроек; ненужную копию загрузчика можно удалить после закрытия программы.

Почему важны версия Windows и версия MCT

В описаниях ошибки с изменением CountryCode чаще фигурирует средство для Windows 11 25H2. На момент проверки, 16 октября 2026 года, официальная русская страница Microsoft предлагает Windows 11 26H2. Результат, полученный с одной версией загрузчика, нельзя считать проверкой другой. Смотрите версию самого EXE, а не только имя файла.

Для носителя Windows 11 Microsoft указывает архитектуру x64. Для компьютера с Arm64 предусмотрена отдельная официальная страница ISO. Создание носителя и совместимость компьютера, на который затем будет установлена система, — разные вопросы: полученный ISO не отменяет требования Windows 11.

Советы для Windows 7 и старых средств Windows 10 часто касаются TLS — протокола защищённого соединения. У Microsoft есть отдельное обновление WinHTTP для старых систем. Это не подтверждение, что на Windows 11 нужно включать устаревшие протоколы или применять тот же рецепт. Для получения носителя используйте актуальную поддерживаемую Windows либо прямую загрузку ISO.

Что известно о 0xc1900500 — 0x20000 и CountryCode

В материале remontka.pro описан опыт запуска MCT для Windows 11 25H2 после замены CountryCode с RU на US в разделе HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Component Based Servicing. Для записи автор менял владельца и разрешения раздела. Сам автор оставляет открытым вопрос, связана ли ошибка с ограничением Microsoft или с серверной недоработкой.

Это наблюдение для определённых условий, а не документированная Microsoft расшифровка кода. В изученной официальной документации нет подтверждения, что смена CountryCode устраняет все случаи этой ошибки. Даже успешный повторный запуск после изменения не устанавливает единственную причину каждого похожего сбоя.

Поэтому менять владельца системного раздела и выдавать себе полный доступ ради скачивания образа не требуется: сначала используйте официальный ISO. Если вы уже меняли CountryCode, одного возврата значения недостаточно для отмены всех действий — отдельно могли измениться владелец и разрешения. Возвращайте их по сохранённым исходным данным; без таких данных лучше обратиться к администратору, чем назначать разрешения наугад.

Скачайте официальный ISO без Media Creation Tool

  1. На странице Microsoft прокрутите до раздела «Скачивание образа диска Windows 11 (ISO) для 64-разрядных устройств».
  2. Выберите многоредакционный ISO Windows 11 и нажмите «Скачать».
  3. Выберите «Русский» и нажмите «Подтвердить». Для обновления с сохранением приложений язык образа должен соответствовать языку установленной системы.
  4. Скачайте образ по появившейся ссылке. Microsoft ограничивает срок действия создаваемых ссылок; если ссылка истекла, получите новую на той же странице.
  5. Проверьте окончание загрузки. Если Microsoft показывает контрольную сумму для выбранного образа, сравните её с SHA-256 скачанного файла. Подробные шаги — в руководстве как скачать и проверить Windows 11 ISO.

Прямая загрузка обходит использование программы MCT, но не гарантирует доступ при ограничениях самого сервиса или сети. Если сайт отказывает в выдаче ссылки, запишите его отдельное сообщение и код, повторите позже или обратитесь в поддержку Microsoft. Не считайте сообщение браузера тем же сбоем, что код в окне MCT, и не используйте чужую устаревшую временную ссылку как постоянный источник.

Создайте флешку или используйте другой компьютер

Сам скачанный ISO — ещё не загрузочная флешка: обычное копирование файла на USB не заменяет запись установочного носителя. Следуйте руководству по созданию флешки Windows 11, где разобрана запись официального образа через Rufus. Rufus — сторонняя программа; источник Windows при этом остаётся официальным.

Если нужен именно штатный инструмент Microsoft, запустите свежую копию MCT на другом подходящем компьютере с Windows и создайте носитель там. Подготовьте пустой USB-накопитель не менее 8 ГБ и заранее сохраните с него файлы: средство удаляет содержимое. После завершения убедитесь, что программа сообщила о готовности. Окончательная проверка загрузки выполняется на целевом ПК через его меню загрузки; для неё не нужно начинать установку и удалять разделы диска.

Если USB больше не нужен как установочный, его можно впоследствии отформатировать для обычных файлов. Это не восстановит данные, удалённые при создании носителя: они возвращаются только из заранее сделанной копии.

Если ошибка повторяется: соберите признаки, а не меняйте всё подряд

Запишите полный код, время попытки, версию Windows и MCT, архитектуру компьютера и точный этап сбоя. Для Windows откройте «Параметры» → «Система» → «О системе»; название страницы может отличаться в разных выпусках. Сравните две попытки: тот же файл через другое разрешённое подключение либо свежий файл на другом ПК. Успех в другом окружении сужает поиск, но не доказывает автоматически вину провайдера, региона или антивируса.

Не отключайте защиту только из-за этой фразы. Если защитная программа действительно зарегистрировала блокировку MCT, сохраните название обнаружения, путь и время события и передайте их администратору или поддержке. При отсутствии такого события совет «выключить антивирус» не является установленным решением.

Если началась установка Windows и затем произошёл сбой, Microsoft описывает журналы setupact.log и setuperr.log в C:\$WINDOWS.~BT\Sources\Panther; расположение зависит от этапа. См. журналы установки и обновления. При раннем отказе загрузчика этих файлов может не быть. Не удаляйте журналы до разбора ошибки и не выкладывайте их целиком публично: в них могут находиться пути и сведения об устройстве.
