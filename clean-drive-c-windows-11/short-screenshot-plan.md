Кадр должен показывать именно соответствующее действие, а не соседнюю панель. Сохранять исходное разрешение, предпочтительно PNG без потерь; не увеличивать маленький файл для видимости качества. Перед загрузкой проверять текст при масштабе 100%, затем в шаблоне сайта. Убирать личные данные из области съёмки до сохранения; в GitHub не помещать полный приватный экран.
