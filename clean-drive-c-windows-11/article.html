Чтобы почистить диск C в Windows 11, удалите ненужные временные файлы через «Параметры» → «Система» → «Память» или встроенную программу «Очистка диска». Если этого мало, проверьте крупные личные файлы и установленные приложения. Для регулярной уборки включите «Контроль памяти», предварительно настроив правила удаления. Ниже — порядок действий без сторонних чистильщиков и ручного удаления системных папок.

С чего начать, если на диске C мало места

Откройте «Проводник» → «Этот компьютер» и запишите, сколько свободно на C. Затем посмотрите категории в «Система» → «Память»: это поможет выбрать способ, который даст результат именно на вашем компьютере. В некоторых переводах Windows и справке Microsoft раздел называется «Хранилище».

Не выбирайте всё подряд. Сначала сохраните важные файлы из «Загрузок» и корзины. Удаление через средства очистки не даёт обычной возможности восстановить их из корзины. Освободив достаточно места для своей задачи, остановитесь: удалять дополнительные данные ради максимальной цифры не требуется.

Удалить временные файлы через Параметры

  1. Нажмите Win + I, откройте «Система» → «Память».
  2. Выберите «Временные файлы» и дождитесь расчёта. Набор пунктов и объём зависят от компьютера.
  3. Прочитайте описания и отметьте только то, что больше не нужно. Кэш и эскизы обычно создаются заново по мере работы; диагностические данные могут понадобиться при разборе ошибки.
  4. Проверьте, не выбраны ли «Загрузки», «Корзина» и «Предыдущие установки Windows». Первые два пункта могут содержать ваши файлы; третий разбирается ниже.
  5. Нажмите «Удалить файлы» и дождитесь завершения. Если Windows попросит перезагрузку, сначала сохраните открытые документы.

Другой путь в этом же разделе — «Рекомендации по очистке». Просмотрите предложенные временные файлы, крупные или неиспользуемые файлы и приложения. Сам факт попадания в рекомендации не означает, что файл вам не нужен. Отметьте подходящие элементы и используйте кнопку очистки соответствующей группы.

Обновите сведения о C в «Этот компьютер» и сравните со значением до уборки. Показанная оценка удаления может отличаться от фактической прибавки: система продолжает записывать данные. Порядок штатной очистки описан в справке Microsoft об освобождении места.

Запустить классическую «Очистку диска»

Этот способ удобен, если вы предпочитаете отдельное окно со списком категорий. Утилита cleanmgr применяется и в Windows 11; отдельную программу скачивать не нужно.

  1. Откройте поиск на панели задач, введите «Очистка диска» и запустите найденное приложение. Другой вариант: Win + R → cleanmgr → Enter.
  2. Если появится выбор устройства, укажите C: и нажмите «ОК». Дождитесь анализа.
  3. Выделяйте категории, чтобы читать описание внизу окна. Установите флажки у ненужных данных.
  4. Для дополнительных категорий нажмите «Очистить системные файлы». При запросе подтвердите права администратора, снова выберите C и дождитесь расчёта.
  5. Повторно проверьте флажки, нажмите «ОК» и подтвердите удаление. Не путайте эту кнопку с начальным «ОК» в окне выбора диска.

«Загруженные файлы программ» — не папка «Загрузки». В показанном окне это отдельная категория старых интернет-компонентов. Всегда ориентируйтесь на её описание. Поддержку утилиты и её параметры подтверждает документация Microsoft Learn.

После завершения снова проверьте свободное место на C. Если передумали до подтверждения удаления, нажмите «Отмена». После очистки общей кнопки возврата нет.

Настроить автоматическую уборку — «Контроль памяти»

Контроль памяти работает на системном диске, обычно C. При стандартной настройке он помогает убирать временные файлы при нехватке места; для корзины действует срок хранения. «Загрузки» и облачные файлы не затрагиваются, пока вы не зададите соответствующие правила.

  1. Откройте «Параметры» → «Система» → «Память» → «Контроль памяти».
  2. Включите функцию и выберите частоту запуска: при нехватке места или по расписанию.
  3. Установите срок удаления файлов из корзины. Если рассчитываете восстанавливать недавно удалённые документы, не задавайте слишком короткий срок.
  4. Для «Загрузок» оставьте «Никогда», если не готовы к автоматическому удалению. Это папка личных файлов, а не только временный кэш.
  5. Если присутствуют настройки облачного содержимого, прочитайте их отдельно: перевод файла в состояние «только в сети» влияет на доступ без интернета.
  6. Для немедленной уборки используйте «Запустить Контроль памяти сейчас» после проверки правил.

Убедитесь, что выбранные правила сохранились, а после запуска проверьте свободное место. Для отмены будущей автоматической уборки выключите функцию или измените сроки; уже удалённые файлы это не вернёт. Подробности — в официальном описании контроля памяти.

Удалить Windows.old после обновления

Папка C:\Windows.old может содержать предыдущую установку Windows. Не удаляйте её, если собираетесь вернуться к прежней версии или ещё не проверили нужные файлы старого профиля.

  1. Убедитесь, что новая система, приложения и устройства работают, а нужные документы сохранены отдельно.
  2. Откройте «Система» → «Память» → «Временные файлы» либо «Рекомендации по очистке».
  3. Выберите «Предыдущие установки Windows», если пункт есть, и запустите штатное удаление. Для него нужны права администратора.

Проверка — обновить свободное место на C после завершения. Отменить удаление предыдущей установки нельзя: возможность штатного возврата к ней будет потеряна. По справке Microsoft предыдущая версия обычно удаляется автоматически через десять дней после обновления. Отсутствие пункта само по себе не говорит об ошибке: подходящих данных может не быть.

Источники: удаление предыдущей версии и инструкция Microsoft для Windows.old.

Освободить больше места: приложения, крупные файлы и OneDrive

Удалить ненужные программы и игры

Откройте «Параметры» → «Приложения» → «Установленные приложения». Используйте сортировку по размеру, если она доступна, и фильтр диска C. Размер в списке не всегда отражает все данные программы, поэтому проверяйте и её собственные настройки хранения.

Сохраните проекты, настройки, игровые сохранения и сведения о лицензии. У нужного приложения откройте меню «…» → «Удалить» и пройдите мастер. Если оно не удаляется здесь, проверьте «Панель управления» → «Программы и компоненты». Не стирайте его папку из Program Files вручную.

После удаления проверьте место на C. Вернуть приложение можно установкой из прежнего доверенного источника, но пользовательские данные восстановятся только при наличии копии или синхронизации. См. справку Microsoft об удалении приложений.

Перенести личные файлы на другой диск

В первую очередь просмотрите «Загрузки», «Видео», «Документы» и рабочий стол: там могут оставаться ISO, архивы и большие записи экрана. В режиме «Таблица» сортируйте файлы по столбцу «Размер». Папки этим способом не обязательно сортируются по суммарному объёму — проверяйте их содержимое отдельно.

Для важных данных сначала скопируйте выбранные файлы на другой диск или внешний накопитель, откройте несколько копий и убедитесь, что они читаются. Только затем удаляйте оригиналы с C. Пока они остаются в корзине на этом диске, место полностью не освободится. Проверьте корзину перед её очисткой.

Перенос в другую папку на C не освобождает место на C. Для возврата скопируйте данные обратно, если хватает пространства. Переносить установленную программу как обычную папку нельзя: используйте функцию переноса её установщика или переустановку.

Оставить файлы OneDrive в облаке

Если папка OneDrive расположена на C и файлы уже синхронизированы, нажмите на ненужный локально файл или папку правой кнопкой → «Освободить место». При включённой функции «Файлы по запросу» облачный оригинал остаётся, а локальная копия освобождает диск.

Проверьте значок облака и наличие файла в OneDrive. Для открытия понадобится интернет, и файл снова скачается. Для отмены выберите «Всегда хранить на этом устройстве» и дождитесь загрузки. Обычное «Удалить» в синхронизируемой папке — другая операция: она затрагивает и облачный файл. См. файлы OneDrive по запросу и правила удаления в OneDrive.

Нужно ли удалять hiberfil.sys, pagefile.sys и WinSxS

Это системные данные. Не удаляйте вручную Windows, WinSxS, Installer, Program Files и весь AppData. В них находятся компоненты системы, установленные приложения и пользовательские настройки.

Для хранилища компонентов Microsoft предусматривает штатную очистку, включая DISM. Удаление WinSxS вручную может нарушить загрузку и обновления. Агрессивную команду с /ResetBase не стоит использовать как обычную уборку: она ограничивает удаление установленных обновлений. Для базового руководства достаточно средств выше. Источник — очистка WinSxS в Microsoft Learn.

Файл hiberfil.sys связан с гибернацией; он используется также механизмами быстрого запуска. Если гибернация вам нужна, оставьте его. Если готовы отказаться от неё, откройте поиск → «Терминал» → «Запуск от имени администратора» и выполните:

powercfg /hibernate off

После успешного выполнения гибернация станет недоступна, её файл освободит место; быстрый запуск и гибридный сон также зависят от этого механизма. Это отдельное изменение режима питания, не удаление мусора. Для возврата выполните:

powercfg /hibernate on

Затем проверьте настройки электропитания: нужные режимы могут потребовать отдельного включения. Возвращённый файл снова займёт место. Размер зависит от конфигурации — универсальную прибавку в гигабайтах обещать нельзя. Источники: отключение и включение гибернации, режимы питания.

pagefile.sys — файл подкачки. Его отключение ради свободного места может мешать приложениям при нехватке памяти. Не меняйте его наугад: для этой задачи оставьте системное управление. Назначение файла объясняет Microsoft Learn.

Что делать, если место не освободилось или снова исчезает

  • Удалилось меньше, чем ожидалось. Проверьте именно C и обновите сведения в Проводнике. Не складывайте оценки разных средств очистки: они могут находить одни и те же данные.
  • Временные файлы снова появляются. Небольшой кэш создаётся при обычной работе. Посмотрите, какая категория растёт, и проверьте загрузки браузера, обновления, записи экрана и данные приложений.
  • Список долго рассчитывается или очистка не завершается. Дождитесь окончания активных обновлений, затем перезагрузите ПК и повторите анализ. Не прерывайте обслуживание удалением системных файлов.
  • Папка Temp быстро заполняется файлами .APPX. Microsoft описывает такой случай отдельно: нужно разбирать работу Microsoft Store и обновлений, а не бесконечно повторять уборку. Используйте раздел об этой ошибке в официальном руководстве.
  • Почти всё занимают нужные программы и документы. Очистка кэша не решит нехватку ёмкости. Перенесите данные на другой накопитель или рассмотрите увеличение хранилища.

Ориентируйтесь на свободное место в Проводнике и требования конкретной задачи, например установки игры или обновления. Универсального объёма, который гарантированно освободится на любом ПК, нет. Форматирование C и переустановка Windows для обычной очистки не нужны. Если обращаетесь за помощью, приложите точный текст ошибки или скриншот окна без личных данных.
