# План и происхождение иллюстраций — 07.10.2026

План составлен до загрузки: отдельная обложка; собственный русский кадр cleanmgr для поиска категорий/кнопки системных файлов; желательные кадры временных файлов и правил Контроля памяти. Кадры должны помогать найти конкретное действие, фиксированного количества нет.

Квадратная композиция с полями для обрезки шаблоном. media ID 11995. Фактически назначенную обложку проверять в предпросмотре и после публикации.

## Границы

Первый запуск SystemSettings.exe не предоставил окно. Позже Параметры открыты штатным пунктом «Свойства» в меню «Этот компьютер», просмотрены «Система → Память» и установленное приложение. Окно содержит личные имя, почту и устройство; полный приватный снимок не сохранён. Изменение ширины для скрытия блока аккаунта не подтвердилось. Поэтому дополнительные безопасные кадры «Временные файлы»/«Контроль памяти» не получены. Снимки конкурента не копируются: они показывают частичные панели, условия на сторонние файлы не подтверждены. Поддельные, английские и переведённые генератором интерфейсы не используются. Текстовые шаги сверены с Microsoft; дополнительные реальные кадры остаются желательным улучшением. Основной полезный кадр cleanmgr включён.

Без ретуши и перевода. media 12002. Показывает свободное место на одном ПК, не результат очистки. Использование и атрибуция Microsoft те же, что выше.
