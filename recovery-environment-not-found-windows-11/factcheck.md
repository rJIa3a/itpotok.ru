# Фактчекинг — 2026-10-20
См. sources.json и claims.json. Команды сверены с Microsoft Learn; альтернативы — с Microsoft Support. Инструкции по развёртыванию не выдаются за испытанный универсальный ремонт установленной ОС. /setosimage исключён: не используется в Windows 10 и новее. /target не нужен для работающей ОС. Образ — winre.wim из Windows image, не boot.wim/install.wim переименованием.
Не проверялись на пользовательском ПК: /enable, /disable, /setreimage, перезагрузка, сброс, монтирование WIM, изменение разделов. Прочитанная документация не является практическим прогоном.
