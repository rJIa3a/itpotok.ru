# Карта
- Почему появляется ошибка → проверка /info, развилка Disabled/Enabled/ошибка → C1–C3.
- Disabled → /enable, перечитать состояние, без скачивания → C2.
- Нет образа → источник, совместимость, метаданные и условия /setreimage → C4–C5.
- Разделы/ошибки → не изменять вслепую → C3.
- Проверка → вход без сброса, возврат в Windows → C6.
- Альтернативы → внешний WinRE, ремонт Windows, сброс, переустановка → C7–C9.
Отрывок описывает охват; ввод даёт ответ; таблица сравнивает диагностические признаки.
