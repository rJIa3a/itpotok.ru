# Иллюстрации — 2026-10-20

Все четыре кадра интерфейса сняты редакцией через Computer Use в настоящей русской Windows 11 Pro 26H2, сборка 26300.9711. Полные приватные снимки в репозиторий не включены. Для Параметров сохранена только правая область с нужными настройками; боковая панель с учётной записью обрезана без ретуширования интерфейса, временные полные снимки удалены. На итоговых кадрах нет имён, адресов, лицензий и частных папок. Классическое окно и диалог показывают только общие роли и системные файлы.

1. `images/originals/pointer-size-color-ru.jpg` — после размера/цвета. Выбран цветной стиль, размер 4. Видны четыре стиля, палитра, выбор другого цвета и размер. После проверки восстановлены белый стиль и размер 1.
2. `images/originals/mouse-pointers-scheme-ru.jpg` — после схемы. Видны «По умолчанию (системная)», роли, «Сохранить как…», «По умолчанию», «Обзор…». Это исходное состояние.
3. `images/originals/cursor-file-dialog-ru.jpg` — после применения файлов. Реальный диалог «Обзор», системная папка Cursors, фильтр «Указатели (*.ani, *.cur)». Выделен системный aero_link_il; он не выдаётся за назначенный основной указатель. Для практического назначения затем использован встроенный aero_arrow_l.cur, без скачивания чужих наборов.
4. `images/originals/text-cursor-ru.jpg` — после текстового курсора. Реально включён индикатор, видны цветные метки и толщина. Затем индикатор отключён, толщина возвращена к 1.

Кадры открываются по ссылке на полный загруженный оригинал; подписи и alt описывают фактическое изображение. Аннотированные копии не нужны: названия элементов читаются, места указаны шагами. Дополнительные кадры scheme-black-applied-ru.jpg, scheme-restored-ru.jpg, cursor-cur-applied-ru.jpg — свидетельства прогона, в тело статьи не вставлены.

Обложка `assets/cursor-cover-16x9-20261020.jpg`, 1600×900 — самостоятельная редакционная иллюстрация, встроенный imagegen, не снимок интерфейса. Промпт в cover-prompt.txt. На широком и узком шаблоне значимые элементы видны.

Снимки `evidence/site-*.png` показывают сайт, а не Windows. Внешние скриншоты и файлы конкурента не использованы. Первоначальное ограничение Computer Use устранено после предоставления полного доступа и открытия Параметров штатной ссылкой «Система» из Панели управления.
