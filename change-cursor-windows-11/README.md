Маркер «как поменять курсор на виндовс 11», очень точная частотность 609 — из контент-плана, не измерялась повторно. Дублей Windows 11 не обнаружено при исходной и предпубликационной проверках; смежные статьи Windows 7 ID 3845 и 3642 не изменены. Публикация новой записи не затрагивает их ID/URL.

Актуальный исходник — `article.html`, отрывок — `excerpt.txt`. Факты повторно сверены по открытым Microsoft Support и Microsoft Learn: размер/цвет, схемы и отдельные роли, .cur/.ani, текстовый курсор и индикатор, собственные указатели приложений. Уточнено название «По умолчанию (системная)». Не рекомендуются неизвестные установщики.

Добавлены **четыре собственных русских скриншота** настоящей Windows 11 Pro 26H2, сборка 26300.9711. Личная область учётной записи исключена, временные полные кадры удалены. Обложка 1600×900 создана imagegen; это отдельная редакционная иллюстрация. Происхождение и ограничения — `illustrations.md`.

Практически проверены цветной стиль и размер указателя, чёрная системная схема, назначение встроенного .cur, включение индикатора и изменение толщины текстового курсора. Исходные значения восстановлены. Подробный журнал — `procedure-evidence.md`. Чужие наборы и установщики не запускались. Не проверялись анимация внешнего .ani, новая сохранённая пользовательская схема после повторного входа и все старые сборки Windows 11. Полный повторный прогон всей инструкции не заявляется.

WordPress: сохранённое тело **побайтно совпадает** с `article.html`; отрывок и назначенная обложка совпадают. FAQ штатный `webnavoz_faq`, пять вопросов, данные в самой записи 12130, дополнительного черновика нет. После публикации каждый вопрос раскрыт, ответы сверены. Четыре изображения открыты в увеличении.

Без авторизации: обычный HTTP GET публичного URL → 200, заголовок, четыре изображения и пять FAQ проверены; шорткод и редакторские пометки не видны (`public-check.json`). В браузере с редакционной авторизацией проверены реальный опубликованный шаблон и узкий экран 390×844. Обложка на узком экране около 335×189; горизонтального выхода нет. `evidence/published-*.png` — доказательства сайта, не снимки Windows.
