# Практическая сверка — 2026-10-20

Windows 11 Pro, русский интерфейс, DisplayVersion 26H2, CurrentBuild 26300, UBR 9711. Название Windows 11 Pro прочитано в «О системе»; старое поле ProductName реестра «Windows 10 Pro» не использовано как определение ОС.

1. Параметры открыты штатной ссылкой «Система» Панели управления. Далее «Специальные возможности → Указатель мыши и сенсорный ввод». Исходно белый стиль и размер 1. Выбран четвёртый цветной стиль, показана палитра, размер изменён на 4. Внешний вид указателя изменился немедленно. Возврат: размер 1, белый стиль. Снимок pointer-size-color-ru.jpg сделан при размере 4. Изменение другого пользовательского цвета не выполнялось: использован уже выбранный салатовый.
2. «Панель управления → Все элементы → Мышь → Указатели». Подтверждены названия, роли, «Сохранить как…», «Обзор…», «По умолчанию». Выбрана «Черная (системная)», нажато «Применить», кнопка стала недоступна, курсоры сменились. Затем выбрана «По умолчанию (системная)», нажато «Применить». Системная схема возвращена. Снимки scheme-black-applied-ru.jpg и scheme-restored-ru.jpg.
3. Для «Основной режим» открыт «Обзор», фильтр .ani/.cur, системная папка Cursors. Двойным щелчком выбран aero_arrow_l, реальный файл .cur, нажато «Применить»; изображение роли и размер стрелки изменились. Через «По умолчанию» и «Применить» возвращён обычный указатель. Снимок cursor-cur-applied-ru.jpg. Отдельная новая схема не сохранялась; чужие файлы не скачивались, программы не запускались. .ani подтверждён документацией Microsoft и фильтром диалога; анимация отдельного файла практически не проверена.
4. «Специальные возможности → Текстовый курсор». Исходно индикатор выключен, толщина 1. Индикатор включён: в предварительном просмотре показаны фиолетовые метки. Толщина изменена на 4: вертикальная черта стала толще. Вернута толщина 1, индикатор отключён. Размер/цвет индикатора оставлены исходными. Снимок text-cursor-ru.jpg — включённый индикатор.

Первичный доступ в предыдущем ходе не работал; это устранено. Однако данный прогон не объявляется полным повторным исполнением всех шагов текущей статьи. Не проверены: новая сохранённая схема и её сохранность после повторного входа; анимация внешнего .ani; результат в играх и сторонних редакторах; все старые сборки Windows 11. Читательский текст не содержит утверждения о полном испытании редакцией.
