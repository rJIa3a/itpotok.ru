## Результат

Переработаны три поддерживаемых способа: Центр обновления, Помощник и запуск setup.exe из ISO внутри Windows 10. Исправлена подмена обновления загрузкой с флешки; добавлены подготовка, резервная копия, проверка сохранения программ, ограничения оборудования, проверка результата и возврат. Актуализированы текущий выпуск и поддержка Windows 10/ESU. Внутренние ссылки ведут на 12015 (ISO) и 11989 (Rufus/USB); 11476 не менялась.

Актуальный исходник: article.html. Отрывок: excerpt.txt. Основания: factcheck.md. Редакционная карта и конкурент: editorial.md. План изображений: illustrations.md. Сохранённые ответы и зависимость: faq.md. Идентификаторы: wordpress.json.
