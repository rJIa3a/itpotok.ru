# Иллюстрации

## Обложка

assets/windows-10-to-11-cover-wide-20261009.png — 1672×941, горизонтальная, приблизительно 16:9. Создана встроенным imagegen 09.10.2026, медиа WordPress 12024. Это редакционная иллюстрация, не снимок Windows и не доказательство переноса данных. Исходная генерация сохранена в рабочую папку без изменения.

Промпт: минимальная голубая 3D-иллюстрация перехода с Windows 10 на Windows 11: два монитора с числами 10 и 11, стрелка и папка; горизонтальный формат, безопасные поля, без поддельного интерфейса, логотипов и водяного знака. Использован встроенный инструмент, не CLI.

## План необходимых реальных русских кадров

| Кадр | Что должно быть видно | Статус |
|---|---|---|
| «Проверка работоспособности ПК» | Кнопка проверки, результат и причины несовместимости | Нет безопасного собственного кадра в Windows 10 |
| Центр обновления Windows 10 | Предложение Windows 11 и «Загрузить и установить» | Нет русской тестовой Windows 10 |
| Установщик из ISO | Итоговая редакция и режим сохранения личных файлов и приложений | Нет кадра перехода из Windows 10; установка на рабочем ПК не запускалась |
| Возврат в Windows 11 | Раздел восстановления с доступным возвратом после обновления | Нет системы после тестового перехода |

Доступна Windows 11 Pro 26300. Целевое окно «Параметры» не открылось через Computer Use; PC Health Check не найден в стандартных каталогах установленного приложения. Пользователю задан вопрос о тестовой Windows 10, ответа на момент подготовки нет. Макеты, переведённые английские кадры, кадр чистой установки из смежной статьи и снимки веб-страницы вместо нужного шага не добавлялись.
