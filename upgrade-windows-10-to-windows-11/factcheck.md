## Границы

В доступной среде Windows 11 Pro 26300, а не Windows 10. Открытие «Параметров» через штатный инструмент не дало целевого окна. Установщики, обновление, обход требований, изменение прошивки, резервное копирование и откат не выполнялись. Наличие локального русского ISO из другой задачи не считается испытанием обновления. Фактчекинг по документации и визуальная проверка сайта описаны отдельно.
