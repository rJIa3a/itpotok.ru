Публикация разрешена сообщением пользователя «фактчекинг и публикуй» и выполнена 2026-10-22. Анонимная проверка после публикации: HTTP 200, заголовок, текст, отрывок и назначенная обложка совпадают; четыре штатных ответа FAQ присутствуют, шорткод не виден, оба изображения доступны. Доказательства — publication-check.json. Визуальное раскрытие FAQ и узкий экран остаются непроверенными.
