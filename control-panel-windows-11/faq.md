# FAQ

Штатный webnavoz_faq. Источник данных — сама запись 12155. Отдельной зависимости нет. Поля прочитаны обратно.

## Есть ли отдельное сочетание клавиш для Панели управления?

В руководстве используется сочетание Win + R для окна «Выполнить», затем команда control. Win + I открывает другое приложение — «Параметры».

## Нужно ли скачивать Панель управления отдельно?

Для описанных способов скачивание не требуется: используется встроенный компонент Windows. Не устанавливайте стороннюю программу с похожим названием ради доступа к системным настройкам.

## Почему в Панели управления не видно все приложения?

«Программы и компоненты» предназначены прежде всего для классических программ. Для других приложений откройте «Параметры» → «Приложения» → «Установленные приложения».

## Можно ли вернуть прежний вид списка?

Да. В правом верхнем углу выберите нужный вариант в списке «Просмотр»: «Категория», «Крупные значки» или «Мелкие значки». Если введён поисковый запрос, сначала очистите его.
