# Исследование, 2026-10-21

Конкурент прочитан: поиск, Выполнить, ярлык, закрепление, дополнительные способы. Сильная сторона — несколько доступных входов. Своя структура переносит акцент на результат: отличие от Параметров, виды отображения, поиск элемента и переходы после обновлений. Не добавлены реестр, God Mode и повтор команды отдельными большими разделами.

Microsoft Support RU переводит control как «элемент управления»; английский оригинал однозначно указывает control. В тексте сохранена латинская команда. Microsoft Learn содержит исторические примеры Vista/8.1; использован синтаксис, а не предположение о неизменности всех апплетов Windows 11. Набор элементов зависит от компонентов и оборудования.
