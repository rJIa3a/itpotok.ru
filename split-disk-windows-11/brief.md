# Бриф

Маркер: «как разделить диск на виндовс 11». Очень точная частотность из плана — 603; регион и дата измерения неизвестны, это не прогноз трафика.
Формат: manual. Аудитория: пользователь установленной Windows 11, которому нужен ещё один локальный том на существующем SSD/HDD.
Результат: исходный том уменьшен; в освободившейся области создан NTFS-том со свободной буквой; файлы доступны.
Границы: базовый исправный диск, существующий NTFS; без изменения реальных дисков пользователя, команд DiskPart, удаления существующих данных, переустановки и сторонних программ.
План: windows-11-content-plan/expanded-content-plan.md, тема 25.
Конкуренты: https://remontka.pro/split-disk-windows-11/ и https://remontka.pro/run-disk-management-windows/.
Публичный каталог и авторизованные записи проверяются в duplicate-check.json. Смежные записи 3214 и 3089 посвящены Windows 7; не являются руководством Windows 11. Новый материал не заменяет их URL.
Критерии: резервная копия, ключ BitLocker и сохранение EFI/Recovery до шагов; различие размера сжатия и остатка; создание только в нераспределённой области; буква, NTFS, проверка и условная отмена.
