# Структура

Отрывок: охват и польза, без пересказа ответа.
Начало → основной маршрут и развилка при готовой области → C1 C2.
Подготовка → копия, тип диска, ключ и системные разделы до шагов → C3 C4 C5 C6.
Открытие и выбор → физический диск, том и исходное состояние → C1 C6.
Сжатие → размер операции, остаток, результат → C2 C7.
Создание → новая область, буква, NTFS и проверка мастера → C1 C8.
Проверка → Проводник, тестовый файл, старые файлы → C1 C3 C8.
Диагностика → неперемещаемые файлы, RAW, неподходящая разметка → C6 C7.
Возврат → соседство, копия и потеря данных при удалении → C9.
FAQ → SSD, программа, занятая D:, удаление исходного тома, резервная копия.
