# Исследование и фактчекинг — 2026-10-29

Источники открыты через web, URL и ограничения в sources.json.

## Решение по официальной позиции
S1 прямо запрещает старый workaround в Windows 10 и новее. Не представлять советы независимых консультантов Microsoft Q&A как политику компании. Не утверждать, что Microsoft публикует отдельную поддерживаемую команду переименования Windows 11. Комбинация S2/S3 подтверждает создание нового профиля и перенос; это редакционно выбранный путь вместо старого workaround.

## Конкурент
Страница 2023-01-17 прочитана 2026-10-29. Сильная сторона: различает отображаемое имя и папку, предлагает новый локальный профиль. Пробел для этой темы: рискованный рецепт оставлен как последовательность действий; недостаточно операционных проверок до удаления старого профиля. Наш материал не копирует структуру смены имени и не повторяет реестровый рецепт. Добавлены отдельные проверки пути, копии, OneDrive, приложений и возврата.

## Границы
Создание/миграция профиля не выполнялись. Рабочий профиль пользователя не менялся. Имена кнопок сверены с официальной процедурой; русские кадры пока не получены. Нет гарантии точного имени папки при конфликте, поэтому обязательна проверка до копирования. EFS/корпоративные доступы не переносились. Привязка одного Microsoft account между двумя профилями не воспроизводилась.


Дополнение: русские кадры получены 2026-10-29 на предварительной сборке Windows 11 26H2 26300.9711. Создание не завершалось. Полного прогона и rerun нет. На форме наблюдалось прямое открытие локального создания после Add account; текст дополнен условием. Первоначальная временная занятость инструмента устранена.
