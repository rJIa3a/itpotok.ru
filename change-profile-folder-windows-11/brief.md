# Бриф

Ключ: как переименовать папку пользователя в windows 11. Очень точная частотность: 482 (план проекта, не собственное измерение).
Конкурент: https://remontka.pro/change-user-name-windows/
Формат: manual. Аудитория: пользователь личного ПК Windows 11. Результат: новый профиль с проверенным нужным путём и перенесёнными личными данными.
Границы: не менять действующий профиль этого ПК; не давать рецепт ProfileImagePath; корпоративные ПК — к администратору.
Поиск REST 2026-10-29: отдельной записи по папке не найдено. 12073 /change-user-name-windows-11/ — другое намерение, отображаемое имя. Windows 10: 9938, другое поколение. Новая запись, существующие не изменяются. Полный безопасный результат поиска — site-search.json.
Критерии: документированные условия, копия и второй доступ до изменений, приложения/OneDrive/Store, фактический путь до копирования, возврат до удаления. Для ready нужны настоящие русские кадры и тестовая среда.
