# Бриф

Маркер: «как поменять днс сервер на виндовс 11», очень точная частотность 574 по заданию. Формат manual. Аудитория — домашний пользователь Windows 11; задача — задать DNS своему подключению, проверить сохранение и разрешение имён, вернуть исходное состояние.

Конкурент: https://remontka.pro/change-dns-server-windows-11/ (обновлён 26.03.2026). Проверка дублей WordPress 22.10.2026: поиски DNS, днс, сервер, status=any, до 100 результатов на запрос. Отдельной подходящей записи Windows 11 нет; старые материалы Windows 8/7/XP не обновлялись. Новый slug change-dns-server-windows-11.

Границы: Параметры и классический адаптер, IPv4/IPv6, DoH, диагностика, кэш и возврат. Сетевые настройки компьютера пользователя не менять. Не обещать ускорение тарифа и обход ограничений. Роутер/браузер объяснить как отдельные настройки. Команды изменения сети не добавлять ради количества способов.

Критерии: корректные первоисточники, разные функции отрывка и начала, реальные русские кадры важных окон, обложка 16:9, штатный FAQ самой записи, черновик WordPress, шаблон desktop/mobile, GitHub. Без реальных кадров и практики не ставить ready.
