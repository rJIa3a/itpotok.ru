# Фактчекинг

Дата: 22.10.2026. Следующая плановая сверка изменчивых адресов/интерфейса: 21.01.2027, раньше при изменениях Windows или провайдера.

Первичные основания: sources.json; атомарный реестр и места текста: claims.json. Все 16 URL открыты, source-check.json хранит HTTP. Конкурент используется только для анализа читательской задачи, не как замена документации.

Проверены обе пары IPv4/IPv6 Cloudflare и Google, оба DoH URL, разница DNS assignment/IP assignment, ручное/автоматическое назначение, свойства IPv4/IPv6, область адаптера/браузера/роутера/VPN, смысл ipconfig /all, /flushdns и второго аргумента nslookup. nslookup не объявлен доказательством DoH. Unknown отделён от тайм-аута. Отсутствуют обещания ускорения интернета и универсального обхода ограничений.

Исправление источника: ошибка русского перевода Microsoft для DoH Off не перенесена в текст. Интерфейс S15 относится к Server; сравнение старых режимов не выдано за практику W11. Пример Google для W10 не выдан за собственный снимок W11.

Не проводились: сохранение другого DNS, применение DoH, контроль трафика, очистка кэша, проверка изменения/отмены на тестовой машине. На пользовательском ПК сетевые параметры не изменялись. Только документационная сверка не делает мануал practically verified.
