# Карта объяснения

- Начало: основной путь смены DNS; C1.
- Подготовка: функция и пределы DNS, старые настройки, организация, VPN, область действия; C2–C4.
- Адреса: две пары, IPv4/IPv6, независимость транспорта и записи; C5–C7.
- Параметры: выбрать подключение, изменить DNS assignment, сохранить и проверить; C1/C8.
- Классическое окно: нужный адаптер и версия протокола, IP не менять; C9.
- DoH: шифрование, шаблоны и fallback; C10/C11.
- Проверка: конфигурация, ответ утилиты, пределы nslookup, браузер; C12–C14.
- Кэш: когда и что очищает команда; C15.
- Возврат и диагностика: автоматическое/ручное исходное состояние; C16.
- FAQ: роутер, переключение Wi-Fi, IPv6, DoH по одному адресу, Unknown.

Отрывок описывает охват; первый абзац отвечает, где менять; таблица содержит адреса, а не пересказ начала.
