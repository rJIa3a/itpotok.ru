## Нужно ли менять DNS в Windows, если он уже настроен на роутере?

Если компьютер автоматически получает нужный DNS и всё работает, повторять настройку не требуется. Роутер может раздавать клиентам адрес DNS или принимать запросы сам и пересылать их дальше. Проверьте сведения выбранного адаптера; по одному адресу роутера нельзя узнать, к какому внешнему DNS он обращается.

## Почему после смены Wi-Fi используются другие DNS?

Проверьте, для какого подключения сохранены адреса. Настройка отдельной сети Wi-Fi и настройка адаптера имеют разную область действия. Ethernet и VPN также могут иметь собственные DNS. Откройте свойства текущего подключения и сверьте его адреса.

## Нужно ли заполнять IPv6, если я уже указал DNS IPv4?

Если IPv6 используется в вашей сети и вы хотите задать выбранный сервис для обоих протоколов, проверьте и его DNS. При этом DNS-сервер, доступный по IPv4, может возвращать IPv6-адреса сайтов. Отключать IPv6 ради смены DNS не нужно.

## Достаточно ли вписать 1.1.1.1, чтобы включился DoH?

Нет, один IP-адрес не подтверждает шифрование. Откройте режим DNS через HTTPS в Параметрах нужного подключения и проверьте его для основного и альтернативного серверов. Браузерный защищённый DNS настраивается отдельно.

## Почему nslookup показывает Unknown, но возвращает адрес сайта?

У IP-адреса DNS-сервера может отсутствовать обратная запись, по которой утилита определяет его имя. Если запрос вернул адреса домена без тайм-аута, сам сервер ответил. Надпись Unknown сама по себе не означает, что DNS не работает.
