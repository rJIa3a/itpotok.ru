## Конкурент

Доступен; обновлён 26.03.2026. Описывает Параметры, классические свойства и netsh, приводит четыре сервиса DNS. Сильная сторона — короткие шаги с русскими снимками и различение сети Wi-Fi/адаптера. Основные пробелы для нашего материала: нет полного возврата к автоматическому DNS, самостоятельного разбора DoH и его fallback, проверка результата ограничена очисткой кэша. В комментариях видна потребность различить роутер и Windows. Структура и формулировки не копировались. Вместо расширения числа способов выбраны два GUI-пути и проверка результата.

## Расхождения

Русская справка Microsoft Essential Network Settings ошибочно описывает DoH «Выключено» как шифрование через HTTP. Английская версия говорит unencrypted; смысл сверён с S5/S6. В тексте исправлено. В справке Microsoft путь описывает IP assignment и ручные IP-поля. Для изменения только DNS использован отдельный DNS server assignment из официальной инструкции Cloudflare для Windows 11; IP/маску/шлюз не меняем.

Google показывает классический интерфейс на примере Windows 10. Серверная справка Microsoft DoH применяется к Server, поэтому не выдаётся за документированный практический прогон Windows 11. Старые названия DoH приведены как отличие интерфейса, основная инструкция следует актуальным шаблонам и fallback.

## Границы

Смена сетевых адресов, DoH и очистка кэша на компьютере пользователя не выполнялись. Нет вывода о скорости и доступности конкретного резолвера в его сети. Практический прогон должен выполняться отдельно в безопасной тестовой среде.
