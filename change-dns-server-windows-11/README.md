## Честные границы

Редакционная доставка завершена, но доказательный статус мануала **unverified-draft**, не ready: нет полного практического прогона изменения DNS/DoH и возврата, нет русских снимков самих полей DNS и переключателей DoH. Имеется собственный безопасный снимок списка компонентов Ethernet; генератором интерфейс не заменялся. Сетевые параметры компьютера пользователя не менялись. Публикация выполнена по отдельному поручению после сообщения о пробеле с кадрами; это не превращает документационную сверку в практическое испытание.
