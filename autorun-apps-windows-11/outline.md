# Карта объяснения
Начало → прямой ответ: где выключить и где добавить, C1/C3.
Выбор действия → таблица «Ситуация / что использовать / что изменится», без пересказа быстрого ответа.
Параметры → переключатель и его обратное действие, C1.
Диспетчер → список, состояние, влияние; без завершения задачи, C2.
Папки → область действия, отключение сохранением ярлыка, C3.
Добавление → уже отключённая запись или новый ярлык; shell:appsfolder, мастер ярлыка, C1/C3/C4.
Проверка → закрыть приложение, новый вход, задержка, возврат и контроль нужных функций, C5.
Восстановление → отдельная функция входа, C6.
Диагностика → настройки приложения, задания/службы/реестр, C7/C8. Без массового отключения.
FAQ → пустая папка, Program/битый путь, свёрнутый запуск, права администратора, Windows 10.
