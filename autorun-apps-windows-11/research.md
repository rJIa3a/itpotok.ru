# Исследование и фактчекинг — 2026-10-21
Первичные страницы из sources.json открыты по HTTP и прочитаны. Текст Windows сверялся с Microsoft; сайт-конкурент не источник технической истинности. Сверка документации не является практическим испытанием.

## Конкуренты
Отключение, обновлено 14.08.2026: Параметры, новый/старый Диспетчер, настройки приложения, реестр/папка, Autoruns и задания. Добавление, обновлено 15.08.2024: сначала реестр, затем ярлык, повторное включение, параметры приложения/планировщик. Сильные стороны: разные источники автозапуска, старый интерфейс, разбор пропавшего элемента. Пробелы для нашего кластера: нет единой инструкции отключения/добавления; общая папка и возврат ярлыка не раскрыты достаточно; проверку после нового входа и риски для защитных компонентов стоит сделать заметнее. Их структуру и формулировки не копировали.

## Решения и исправления
- Русская Microsoft Support ошибочно переводит литерал shell:common startup как «shell:общий запуск»; сохранена английская команда, сверенная по S7. Обе папки относятся к входу пользователя, не запуску до входа.
- Название нового раздела Диспетчера в справке («Автозагружаемые приложения»), у конкурента («Начальная загрузка приложений») и на внешнем русском кадре различается. Для читателя: «Автозагрузка приложений» и значок спидометра, старая вкладка «Автозагрузка»; версия конкретной локальной сборки не выдаётся за универсальную.
- Статус Включено/Отключено показывает разрешение автозапуска, не состояние процесса. Отключение не описано как принудительное завершение текущего сеанса или удаление программы.
- Высокое влияние — не рекомендация отключить защиту, драйверы, обновления. Нет численных обещаний ускорения.
- Пустая папка Startup не означает отсутствие всех механизмов автозапуска. Службы/задания рассматриваются как отдельная диагностика без массового отключения.
- Не рекомендован реестр новичку: обычные задачи покрываются штатными интерфейсами и ярлыками. StartupApproved не редактируется.
- Для программы с повышением прав нет обещания обхода UAC через общую папку.

## Границы
Собственный полноценный прогон отключения/добавления и возврата в изолированной русской Windows не выполнен. На рабочем компьютере сборка 26300.9711, DisplayVersion 26H2; реестр ProductName сохраняет старую строку Windows 10 Pro. Не делается вывод о коммерческом статусе сборки. SystemSettings не открыл целевое окно; sky несколько раз вернул active request, затем кадры были перекрыты другими окнами и не соответствовали выбранному приложению. Изменения чужой рабочей автозагрузки, выход из сеанса и перезагрузка не проводились. Безопасные UI-кадры подбирались отдельно с источником и условиями; внешние иллюстрации не являются нашим прогоном.
