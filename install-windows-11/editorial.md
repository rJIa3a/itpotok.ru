# Редакционные заметки

Запрос: как установить/переустановить Windows 11. Основное намерение — получить работающую систему и заранее понять судьбу файлов и программ. Читателю нужны разные маршруты для нового SSD, работающей системы и ПК без рабочего стола.

Конкурент: https://remontka.pro/windows-11-install/ (страница доступна, указана дата 10.12.2025). Сильные стороны: подробная последовательность USB-установки, иллюстрации установщика, варианты разметки и разбор ошибок. Наш материал не воспроизводит его порядок: сначала выбор по сохраняемым данным, затем подготовка и основной путь с флешки; восстановление и сброс идут после него. Добавлены чёткое отличие запуска setup.exe от USB-загрузки, проверка копии, BitLocker, ограничения отката, безопасное определение физического диска и контроль результата. Обход TPM не представлен как поддерживаемая установка. Обгон в поиске не обещается.

На сайте найдена единственная непосредственно соответствующая опубликованная запись ID 11476: https://itpotok.ru/how-to-install-windows-11/. Отдельная статья ID 11544 об обновлении Windows 10 имеет смежное, но иное намерение. Подготовлен черновик обновления 11926; опубликованную запись не редактировали. При будущем переносе сохранить ID 11476 и URL.

Исходная версия 11476 зафиксирована в коммите f20d5d0 и отправлена в GitHub до подготовки нового текста. В рабочем дереве один текущий article.html; старый текст доступен через Git.

Отрывок описывает пользу руководства. Быстрый ответ расположен один раз в теле. Таблица сравнивает задачи и сохранение данных. При проверке сайта обнаружено, что тема изменяет ID заголовков, добавляя -2; якоря таблицы вынесены в отдельные div перед заголовками.
