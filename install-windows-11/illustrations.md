## Собственный кадр после доработки

windows-11-recovery-settings-20261002.png, 919×198: реальный русскоязычный интерфейс «Параметров» Windows 11, снят 02.10.2026. Показывает строки переустановки через Центр обновления и сброса; не показывает выполнение операций. Сохранён только фрагмент без боковой панели аккаунта, личных данных и уведомления. Полный временный снимок удалён вне репозитория. Итоговый кадр принадлежит редакции, разрешён для GitHub. В черновике подключён через raw.githubusercontent.com; перед публикацией предпочтительно перенести в медиатеку сайта.

Ранее указанное отсутствие управления Windows уточнено: удалось открыть параметры через Computer Use и снять безопасный кадр. Кадров Media Creation Tool и выбора разделов в тестовой VM пока нет. Установка не выполнялась.
