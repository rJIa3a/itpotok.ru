## Происхождение и условия

Семь внешних кадров: Digi-Keys, https://digi-keys.ru/articles/poshagovaya-instruktsiya-po-ustanovke-windows-11/ , публикация 08.09.2022. Фактическая дата кадра и сборка неизвестны; это выпущенная Windows 11 с классическим установщиком/OOBE, не доказательство интерфейса 26H2. Каждый выбранный кадр осмотрен целиком: чистый Microsoft UI, без фотографий монитора, добавленных рамок/стрелок, стороннего содержимого, лиц, учётных данных и водяных знаков. В кадре имени компьютера «User» — видимое обезличенное имя-пример, не имя автора статьи.

Право использования чистых снимков выпущенных продуктов на сайте проверено по официальным Microsoft Copyright Permissions → Screenshots: https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions . Сохранены полный кадр без ретуши/перевода, только масштабирование в шаблоне, атрибуция «Used with permission from Microsoft.» и активная ссылка на источник. Это основание на использование интерфейса Microsoft, не утверждение о разрешении редакции Digi-Keys. Внешние файлы подключены по исходным URL; в GitHub не копировались.

Отвергнутые варианты: фотографии Skillbox (права фотографа отдельно не подтверждены); Digi-Keys 5/6/7/8/16 с добавленными рамками/стрелками (не соответствуют условию Microsoft об отсутствии изменений); английские интерфейсы и кадры предварительной версии до коммерческого выпуска. Эти файлы остались только в исследовательской папке вне репозитория.
