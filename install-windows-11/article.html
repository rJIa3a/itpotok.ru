Ограничения для россиян и белорусов

В 2022 году компания Microsoft сделала заявление о постепенном сокращении бизнеса в России. В настоящее время при попытке загрузить образ Windows 11 с официального сайта у пользователей из РФ или Республики Беларусь могут возникать проблемы. Например, при попытке загрузки ISO-файла может высвечиваться сообщение, что запрос не удаётся выполнить. Существует несколько способов обойти это ограничение: воспользоваться VPN, специальными утилитами или скриптами. Подробнее об этих методах расскажем далее.

Обходим ограничения и скачиваем Windows 11

Несмотря на существующие ограничения, наиболее рациональным вариантом загрузки Windows 11 по-прежнему остаётся официальный сайт. Обойти запреты можно одним из следующих способов.

Воспользоваться VPN

Можно установить браузерное расширение в виде VPN. Для этого необходимо зайти в магазин расширений вашего браузера и ввести в поисковую строку запрос «VPN». В результатах выдачи появятся наиболее популярные среди пользователей расширения. Далее остаётся выбрать подходящее, нажать «Установить». Затем рекомендуется перезапустить браузер, включить VPN и снова зайти на сайт Microsoft. После нажимаем на кнопку «Скачать» и дожидаемся начала загрузки. Далее можно поставить загрузку на паузу, и скопировать ссылку для скачивания и выключить VPN. Далее вставить полученную ссылку в любую программу для загрузки файлов или браузер для обычной загрузки. Утилита Media Creation Tool

Если первый способ не сработал, можно воспользоваться утилитой Media Creation Tool. Для её использования не нужен VPN. Скачивание в программе происходит без каких-либо проблем, и её можно использовать как для создания ISO-образа, так и для установочного накопителя. Если при загрузке утилиты также возникают проблемы, можно воспользоваться способом ниже.

Скрипт Universal Media Creation

Данный скрипт можно использовать как для обновления до Windows 11 на компьютерах, где это поддерживается, так и для загрузки доступных версий Windows 10 и Windows 11. Скрипт скачивается со страницы разработчика в GitHub. Далее нужно распаковать архив, запустить программу (файл MediaCreationTool.bat ), выбрать нужную версию утилиты Media Creation Tool и загрузить её. Далее воспользоваться загруженной утилитой и следовать инструкциям на экране.

Создаем загрузочную флешку с Windows 11

  Для создания загрузочной флешки из-под UEFI следует выполнить следующие действия:
  1. Вставить подходящую флешку в USB-разъем ПК (объём — не менее 8 Гб);
  2. Перейти на официальный сайт Microsoft и скачать соответствующую утилиту:
  1. Запустить утилиту, принять условия пользовательского соглашения, в окне с языком и версией Windows нажать «Далее»(если требуется изменить язык, снимите галочку напротив рекомендуемых параметров):
  1. В следующем окне выбираем вариант «USB-устройство флэш-памяти» и нажимаем «Далее»:
  1. Утилита распознает подключённый к ПК накопитель. Убедитесь, что это именно он, выберите его и нажмите «Далее»:
  1. Дождитесь загрузки дистрибутива и окончания его записи на флешку. О ходе процесса будет сообщать строка, где отображается процент выполнения задачи. В случае успешного завершения процесса программа выведет сообщение, что USB-устройство флэш-памяти создано. Нажмите на кнопку «Готово», чтобы выйти из программы.

Подготовка к установке и загрузка с флешки в БИОС (UEFI)

Перед установкой ОС позаботьтесь о сохранности необходимых файлов и данных. По возможности перенесите их на внешний накопитель. Для загрузки с подготовленного флеш-устройства перезагрузите ПК, воспользовавшись именно кнопкой «Перезагрузка».
Обратите внимание: если просто выключить ПК, а затем включить его, это может создать проблемы при выполнении последующих шагов.
После перезагрузки войдите в БИОС (UEFI) и сделайте флешку с Windows 11 первой в загрузочном списке устройств или воспользуйтесь Boot Menu, где можно выбрать нужное устройство.
Обратите внимание: загрузка должна производиться в UEFI-режиме, (настраивается в БИОС). Если флешка отображается в списке устройств дважды, следует выбирать вариант с пометкой UEFI или EFI.
При поддержке Legacy или UEFI-режима, загрузка по умолчанию может идти в режиме Legacy. В этом случае следует полностью выключить Legacy Support в БИОС, чтобы загрузка наверняка перешла в режим UEFI. При наличии опции безопасной загрузки Secure Boot её рекомендуется активировать (обычно можно найти на вкладке Security). После загрузки с подготовленного USB-устройства в нужном режиме отобразится логотип Windows и откроется программа установки или же появится строка «Press any key to boot from CD or DVD». В этом случае нужно нажать любую кнопку на клавиатуре, чтобы перейти к процессу установки.

Процесс установки Windows 11 на компьютер или ноутбук

Для установки Windows 11 нужно сделать следующее:
  1. В первом окне выбрать язык, формат времени, метод ввода. Вариант по умолчанию — «Русский». Нажмите «Далее», а в следующем окне — «Установить».
  1. При появлении ошибки запуска следует убедиться, что поддержка TPM 2.0 или TPM 1.2 в БИОС включена и не используется режим Legacy для загрузки.
  2. Если установка производится на ПК, где не было ранее ни одной из последних версий Windows, появится окно активации, где нужно будет ввести ключ продукта. Введите его и нажмите «Далее».
Если выбран вариант «У меня нет ключа продукта» в следующем окне будет предложено выбрать редакцию ОС, которую вы хотите установить (домашняя, Pro и др.). Далее нужно согласиться с условиями пользовательского соглашения и перейти непосредственно к установке.
  1. Выбираем вариант установки — обновление или выборочная:
  1. В следующем окне выбираем раздел диска, куда требуется произвести установку. Если имеется несколько накопителей или же на данном ПК уже устанавливалась ранее ОС, количество разделов может быть большим. Для некоторых из них может появляться предупреждение о том, что в выбранный раздел нельзя установить Windows. В этом случае можно отформатировать раздел с ранее установленной режиме UEFI ОС и выбрать его. На фирменных ПК также может быть скрытый раздел объёмом около 10-20 Гб. Как правило, он содержит резервную копию системы — его рекомендуется оставить. для экстренного восстановления, я рекомендую его оставить.
  1. После того, как раздел выбран, начнется установка Windows 11. Будет производиться копирование файлов, их подготовка, установка компонентов и обновлений. По каждому из пунктов будет отображаться процесс готовности. Последний пункт — «Завершение».
  1. После завершения система перезагрузится и перейдёт к этапу первоначальной настройки. Нужно будет выбрать регион, раскладку(по умолчанию — русская для русскоязычной версии ОС). Затем подтвердить выбор.
  1. Далее будет предложено подключиться к Сети или продолжить инсталляцию без подключения к Интернету (ограниченная установка). После этого вводится имя пользователя, пароль, выбрать вариант использования (для работы или учёбы). Затем производится вход под учётной записью Microsoft (при наличии соединения с Интернетом).
  2. На завершающем этапе настраиваются прочие параметры, задаются настройки конфиденциальности, создаётся резервная копию файлов в OneDrive (по желанию).
  3. Далее производится подготовка Windows 11 к первому запуску (может длиться несколько минут). В это время не следует выключать ПК — нужно дождаться завершения процесса.
После этого Windows 11 будет успешно установлена и готова к использованию!
