Установить Windows 11 на новый SSD или переустановить систему с удалением старых данных можно с загрузочной флешки. Если Windows запускается и нужно сохранить программы, начните с восстановления через Центр обновления или запуска setup.exe внутри работающей системы. Сброс с вариантом «Сохранить мои файлы» оставляет личные файлы, но удаляет приложения. Ниже — выбор способа, подготовка и порядок действий.

Речь идёт об обычном личном ПК. На рабочем или учебном устройстве сначала уточните порядок восстановления у администратора. Если проблема появилась после одного обновления, полная переустановка может быть излишней: Microsoft предлагает сначала рассмотреть варианты восстановления.

Что подготовить до начала

  1. Резервную копию на другом накопителе. Скопируйте документы, фото, рабочие проекты, нужные загрузки и локальные сохранения. Откройте несколько файлов из копии. Для облачных папок проверьте завершение синхронизации. Копия на другом разделе того же SSD не защитит от удаления всех его разделов.
  2. Сведения о лицензии. В Windows 11 откройте «Параметры» → «Система» → «Активация», а редакцию Home или Pro посмотрите в «Система» → «О системе». При переустановке нужна редакция, соответствующая лицензии. Замена материнской платы может потребовать отдельной повторной активации.
  3. Ключ восстановления шифрования. Если включён BitLocker или шифрование устройства, сохраните ключ вне переустанавливаемого ПК. Найти его можно по инструкции Microsoft. Сопоставляйте ID ключа; пароль входа в Windows его не заменяет.
  4. Питание, интернет и драйвер сети. Подключите ноутбук к зарядке. Заранее скачайте драйвер Wi-Fi или Ethernet для своей модели с сайта производителя на отдельный носитель. Для первоначальной настройки Windows 11 Home и Pro для личного использования Microsoft требует интернет и учётную запись Microsoft.

Для перехода на Windows 11 проверьте совместимость через «Проверку работоспособности ПК» (PC Health Check). Минимум включает поддерживаемый 64-разрядный процессор, 4 ГБ ОЗУ, накопитель от 64 ГБ, UEFI с поддержкой безопасной загрузки и TPM 2.0. Это минимальные требования, а не обещание комфортной работы. Полный список, включая графику и экран, — на странице Microsoft. Не меняйте режим загрузки работающей системы с Legacy на UEFI наугад.

Основной сценарий с Media Creation Tool ниже предназначен для x64. На ARM-компьютере нужен носитель для ARM64 и инструкции производителя: обычная x64-флешка не подходит. Для обновления Windows 10 без чистой установки есть отдельное руководство.

Переустановка через Центр обновления: сохранить программы

Этот вариант восстанавливает текущую версию Windows 11 с сохранением приложений, документов и параметров. Он подходит, если система загружается, но есть проблемы с её компонентами или обновлениями.

  1. Нажмите Win + I и откройте «Система» → «Восстановление».
  2. Найдите раздел устранения проблем с помощью Центра обновления Windows и нажмите «Переустановить сейчас». Не выбирайте соседний сброс компьютера.
  3. Прочитайте подтверждение. При желании разрешите автоматическую перезагрузку после завершения. Нажмите «ОК».
  4. Дождитесь скачивания и установки версии для восстановления. Оставьте ПК подключённым к интернету и питанию; затем перезагрузите его.

Если пункта нет, проверьте обновления. По справке Microsoft, требуется Windows 11 22H2 или новее с дополнительным обновлением февраля 2024 года либо более поздним. На устройствах с управляемыми обновлениями функция может быть недоступна. Тогда рассмотрите следующий способ.

Переустановка из ISO без загрузки с флешки

Для сохранения установленных программ запускайте установщик из работающей Windows. Загрузка ПК с флешки — другой сценарий.

  1. Скачайте официальный ISO Windows 11 подходящей архитектуры с страницы загрузки. Для сохранения данных выбирайте тот же язык установки системы. Если используете готовый носитель, подключите его, оставаясь на рабочем столе.
  2. Для ISO откройте контекстное меню файла и выберите «Подключить». В Проводнике появится виртуальный диск.
  3. Откройте этот диск либо установочную флешку и запустите setup.exe. Подтвердите запрос администратора и пройдите проверки установщика.
  4. На итоговом экране проверьте, что указано «Сохранить личные файлы и приложения». При необходимости откройте «Изменить выбранные для сохранения компоненты» — название может отличаться.
  5. Только после проверки выбранного режима нажмите «Установить». Компьютер несколько раз перезагрузится.

Если сохранение приложений недоступно, остановитесь до установки. Проверьте язык и редакцию носителя; не соглашайтесь на удаление данных ради продолжения. Вариант «Сохранить только личные файлы» удаляет приложения, а «Ничего» — также личные данные. Доступные режимы описаны в инструкции Microsoft по установке. Новый ISO может обновить версию системы; для восстановления именно текущей версии используйте предыдущий раздел.

Сброс без флешки: оставить файлы, удалить приложения

  1. Откройте «Параметры» → «Система» → «Восстановление» → «Вернуть компьютер в исходное состояние».
  2. Выберите «Сохранить мои файлы» либо «Удалить всё». Первый вариант не сохраняет установленные вами приложения и их настройки.
  3. Выберите «Загрузка из облака» для скачивания копии Windows или «Локальная переустановка» для использования файлов на ПК. При повреждении локальных файлов рассмотрите облачную загрузку.
  4. Проверьте итоговое описание и список удаляемых приложений, если он показан. При полном удалении особенно внимательно прочитайте, какие диски затронут выбранные параметры.
  5. Подтвердите сброс и дождитесь завершения. Длительный чёрный экран сам по себе не означает сбой; не перезапускайте ПК принудительно только из-за него.

Если рабочий стол недоступен, но открывается среда восстановления, выберите «Поиск и устранение неисправностей» → «Вернуть компьютер в исходное состояние». Может понадобиться ключ BitLocker. Сброс переустанавливает уже имеющуюся Windows и не служит способом перехода с Windows 10 на 11. Подробности — в справке по сбросу.

Как создать установочную флешку

Нужен работающий компьютер с интернетом, права администратора и пустая флешка не менее 8 ГБ. Практически удобно взять 16 ГБ или больше. Содержимое выбранной флешки будет удалено.

  1. Откройте «Скачать Windows 11» и найдите «Создание установочного носителя Windows 11». Скачайте Media Creation Tool из этого раздела. «Помощник по установке» предназначен для другого сценария.
  2. Запустите утилиту, прочитайте и примите условия, если согласны. Проверьте предлагаемые язык и выпуск; для другого ПК при необходимости отключите использование рекомендуемых параметров.
  3. Выберите USB-накопитель. Сверьте его букву и объём с Проводником, чтобы не стереть другой носитель.
  4. Дождитесь сообщения о готовности и завершите работу утилиты. Просто скопировать ISO на пустую флешку недостаточно для этого способа.

Microsoft описывает подготовку носителя в отдельной справке. Если загрузка недоступна, не считайте это доказательством, что утилита обязательно заработает из другой сети. Попробуйте позже или подготовьте официальный носитель на другом доступном ПК. Не подменяйте образ случайной «сборкой» и не отключайте защиту ради её запуска.

Чистая установка с флешки на новый или очищаемый диск

Загрузитесь с USB в режиме UEFI

  1. Подключите подготовленную флешку и выключите ПК.
  2. Включите компьютер и вызовите меню выбора загрузочного устройства — Boot Menu. Клавиша зависит от модели; проверьте руководство производителя. Часто используется F12 или Esc.
  3. Выберите флешку; если есть два варианта, используйте вариант UEFI. Если снова открылась старая Windows, загрузка с USB не состоялась.
  4. В установщике выберите язык и раскладку. В современном интерфейсе выберите установку Windows 11 и прочитайте предупреждение об удалении. В старом интерфейсе нужный сценарий может называться «Выборочная установка».

Проверьте лицензию и выберите целевой накопитель

Если установщик спрашивает ключ, введите имеющийся ключ. При повторной установке той же редакции на устройстве с действующей цифровой лицензией можно выбрать «У меня нет ключа продукта». Это не даёт бесплатную лицензию новому компьютеру. Если ключ уже записан в прошивке, окно может не появиться.

Перед удалением разделов определите физический диск. Сверьте его ёмкость и состав разделов с заранее записанными сведениями. Буквы C: и D: в установщике не являются надёжным ориентиром. Номер «Диск 0» тоже не доказывает, что перед вами нужный SSD. Если накопителей несколько и вы не уверены, отмените установку и уточните конфигурацию.

  1. Новый пустой SSD: выберите незанятое пространство нужного диска и нажмите «Далее». Установщик создаст необходимые разделы.
  2. Полная очистка старого системного диска: только после проверки копии удалите разделы на выбранном целевом диске и выберите образовавшееся незанятое пространство. Это удалит также разделы с личными файлами и заводским восстановлением на этом диске. Другие физические диски не трогайте.
  3. Проверьте итоговый экран и начните установку. После перезагрузок не запускайте установку с USB заново: выберите Windows Boot Manager внутреннего накопителя либо верните прежний порядок загрузки.

Здесь описан сценарий с пустым или полностью очищаемым диском. Если нужно оставить раздел с данными на том же SSD, не выполняйте удаление всех разделов по этой инструкции: сначала сделайте отдельную копию и точно определите назначение каждого раздела. Папку Windows.old нельзя считать заменой резервной копии.

Завершите первоначальную настройку

Выберите регион, раскладку и сеть, войдите в учётную запись и прочитайте предлагаемые параметры конфиденциальности. Если предлагается восстановить данные из облачной копии, выбирайте это осознанно. Появление рабочего стола означает завершение основного этапа, но затем нужно проверить обновления, драйверы и активацию.

Если установка не продолжается

  • Флешки нет в Boot Menu. Проверьте её подключение, другой USB-порт и завершение создания носителя. Сверьте режим загрузки с руководством ПК. Не отключайте Secure Boot наугад.
  • «Компьютер не соответствует требованиям». Проверьте результат PC Health Check и настройки TPM по документации производителя. Обход проверки не делает оборудование поддерживаемым: Microsoft не гарантирует обновления на несовместимом ПК.
  • Установщик не видит SSD. На некоторых моделях нужен драйвер контроллера Intel RST/VMD. Скачайте и распакуйте драйвер для своей модели на носитель, выберите «Загрузить драйвер» и укажите папку с драйвером. Пример для поддерживаемых моделей — инструкция Dell. Не меняйте RAID/VMD на AHCI без понимания последствий для существующей системы.
  • Сообщение о MBR/GPT. Проверьте, что флешка загружена в UEFI. Не запускайте команды очистки диска из случайных советов: они могут уничтожить все разделы. Для полностью очищаемого целевого диска используйте описанный выше выбор незанятого пространства; при сохранении разделов остановитесь и разберите разметку отдельно.
  • Нет сети при настройке. Попробуйте Ethernet, если он доступен, либо установите заранее подготовленный драйвер по инструкции производителя. При отсутствии подходящего драйвера подготовьте его на другом ПК.
  • Установка начинается по кругу. Выберите Windows Boot Manager внутреннего диска вместо флешки. Не удаляйте разделы повторно.

Что проверить после переустановки и как вернуться назад

  1. Откройте «Параметры» → «Система» → «Активация». Проверьте статус и редакцию. При проблеме не покупайте ключ сразу: сначала сверьте редакцию с прежней лицензией и проверьте подключение к интернету.
  2. Откройте «Центр обновления Windows», установите доступные обновления и перезагрузите ПК, если требуется.
  3. Проверьте Wi-Fi, звук, камеру и остальные нужные устройства. Недостающие драйверы берите у производителя конкретного ПК или компонента.
  4. Откройте несколько важных файлов и программ. После сброса или чистой установки восстановите файлы из копии и установите приложения заново. После восстановления проверьте именно ту ошибку, ради которой его выполняли.

Отмена до начала: закройте мастер или выберите отмену до финального подтверждения. После запуска не выключайте ПК ради отмены. Удалённые при чистой установке разделы и приложения после сброса штатная кнопка «Отменить» не возвращает: для полного возврата нужна заранее созданная резервная копия системы.

После обновления до другой версии может быть доступна «Система» → «Восстановление» → «Назад». Обычно срок — 10 дней; требуются сохранённые файлы предыдущей установки. Это условная возможность после обновления, а не гарантия отката после чистой установки или сброса. Ограничения описаны в справке Microsoft.
