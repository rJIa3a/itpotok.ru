## Первичные источники

1. [Microsoft: изменение имени учётной записи](https://support.microsoft.com/ru-ru/accounts-billing/manage/how-to-change-your-user-account-name). Подтверждает Панель управления для локальной записи, онлайн-профиль для Microsoft, задержку до 24 часов и ограничения рабочего/учебного аккаунта. Указанный производителем путь не ограничен редакцией Pro. Пароль, PIN и адрес входа не являются полями имени; их изменение в описанный путь не входит.
2. [Microsoft: переход между локальной записью и Microsoft](https://support.microsoft.com/en-US/accounts-billing/manage/change-from-a-local-account-to-a-microsoft-account-in-windows). Подтверждает Accounts → Your info, условное появление ссылок переключения. В статье предложено использовать ссылки лишь для определения типа, без смены типа записи.
3. [Set-LocalUser](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.localaccounts/set-localuser?view=powershell-5.1). Определение FullName: полное имя отличается от user name. Документация подтверждает различие полей, а не русскую подпись конкретного окна netplwiz.
4. [Rename-LocalUser](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.localaccounts/rename-localuser?view=powershell-5.1). Подтверждает отдельную операцию переименования локальной записи. Команды изменения аккаунта редакция не выполняла.
5. [Microsoft KB 2454362](https://learn.microsoft.com/en-us/previous-versions/troubleshoot/windows-client/renaming-user-account-not-change-profile-path). Документ относится к Windows 7/Server 2008 R2. Не выдаётся за инструкцию Windows 11. Microsoft прямо запрещает применение описанного обходного пути в Windows 10 и более новых системах из-за риска нарушить winget. Подробная инструкция реестра в статью не перенесена.
6. [whoami](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/whoami). Применимость Windows 11, без параметров выводит домен и имя текущего пользователя. Это проверка короткого имени после нового входа, а не подписи.

## Дополнительная сверка интерфейса и редакций

[Конкурент](https://remontka.pro/change-user-name-windows/) доступен и прочитан. У него есть netplwiz, оснастка локальных пользователей, WMIC, Microsoft-профиль и отдельный большой блок изменения папки профиля. Русские названия полей netplwiz сверены с его кадрами; они не объявляются собственным испытанием или первичной документацией. Для независимой проверки конкретных подписей требуется тестовая Windows 11. WMIC не включён: для решения основной задачи он не нужен.

[Ответ Microsoft Q&A об отсутствии оснастки в Home](https://learn.microsoft.com/en-us/answers/questions/788739/how-to-enable-local-users-and-groups-in-windows-11) — вспомогательное свидетельство на сайте производителя, не документация разработчика и не собственный тест. Основные способы статьи не требуют этой оснастки.

Отличия от конкурента: явное разделение подписи, короткого логина и пути; основной способ через Панель управления; отдельное ограничение netplwiz только для локальных записей; возврат; ожидание синхронизации; предупреждение про автоматический вход. Переименование папки оставлено отдельной темой плана (expanded-content-plan.md, блок дополнительных публикаций).
