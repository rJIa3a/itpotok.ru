Сначала предпринята попытка снять собственные кадры штатным Computer Use. Автоматическая проверка запретила использование «Инструменты Windows». Другой механизм управления этим приложением для обхода запрета не использовался. Подходящие кадры не подменены генерацией.

Проверена русская [официальная справка Microsoft](https://support.microsoft.com/ru-ru/accounts-billing/manage/how-to-change-your-user-account-name): ссылка с alt «Снимок экрана: свернутый вид панели управления» ведёт на https://support.microsoft.com/ru-ru/accounts-billing/media/control-panel.png. Фактически это маленький значок, не доказательство шагов. Он исключён из статьи и GitHub. Иллюстрации конкурента не копировались: права на публичное распространение не установлены.

До редакционной готовности нужно получить перечисленные реальные русские кадры через разрешённый Computer Use или из тестовой среды. Снимать только целевое окно, заранее использовать обезличенную тестовую запись; не включать приватный полный экран. Для узких кадров добавить открытие оригинала. Подпись должна различать собственный кадр и внешний источник. [Правила Microsoft для скриншотов](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions) прочитаны; для разрешённого внешнего материала сохранить источник, условия и атрибуцию.
