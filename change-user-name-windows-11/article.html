Чтобы поменять имя пользователя в Windows 11, для локальной учётной записи откройте «Панель управления» → «Учётные записи пользователей» → «Изменение имени своей учётной записи». Если вы входите с аккаунтом Microsoft, измените имя в его онлайн-профиле. Оба способа подходят для Windows 11 Home и Pro; имя папки профиля в C:\Users после смены имени остаётся прежним.

Какое имя вы хотите изменить

Windows использует несколько связанных, но разных названий. Отображаемое имя видно на экране входа и в меню учётной записи. Имя входа определяет, какую запись использует система: у локального пользователя это короткое имя, у аккаунта Microsoft — адрес электронной почты или другой разрешённый псевдоним. Папка профиля — путь к документам и настройкам, например C:\Users\Reader. Она не обязана совпадать с именем на экране.

Как определить тип учётной записи

  1. Откройте «Параметры» сочетанием Win + I.
  2. Перейдите в «Учётные записи» → «Ваши данные».
  3. Посмотрите сведения о записи. Для локального пользователя доступен переход ко входу с учётной записью Microsoft; для аккаунта Microsoft — переход к локальной записи. Только определите тип: переключаться между ними ради нового имени не требуется.

Если это рабочая или учебная запись организации, изменение имени может быть запрещено её правилами. Обратитесь к администратору: редактирование локальной записи не меняет имя в каталоге организации.

Изменить отображаемое имя локальной записи

Используйте этот способ, если нужно исправить подпись на экране входа. Запишите прежнее имя, чтобы при необходимости вернуть его. Если Windows запросит повышение прав, понадобится подтверждение администратора.

  1. Откройте «Пуск», введите «Панель управления» и откройте найденное приложение.
  2. При просмотре по категориям выберите «Учётные записи пользователей», затем ещё раз «Учётные записи пользователей». При просмотре значками откройте этот пункт сразу.
  3. Выберите «Изменение имени своей учётной записи». Убедитесь, что на странице показана именно нужная локальная запись.
  4. Введите новое имя и нажмите «Переименовать».
  5. Сохраните открытые документы и выйдите из учётной записи через меню пользователя в «Пуск». Проверьте подпись на экране входа и войдите снова.

Этот путь меняет видимую подпись, а короткое имя локального пользователя может остаться прежним. Пароль и ПИН-код менять не требуется. Для возврата откройте тот же пункт и введите прежнее имя. Если пункта изменения имени нет, ещё раз проверьте тип записи: для аккаунта Microsoft используйте следующий способ.

Изменить имя аккаунта Microsoft

Нужны доступ к интернету и возможность войти в тот аккаунт Microsoft, который используется в Windows. Новое имя относится ко всему аккаунту и может отображаться в других службах Microsoft, а не только на одном компьютере.

  1. Откройте профиль Microsoft и войдите в нужную учётную запись.
  2. В разделе сведений о пользователе найдите «Изменить имя».
  3. Укажите новые имя и фамилию, выполните проверку, если она появится, и нажмите «Сохранить».
  4. Убедитесь, что в веб-профиле появилось новое имя. На компьютере подключитесь к интернету, сохраните документы и выйдите из Windows, затем войдите снова.

По справке Microsoft, обновление имени может занять до 24 часов. Повторный вход не гарантирует мгновенную синхронизацию. Если на компьютере пока видно старое имя, проверьте, что вы изменили нужный аккаунт, и дождитесь обновления.

Изменение имени не заменяет адрес электронной почты для входа, пароль или ПИН-код. Для отмены снова откройте профиль и сохраните прежнее имя; его распространение тоже может потребовать времени. Изменение адреса входа и тега игрока Xbox — отдельные операции.

Если нужно изменить короткое имя локального пользователя

Для одной только подписи на экране входа достаточно Панели управления. Короткое имя меняйте, когда оно действительно нужно для входа или обращения к локальной записи. Этот раздел предназначен только для локального пользователя, не связанного с аккаунтом Microsoft или организацией.

Понадобятся права администратора. Запишите прежние значения и убедитесь, что знаете пароль. Если настроен автоматический вход либо задания и подключения используют старое имя, их настройки потребуется проверить после переименования. Не меняйте пароль, группы и параметры автоматического входа одновременно с именем.

  1. Нажмите Win + R, введите netplwiz и нажмите Enter.
  2. В окне «Учётные записи пользователей» выберите нужного локального пользователя и нажмите «Свойства».
  3. Измените поле «Пользователь», если нужно новое короткое имя. Поле «Полное имя» задаёт отображаемую подпись: если в нём осталось прежнее значение, на экране входа может сохраниться старая подпись.
  4. Нажмите «ОК» в свойствах и в основном окне. Сохраните документы, выйдите из записи и войдите снова.

Для проверки короткого имени откройте командную строку и выполните whoami: после обратной косой черты должно быть новое имя. Команда не показывает отображаемую подпись. Пароль остаётся прежним. Для возврата повторите действия и восстановите записанные значения обоих полей.

Не используйте этот путь для «исправления» аккаунта Microsoft. Если нужная запись или её свойства недоступны, вернитесь к определению типа аккаунта и проверьте права администратора. Оснастка «Локальные пользователи и группы» не входит в Windows 11 Home; приобретать Pro ради изменения отображаемого имени не требуется.

Почему папка пользователя сохранила старое имя

Папка профиля создаётся отдельно от отображаемого имени. Например, после замены подписи «Reader» на «Александр» документы могут по-прежнему находиться в C:\Users\Reader. Это не признак неудачной смены имени.

Чтобы проверить фактический путь, откройте Проводник, введите %USERPROFILE% в адресной строке и нажмите Enter. Проводник откроет текущую папку профиля. Для этого не нужно переименовывать каталог.

Не переименовывайте папку вручную и не меняйте путь профиля в реестре по старой инструкции для Windows 7. Microsoft прямо предупреждает, что описанный там обходной способ нельзя применять в Windows 10 и более новых системах: он может нарушить работу winget. Изменение папки профиля требует отдельной подготовки и проверки сохранности данных.

Если новое имя не появилось

  • Локальная запись: выйдите из сеанса после сохранения документов. Если меняли только поле «Пользователь», проверьте «Полное имя» — это отдельная подпись.
  • Аккаунт Microsoft: сверьте аккаунт в Windows с изменённым веб-профилем, проверьте подключение к интернету и дайте синхронизации до 24 часов.
  • Видно прежний адрес электронной почты: изменение имени не меняет адрес для входа.
  • Старое имя осталось в C:\Users: это ожидаемо; проверьте подпись на экране входа, а не название каталога.
  • Рабочая или учебная запись: попросите администратора изменить имя в организации.

Если после изменения короткого имени перестал срабатывать автоматический вход, выберите нужную запись на экране входа и войдите обычным способом с прежним паролем. Не удаляйте пользователя и его папку ради восстановления подписи.
