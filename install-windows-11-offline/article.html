При обычной первоначальной настройке Windows 11 Home и Pro для личного использования Microsoft требует интернет и учётную запись Microsoft. Если мастер остановился на подключении к сети, официальный путь — восстановить подключение и завершить настройку. После этого можно перейти на локальную учётную запись. Полностью автономную установку с помощью старых команд обхода нельзя обещать для любого современного образа.

Ниже разбираем именно первоначальную настройку после установки — OOBE. Подготовка диска и копирование файлов описаны отдельно в руководстве по установке Windows 11. Сведения о требованиях и версиях сверены 29 октября 2026 года; успешный обход OOBE на актуальных сборках в этом материале не заявляется.

Почему важны редакция, версия и сборка

На дату сверки Microsoft относит к общедоступным выпускам 26H2 (семейство сборок 26300), 25H2 (26200) и 26H1 (28000). Выпуск 26H1 предназначен для определённых новых устройств и не предлагается как обычное обновление существующих ПК с 24H2/25H2. Поддержка Home и Pro версии 24H2 уже завершена; у Enterprise и Education другой срок. Актуальную таблицу ведёт Microsoft.

Например, исходный выпуск 26H2 имеет сборку 26300.9457, а последняя указанная в таблице Microsoft на 29 октября — 26300.9818, предварительное накопительное обновление от 28 октября. Это номера ОС, а не доказательство работоспособности команды OOBE. Результат на одном ISO не подтверждает результат на обновлённом образе или заводском восстановлении.

Для проверки способа записывайте редакцию, полный номер сборки, происхождение ISO, дату опыта и наличие сети во время настройки. Надпись «работает в Windows 11» без этих условий мало помогает выбрать действие.

Требование Microsoft касается Home и Pro для личного использования. Pro также используется в организациях, но наличие этой редакции само по себе не гарантирует кнопку локального входа на каждом этапе. Enterprise, Education и специальные IoT/LTSC-выпуски не стоит выбирать вместо своей лицензированной редакции ради обхода: у них другие условия применения и развёртывания.

Как продолжить настройку, если нет Wi-Fi

Сначала определите, видит ли Windows сеть. Если список сетей есть, но ваш роутер не отображается, проверьте подключение рядом с ним и возможность соединиться с телефона. Если сетей нет совсем, возможна проблема с драйвером адаптера.

  1. Если доступен Ethernet, подключите компьютер к роутеру кабелем. Либо включите на телефоне точку доступа с мобильным интернетом и подключитесь к ней по Wi-Fi. Учитывайте тариф: настройка может загружать данные.
  2. Если Wi-Fi-адаптер не обнаружен, на другом устройстве скачайте драйвер с сайта производителя именно для вашей модели ПК и Windows 11. Распакуйте пакет с файлами INF на флешку. Если доступен только EXE, следуйте инструкции производителя.
  3. Для установки INF по инструкции Microsoft откройте командную строку клавишами Shift + F10. Выполните diskpart, затем list volume, найдите букву флешки и введите exit. Здесь нужны только просмотр томов и выход; команды очистки диска не вводите.
  4. Если INF лежат в корне флешки D:, выполните pnputil /add-driver D:\*.inf, затем при необходимости pnputil /scan-devices. Замените D: фактической буквой флешки.
  5. Закройте командную строку и проверьте, появились ли сети. Подключитесь и продолжите мастер. Если адаптер по-прежнему не обнаружен, проверьте пакет драйвера по модели устройства.

После выхода на рабочий стол временную точку доступа можно выключить и перейти на своё подключение. Установка драйвера помогает вернуть сеть; требование онлайн-настройки она не отменяет.

Как перейти на локальную учётную запись после установки

Этот вариант подходит, если вы можете один раз завершить обычную настройку онлайн, а затем хотите локальный вход. Он не решает задачу установки совсем без доступа к интернету.

  1. Сохраните открытые документы: в конце потребуется выход из системы.
  2. Откройте Параметры → Учётные записи → Ваши данные.
  3. Выберите ссылку перехода на локальную учётную запись. Она доступна для профиля, в котором используется учётная запись Microsoft. Подтвердите личность, если мастер запросит это.
  4. Задайте имя локального пользователя, пароль и подсказку. Завершите мастер кнопкой выхода из системы и войдите с новыми данными.

Проверьте тип учётной записи в том же разделе. Для возврата выберите ссылку входа с учётной записью Microsoft и пройдите предложенные шаги. Оба направления описаны в справке Microsoft.

Локальный пользователь относится к этому компьютеру; для входа ему не требуется интернет. Облачная синхронизация и вход в отдельные службы — другая задача. Сам переход не означает удаления онлайн-аккаунта или автоматического выхода из всех приложений Microsoft.

Что известно о старых командах обхода

У Microsoft есть два отдельных объявления: в Insider Dev 26200.5516 от 28 марта 2025 года заявлено удаление скрипта bypassnro.cmd; в Insider Dev 26220.6772 от 6 октября 2025 года — удаление известных механизмов создания локального пользователя в OOBE. Это сведения о конкретных тестовых ветках, а не перечень результатов испытания всех стабильных ISO.

Вариант из старых инструкцийЧто можно утверждать
OOBE\BYPASSNROЗависит как минимум от наличия соответствующего скрипта и поведения OOBE. Объявление об удалении в Insider не доказывает отсутствие файла во всех стабильных образах.
start ms-cxh:localonlyНедокументированный путь к локальному созданию пользователя. Успех в старой 25H2 не подтверждает успех в 26H2.
Параметр реестра BypassNROРучное создание значения реестра и наличие CMD-скрипта — разные вещи. Само успешное добавление значения не доказывает, что мастер разрешит автономную настройку.
HideOnlineAccountScreens через реестрДокументация одноимённой настройки Unattend не подтверждает произвольную команду изменения реестра.

Поэтому здесь эти варианты перечислены для распознавания устаревших советов, без пошагового обещания обхода. Неудача одной команды также не доказывает, что локальные учётные записи полностью убраны из Windows. Первичные объявления: 26200.5516 и 26220.6772.

Pro, Rufus и файл ответов: где заканчивается обычная настройка

В Pro встречается путь через настройку для работы или учёбы и присоединение к домену вместо облачного входа. Он относится к другому сценарию настройки; считать его гарантированным способом завершить 26H2 без сети оснований здесь нет. На устройстве организации способ выбирайте с администратором.

Microsoft документирует автоматизацию OOBE с файлом ответов. Для неё существуют настройки LocalAccount, HideOnlineAccountScreens и HideWirelessSetupInOOBE. Создание пользователя и скрытие отдельных страниц — разные параметры. Наличие этих настроек не является документированной отменой требований Home/Pro для личной интерактивной настройки.

Файл ответов нужно готовить и проверять для конкретного образа в тестовой среде. Не используйте неизвестный XML на единственном рабочем ПК: он может содержать не только настройки пользователя, но и разметку диска или запускаемые команды. Microsoft отдельно предупреждает не использовать SkipMachineOOBE для автоматизации.

У Rufus есть опция снятия требования онлайн-аккаунта. В FAQ разработчика указано, что соответствующий сценарий требует отсутствия сетевого подключения при создании пользователя. Это описание функции Rufus, а не подтверждение совместимости каждой его версии с каждым ISO 26H2. Полный прогон актуального сочетания здесь не выполнен. Подготовка носителя разобрана в отдельном руководстве Rufus; перезапись флешки уничтожает её содержимое, поэтому заранее сохраните нужное.

Что проверить после завершения настройки

В «Параметрах» проверьте тип учётной записи и состояние сетевого подключения. Когда интернет станет доступен, откройте Центр обновления Windows и установите необходимые обновления; проверьте устройства, для которых ещё нужны драйверы. Автономный вход не заменяет обслуживание системы.

Если вы ещё только готовитесь к чистой установке и сеть недоступна вообще, сначала сохраните резервную копию и проверьте весь путь до рабочего стола на отдельной виртуальной машине с тем же образом. До такой проверки не удаляйте рабочую систему в расчёте на команду из старой инструкции.
