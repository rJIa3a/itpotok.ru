# FAQ

Хранить ответы в штатных метаданных итоговой записи. Шорткод должен ссылаться на ID этой же записи; отдельный черновик как источник FAQ не нужен.

1. Можно ли перенести встроенный виджет на рабочий стол?
Нет, в описанном штатном интерфейсе карточки размещаются внутри доски мини-приложений. Для постоянно видимых элементов рабочего стола нужна отдельная программа, например Rainmeter.

2. Почему после отключения кнопки виджеты всё равно открываются?
Переключатель в параметрах панели задач скрывает кнопку, но не удаляет компонент. Панель остаётся доступна через Win + W; настройки экрана блокировки меняются отдельно.

3. Можно ли оставить погоду и убрать новости?
В новом оформлении откройте параметры доски и отключите панель Discover. Карточки останутся. Если нужного переключателя нет, проверьте обновления компонентов и доступные настройки вашей версии.

4. Почему нет нужного виджета в списке добавления?
Набор зависит от установленных приложений и их поддержки Windows Widgets. Обычный ярлык не становится карточкой. Для экрана блокировки дополнительно нужна поддержка малого размера.

5. Нужна ли учётная запись Microsoft для любого виджета?
Требования зависят от приложения и данных. Персонализация Discover использует настройки учётной записи Microsoft, а карточке с личными задачами может потребоваться вход в соответствующий сервис. Не считайте вход обязательным для всех сторонних часов и локальных показателей.

6. Почему настройки экрана блокировки отличаются от скриншота?
В статье показан прежний список «Состояние экрана блокировки». Microsoft также описывает новый интерфейс с отдельными карточками. Выбирайте инструкцию по элементам, которые реально видны в ваших Параметрах.
