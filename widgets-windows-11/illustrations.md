# План и происхождение иллюстраций — 03.10.2026

План составлен до загрузки в WordPress: новая редакционная обложка; меню настройки карточки; выбор «Ничего» на экране блокировки. Снимки русского интерфейса обязательны. Иллюстрации не требуются под каждым заголовком.

## Обложка

widgets-windows-11-cover-20261003.png, 1600×900. Создана редакцией скриптом generate-cover.ps1. Стилизованные карточки — иллюстрация, не скриншот Windows. Нет чужих фотографий, логотипов или кадров; надписи в центральной области для обрезки шаблоном. Проверку фактически назначенной обложки и её ID см. README.md и verification.md.

## Собственная съёмка и ограничения

Computer Use дважды попытался открыть Параметры: приложение есть в списке, но targetable window отсутствует. Продолжение через неподдерживаемую автоматизацию не выполнялось. Собственные кадры Windows для этой статьи не сняты. Локальная сборка 26300 не использована как доказательство коммерческого интерфейса.

Новые кадры добавления на доску, нового списка экрана блокировки и русского Rainmeter не получены. Их нельзя подменять английским интерфейсом, генерацией или снимком веб-страницы. Шаги проверены по первичным источникам; эти кадры остаются улучшением редакционного пакета. Старые изображения используются только для соответствующих меню и вариантов, с явной датой в подписи.
