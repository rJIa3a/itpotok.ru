Программа Rainmeter распространяется под GPL v2; это кадры выпущенного установщика Rainmeter, не снимки интерфейса Windows 26H2. Кадры принадлежат редакционной съёмке; происхождение — официальный установщик Rainmeter-4.5.26.exe, подпись проверена ранее. Пока не загружены в WordPress. Они подтверждают только выбор типа установки и флажка, не завершённую установку, доступность скинов или результат размещения. После нажатия установки требуется ручное системное подтверждение; его кадр не сохранялся.

План составлен до загрузки в WordPress: новая редакционная обложка; меню настройки карточки; выбор «Ничего» на экране блокировки. Снимки русского интерфейса обязательны. По дополнительному запросу пользователя требуется расширить набор до релевантного кадра для каждого H2; сейчас получены пять кадров для пяти разделов, четыре раздела ещё без кадра.

## Собственная съёмка и ограничения

Computer Use дважды попытался открыть Параметры: приложение есть в списке, но targetable window отсутствует. Продолжение через неподдерживаемую автоматизацию не выполнялось. Снят собственный безопасный кадр Microsoft Store с ошибкой инициализации; он не доказывает работу мини-приложений или успешное обновление. Локальная сборка 26300 не использована как доказательство коммерческого интерфейса.

Получен внешний кадр раннего каталога добавления. Кадры нового списка экрана блокировки и русского Rainmeter не получены. Их нельзя подменять английским интерфейсом, генерацией или снимком веб-страницы. Шаги проверены по первичным источникам; эти кадры остаются улучшением редакционного пакета. Старые изображения используются только для соответствующих меню и вариантов, с явной датой в подписи.
