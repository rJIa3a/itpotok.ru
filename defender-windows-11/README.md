# Как отключить Microsoft Defender в Windows 11

Актуальный редакционный исходник: [`defender-factchecked.html`](defender-factchecked.html). [Статья опубликована на ITpotok.ru](https://itpotok.ru/kak-otklyuchit-microsoft-defender-v-windows-11/) 30 сентября 2026 года, запись WordPress 11875.

## Что входит в папку

- `defender-factchecked.html` — HTML, сохранённый в WordPress.
- `defender-factcheck.md` — проверенные утверждения, первичные источники, редакционные исправления и границы проверки.
- `illustrations.md` — происхождение восьми изображений и правила подписей.
- `cover-defender-windows-11.png` — созданная для статьи обложка, установленная как «Изображение записи» в WordPress.
- `cover-prompt.md` — описание генерации обложки.
- `published-preview.jpg` — снимок верхней части опубликованной страницы для редакционного архива.

## Соседний материал на сайте

На сайте осталась [предыдущая статья о Защитнике Windows 11](https://itpotok.ru/disable-defender-antivirus-windows-11/). После публикации нового материала редакции нужно решить судьбу старой страницы, чтобы две записи не конкурировали за один запрос. Старую запись в рамках этой задачи не меняли.

## Граница проверки

Статья сверена с документацией Microsoft и источниками иллюстраций. Отключение Defender на тестовой Windows 11, состояние после перезагрузки и восстановление защиты практически не проверялись. Собственных кадров приложения «Безопасность Windows» нет. Эти ограничения нельзя удалять из редакционных материалов или заменять недоказанными утверждениями.
