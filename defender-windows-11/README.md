# Как отключить Защитник Windows 11

## План переноса на прежний URL

Пользователь решил сохранить старую страницу и её позиции. Целевой адрес: [https://itpotok.ru/disable-defender-antivirus-windows-11/](https://itpotok.ru/disable-defender-antivirus-windows-11/), старая запись WordPress 11548. Её заголовок и постоянную ссылку сохранить; заменить основной текст подготовленной редакцией из `defender-factchecked.html`, перенести нужные иллюстрации и обложку, проверить предпросмотр и обновить опубликованную старую запись.

Новую запись WordPress 11875 по адресу [https://itpotok.ru/kak-otklyuchit-microsoft-defender-v-windows-11/](https://itpotok.ru/kak-otklyuchit-microsoft-defender-v-windows-11/) после успешного обновления старой перевести в черновик. Не удалять её содержимое до проверки старой страницы. Предыдущий текст старой статьи сохранён локально в рабочем архиве; этот полный HTML не загружать в публичный репозиторий, поскольку в шапке страницы могут находиться служебные коды сайта.

**Состояние на 2 октября 2026:** перенос и смена статуса WordPress ещё не выполнены. Браузер ранее отклонил доступ к сайту. Черновик 11875 пока не переключён. Для продолжения нужен разрешённый браузерный доступ к WordPress.

## Текущий исходник

- `defender-factchecked.html` — подготовленный текст статьи для записи 11548.
- `defender-factcheck.md` — фактчекинг, первичные источники и границы практической проверки.
- `illustrations.md` — источники и атрибуции восьми иллюстраций.
- `cover-defender-windows-11.png` — обложка, загруженная в медиатеку WordPress.
- `cover-prompt.md` — описание создания обложки.
- `published-preview.jpg` — снимок прежнего предпросмотра новой статьи для архива.

В HTML проставлен `rel="nofollow"` для 20 внешних ссылок на источники. Якоря внутри статьи и URL изображений на самом сайте не менялись.
