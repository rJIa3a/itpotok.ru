# Как отключить Защитник Windows 11

Редакционная цель после решения о сохранении старого URL: обновить существующую запись WordPress **11548** по адресу [itpotok.ru/disable-defender-antivirus-windows-11/](https://itpotok.ru/disable-defender-antivirus-windows-11/). У неё остаются прежние адрес и заголовок; актуальный материал из этой папки переносится в её тело.

Новая запись WordPress **11875** по адресу [itpotok.ru/kak-otklyuchit-microsoft-defender-v-windows-11/](https://itpotok.ru/kak-otklyuchit-microsoft-defender-v-windows-11/) содержит подготовленный материал. После успешного переноса и проверки её следует снять с публикации и настроить постоянное перенаправление на старый URL. На момент этого обновления WordPress не менялся: браузерный доступ к сайту ранее был отклонён.

Актуальный редакционный текст для переноса: [defender-factchecked.html](defender-factchecked.html). В нём к 20 внешним ссылкам на источники добавлен `rel="nofollow"`; внутренние ссылки и ссылки на изображения сайта не затронуты.

## Файлы

- `defender-factchecked.html` — полный актуальный HTML тела статьи для записи 11548.
- `defender-factcheck.md` — фактчекинг, источники и границы практической проверки.
- `illustrations.md` — источники и атрибуции восьми иллюстраций.
- `cover-defender-windows-11.png` — созданная обложка, доступная в медиатеке сайта.
- `cover-prompt.md` — описание создания обложки.
- `published-preview.jpg` — снимок прежнего предпросмотра новой статьи для архива.

## Данные по конкуренту

В полученном отчёте remontka.pro занимает позиции 2–5 по многим точным запросам об отключении антивируса Windows 11. Наиболее приоритетные видимые фразы: «как отключить антивирус на Windows 11» (позиция 4; Wordstat 11 105), «как полностью отключить антивирус в Windows 11» (позиция 2; Wordstat 522), «отключить антивирус Windows 11» (позиция 2; Wordstat 2 483), «отключить защиту Windows 11» (позиция 2; Wordstat 2 224), «как отключить защитника Windows 11» (позиция 5; Wordstat 1 693). Отчёт снят для Google, регион Москва; дата проверки на изображении не указана. Исходный снимок с личной учётной записью в репозиторий не добавляли.

## Ограничения фактической проверки

Статья сверена с документацией Microsoft и источниками иллюстраций. Реальное отключение Defender на конкретной сборке Windows 11, состояние после перезагрузки и восстановление защиты практически не проверялись. Иллюстрации экранов Windows взяты у Microsoft и Hetman Software, это не собственные кадры ITpotok.
