Файл подкачки в Windows 11 меняют в окне «Параметры быстродействия» → «Дополнительно» → «Виртуальная память». Если ошибок памяти нет, оставьте автоматическое управление. Для ручной настройки нужно выбрать диск, задать размеры и проверить результат после перезагрузки. Этот порядок подходит и для Windows 10.

Для чего нужен файл подкачки

pagefile.sys — скрытый системный файл на накопителе. Windows может записывать в него редко используемые изменённые страницы памяти, освобождая RAM для текущей работы. Кроме того, файл подкачки увеличивает объём памяти, который система может выделить программам, и может требоваться для записи дампа при сбое.

Файл подкачки не добавляет физическую оперативную память. Обращение к накопителю отличается от работы с RAM, поэтому увеличение размера само по себе не гарантирует ускорения компьютера или роста FPS. Оно может помочь, когда выделение памяти упирается в установленный предел.

В Диспетчере задач на странице «Производительность» → «Память» есть показатель «Выделено», например 18/24 ГБ. Первое число — сколько памяти система уже обязалась предоставить; второе — предел выделения. Это не объём записанных в pagefile.sys данных. Предел зависит от RAM и файлов подкачки. Если первое число приближается ко второму, приложения могут не получить новую память, даже когда один из других показателей выглядит нормальным.

Универсального размера для 8, 16 или 32 ГБ RAM нет. Microsoft связывает его с пиковой потребностью в выделенной памяти и выбранным типом дампа. Правило «всегда вдвое больше RAM» для этой задачи не подходит. Поле «Рекомендуется» в окне настройки тоже не следует превращать в обязательный размер для всех компьютеров.

Как открыть окно «Виртуальная память»

Понадобятся права администратора для изменения системных параметров. На рабочем компьютере настройки могут ограничиваться организацией. В Windows 11 Home и Pro используется одно и то же классическое окно; редактор групповых политик для этого не нужен.

  1. Нажмите Win + R, введите SystemPropertiesPerformance.exe и нажмите Enter.
  2. В окне «Параметры быстродействия» откройте вкладку «Дополнительно».
  3. В разделе «Виртуальная память» нажмите «Изменить…».

Ещё один путь: Win + R → sysdm.cpl → вкладка «Дополнительно» → «Параметры…» в разделе «Быстродействие». Затем снова выберите «Дополнительно» и «Изменить…». Это позволяет добраться до нужного окна без поиска пункта в меняющемся интерфейсе «Параметров» Windows.

Перед изменениями запишите, установлен ли флажок «Автоматически выбирать объем файла подкачки», какие диски используются и какие размеры заданы. При необходимости сделайте снимок только этого окна. Так вы сможете вернуть прежнюю ручную конфигурацию, если автоматическое управление вам не подходит.

Как увеличить или задать размер вручную

Ручная настройка имеет смысл, если известен требуемый размер: например, его указал разработчик программы или вы ограничили файл ранее и теперь видите нехватку выделенной памяти. Убедитесь, что на выбранном диске достаточно свободного места. Если значения неизвестны, начните с возврата к автоматическому управлению.

  1. В окне «Виртуальная память» снимите флажок «Автоматически выбирать объем файла подкачки». Нижние элементы станут доступны.
  2. Выберите диск в списке. Для обычной настройки используйте диск, на котором файл уже находится; перенос разобран отдельно ниже.
  3. Выберите «Указать размер». Введите «Исходный размер (МБ)» и «Максимальный размер (МБ)». Максимальный размер должен быть не меньше исходного.
  4. Нажмите «Задать». Убедитесь, что в строке выбранного диска появились введённые размеры. Одного ввода чисел и нажатия «ОК» недостаточно.
  5. Нажмите «ОК» в окне виртуальной памяти и подтвердите изменения в оставшихся окнах. Если Windows предложит перезапуск, сначала сохраните документы. Выполните перезагрузку через «Перезагрузка», затем проверьте настройку.

Исходный размер задаёт начальный объём файла, максимальный — границу его увеличения. Например, 4096 и 8192 МБ означают 4 и 8 ГБ: это только пример перевода единиц, а не рекомендация для вашего компьютера. Если поставить одинаковые значения, файл лишится запаса для роста. Такой фиксированный размер не делает систему автоматически быстрее.

Для уменьшения используется тот же порядок, но не снижайте предел без проверки обычной максимальной нагрузки и требований к дампу. Отсутствие ошибки сразу после запуска не доказывает, что памяти хватит при обработке большого проекта или запуске нескольких программ.

Как проверить результат после перезагрузки

  1. Снова откройте «Виртуальная память». Проверьте диск и режим: при ручной настройке в списке должны быть ваши значения. Для автоматического режима должен сохраниться соответствующий флажок.
  2. Откройте Диспетчер задач сочетанием Ctrl + Shift + Esc, выберите «Производительность» → «Память» и посмотрите «Выделено». Сравните предел с прежним значением. Его изменение не обязано точно совпадать с введённой цифрой: в расчёте участвуют RAM и все файлы подкачки.
  3. Повторите задачу, при которой возникала ошибка, сохраняя рабочие файлы. Следите за «Выделено» во время нагрузки, а не только на свободном рабочем столе. Если ошибка остаётся при заметном запасе до предела, увеличение файла подкачки может не решать её причину.

Для дополнительной проверки фактически созданных файлов можно открыть PowerShell и выполнить команду чтения:

Get-CimInstance Win32_PageFileUsage | Select-Object Name, AllocatedBaseSize, CurrentUsage, PeakUsage

Name показывает путь, AllocatedBaseSize — выделенное на диске место, CurrentUsage и PeakUsage — текущее и максимальное использование за время работы системы; размеры указаны в МБ. Команда ничего не меняет. Она помогает отличить выбранный максимум от фактического объёма файла. Если вывода нет, сначала проверьте режим в графическом окне и перезапуск, а не создавайте файл вручную.

Как вернуть автоматическое управление и включить файл подкачки

  1. Откройте «Виртуальная память» и установите флажок «Автоматически выбирать объем файла подкачки».
  2. Подтвердите «ОК» и примените изменения в окнах параметров. Сохраните документы и перезагрузите компьютер.
  3. После запуска убедитесь, что флажок остался включён. Затем проверьте проблемную программу.

Это же действие подходит, если файл подкачки был отключён: Windows создаст и будет обслуживать его сама. Создавать пустой pagefile.sys в Проводнике не нужно. В автоматическом режиме текущий размер может изменяться; число в разделе «Виртуальная память» не обязано постоянно равняться объёму RAM.

Отдельный режим «Размер по выбору системы» относится к выбранному диску, когда общий флажок снят. Чтобы использовать его, выберите диск, отметьте этот режим и нажмите «Задать». Общий флажок передаёт Windows управление конфигурацией для всех дисков — это разные уровни настройки.

Можно ли перенести файл на другой диск

Можно создать файл подкачки на другом подходящем локальном диске. Это бывает полезно при нехватке места, но перенос на другой раздел того же накопителя сам по себе не даёт дополнительной скорости. Эффект зависит от нагрузки и характеристик дисков. Не рассчитывайте на гарантированное ускорение и не используйте флешку как замену RAM.

Перед отключением файла на диске с Windows проверьте требования к дампу. Дамп — данные для диагностики системного сбоя. Для обычной записи дампа нужен подходящий файл подкачки на загрузочном томе; альтернативой служит специально настроенный файл дампа. Одного файла подкачки на другом диске может быть недостаточно. Если такой конфигурации у вас нет, безопаснее сохранить системный файл подкачки на C и при необходимости добавить второй.

  1. Откройте «Виртуальная память» и снимите общий флажок автоматического выбора.
  2. Выберите целевой локальный диск со свободным местом. Установите «Размер по выбору системы» или обоснованные ручные значения и нажмите «Задать».
  3. Оставьте файл на C, если его сохранение требуется для дампа. Только если последствия проверены и нужен именно полный перенос, выберите прежний диск → «Без файла подкачки» → «Задать». Прочитайте предупреждение Windows перед подтверждением.
  4. Подтвердите окна, перезагрузите компьютер и проверьте список дисков и вывод команды из раздела проверки.

Для отмены верните автоматическое управление либо восстановите записанные ранее параметры на каждом диске. Не перемещайте pagefile.sys через Проводник: его расположением управляет Windows.

Что учитывать перед отключением

При отключении всех файлов подкачки предел выделенной памяти становится немного меньше установленного объёма RAM. Если нагрузка достигнет этого предела, программы могут получить ошибки выделения памяти, зависнуть или завершиться. Некоторые приложения требуют файл подкачки по собственным условиям — это нужно проверять в документации конкретного продукта. Большой объём RAM не отменяет требования к дампу.

Для полного дампа Microsoft указывает файл размером RAM + 257 МБ; дамп ядра и автоматический дамп зависят от используемой памяти ядра. Это требования к диагностике сбоя, а не универсальная формула настройки. Без достаточного файла подкачки или специально настроенного файла дампа нужный дамп может не записаться.

Если вы осознанно проверяете работу без подкачки, сохраните прежние настройки. Снимите общий флажок, на каждом диске с файлом выберите «Без файла подкачки» и нажмите «Задать», затем подтвердите окна и перезагрузитесь. Отключение только на C при наличии файла на D не отключает подкачку целиком. При ошибках верните автоматическое управление.

Удалять pagefile.sys вручную ради очистки диска не нужно. Для освобождения места сначала используйте обычные способы очистки диска C в Windows 11. Если подозреваете файл подкачки, проверьте его фактический объём и нагрузку; отключение не исправит утечку памяти в программе.

Чем swapfile.sys отличается от pagefile.sys

swapfile.sys — другой системный файл, связанный с механизмами управления памятью приложений Windows. Это не «улучшенная версия» pagefile.sys и не ещё один объём RAM.

В окне «Виртуальная память» вы настраиваете файлы подкачки для дисков; отдельного поля размера swapfile.sys там нет. Для обычной настройки не требуется удалять этот файл, редактировать реестр или создавать символические ссылки. Не переносите на него вручную введённые значения для pagefile.sys.

Если параметры не сохранились или памяти всё равно мало

  • Числа не появились в списке. После ввода нажмите «Задать», затем подтвердите окна. Проверьте, что выбран именно нужный диск.
  • Поля серые. При включённом общем флажке размером управляет Windows. Для ручного ввода флажок нужно снять. Если изменение всё равно недоступно, проверьте права и ограничения организации.
  • На диске мало места. Освободите его до увеличения файла. Автоматическое управление тоже требует свободного пространства.
  • Настройка верна, ошибка остаётся. Проверьте «Выделено» во время сбоя, требования приложения и его точное сообщение. Не увеличивайте файл бесконечно, если предел не достигнут.
  • После прежней ручной настройки стало хуже. Верните автоматический выбор, перезагрузитесь и повторите ту же задачу.
