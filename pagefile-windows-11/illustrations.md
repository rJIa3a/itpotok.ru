## Условия завершения

Получить безопасные реальные русские кадры из рабочей/тестовой среды без изменения памяти рабочего ПК либо внешний набор с проверенными правами. Добавить точные подписи и alt, ссылку для увеличения узких кадров. Внешние файлы без разрешения не отправлять в GitHub. Затем проверить картинки и обложку в реальном шаблоне; одного формата исходника недостаточно.
