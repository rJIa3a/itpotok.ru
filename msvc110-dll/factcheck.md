# Фактчекинг — 21 октября 2026 года

## Первичные источники и выводы

- https://learn.microsoft.com/en-us/visualstudio/releases/2012/2012-redistribution-vs — официальный список Visual C++ Runtime содержит msvcp110.dll и msvcr110.dll для x86/x64/ARM в Microsoft.VC110.CRT; распространяемый пакет устанавливает библиотеки C/C++ для приложений Visual Studio 2012.
- https://www.microsoft.com/ru-ru/download/details.aspx?id=30679 — действующая русская страница Update 4, версия 2012.4, vcredist_x86.exe и vcredist_x64.exe. Страница и диалог прочитаны в браузере. Windows 10/11 не перечислены в системных требованиях; не заявлена их официальная поддержка.
- https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist — пакет соответствует архитектуре приложения, раздел 2012 содержит 11.0.61030.0. Поддержка закончилась 10.01.2023. Современный v14 не заменяет поколения до 2013, которые устанавливаются отдельно.
- https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files — центральная установка пакетом, восстановление /repair, права администратора, локальное размещение библиотек и ошибки отсутствующих зависимостей. Команды современного установщика не выданы за испытание версии 2012. Восстановление описано условно: если оно предложено.
- https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/regsvr32 — регистрация компонентов через DllRegisterServer; это не установка runtime. Команды регистрации в статью не включены.
- https://learn.microsoft.com/en-us/cpp/c-runtime-library/crt-library-features — различие CRT/STL и отладочных библиотек; обычный runtime не устанавливает Debug-окружение. FAQ с буквой D направляет к разработчику.
- https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions — правила снимков; атрибуция добавлена, EXE не распространяются через GitHub. Ограничение кадра указано в illustrations.md.

## Выполнено практически

Скачаны оба русских установщика с URL из официальной страницы: HTTP 200, размеры и SHA-256 в download-check.json. Get-AuthenticodeSignature для обоих: Valid, подписант Microsoft Corporation. Исполняемые файлы находятся вне Git.
Снят реальный русский диалог выбора загрузок. Проведена структурная и языковая вычитка. Конкуренты прочитаны, их текст и изображения не заимствованы.
По авторизованному REST выполнен поиск msvcp110, msvcr110, Visual C++ среди всех статусов. Совпадающих публикаций нет; подробности в duplicate-check.json.

## Границы

Не выполнены установка, удаление и восстановление пакета, запуск неисправного приложения и устранение ошибки на чистой Windows 11. Не проверены ARM и старые Windows. Сценарии 0xc000007b, точки входа, карантина и локальных DLL — диагностические варианты, а не установленная причина на конкретном ПК. Названия кнопок восстановления не подтверждены собственным кадром; статья не обещает одинакового интерфейса.
Проверка документации и текста не называется практическим испытанием. Доступность английских прямых EXE из Microsoft Learn подтверждена наличием официальных ссылок, но их скачивание отдельно не выполнялось; скачаны русские x86/x64.
