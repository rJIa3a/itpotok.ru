## Microsoft: происхождение и условия

Оба внешних кадра получены из [русской справки Microsoft о среде восстановления Windows](https://support.microsoft.com/ru-ru/windows/experience/backup-recovery/windows-recovery-environment). На сайте Microsoft обозначены как снимки экранов Windows RE. Это внешние изображения, не собственные кадры редакции. Дата исходной съёмки не указана; дата получения и сверки 11.10.2026. Первый кадр явно содержит Windows 11. Точная сборка не заявляется.

[Microsoft разрешает использовать скриншоты на сайтах](https://www.microsoft.com/en-us/legal/intellectualproperty/copyright/permissions), раздел Screenshots, с общими условиями: полное имя продукта, фраза «Used with permission from Microsoft.», без изменения кроме масштабирования, без фрагментов, третьестороннего контента и узнаваемых людей; исключены загрузочные заставки и бета-продукты. Выбраны целые экраны служебного интерфейса коммерческой Windows, не стартовые заставки. Источник указан активной ссылкой в каждой подписи, обязательная фраза сохранена. Кадры не изменялись, персональных данных и третьестороннего контента нет.

По консервативному правилу проекта внешние файлы в публичный GitHub не скопированы: пакет хранит происхождение, условия и адреса медиатеки. На WordPress загружены целиком в рамках указанных условий. Для каждого кадра ссылка на оригинал добавлена для увеличения.
