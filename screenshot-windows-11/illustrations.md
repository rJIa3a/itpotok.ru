## Актуальные собственные кадры — 2 октября 2026

Четыре файла — реальные снимки русского интерфейса, сделанные редакцией. Они не генерировались; надписи и элементы не заменялись. Кадры можно хранить и распространять в редакционном пакете. Личные данные и приватные файлы исключены обрезкой; полные исходные снимки в репозиторий не включены.

- `images/snipping-tool-ru.jpg`, 502 × 231: окно «Ножницы» с раскрытыми режимами. Это окно приложения, а не плавающая панель Win + Shift + S. Версия пакета не проверялась. WordPress ID 11916: https://itpotok.ru/wp-content/uploads/2026/10/snipping-tool-ru.jpg
- `images/screenshots-folder-ru.png`, 910 × 134: верхняя часть настоящего Проводника с путём «Изображения → Снимки экрана». Список файлов и боковая панель исключены. Показывает расположение папки, а не результат испытания Win + PrtSc. WordPress ID 11917: https://itpotok.ru/wp-content/uploads/2026/10/screenshots-folder-ru.png
- `images/printscreen-setting-ru.png`, 913 × 74: строка настройки Print Screen в настоящих Параметрах, переключатель уже включён. В наблюдавшейся системе настройка находится в «Bluetooth и устройства → Клавиатура». Переключатель не менялся. WordPress ID 11918: https://itpotok.ru/wp-content/uploads/2026/10/printscreen-setting-ru.png
- `images/snipping-delay-ru.png`, 502 × 200: меню задержки «Ножниц» с вариантами без задержки, 3, 5 и 10 секунд. Снят через Computer Use 2 октября 2026 года; из настоящего снимка развёрнутого окна обрезан прямоугольник (0, 0, 502, 200), исключены пустое поле и постороннее наложение справа. Выбор времени и захват с таймером не выполнялись; кадр подтверждает видимые варианты меню. WordPress ID 11923: https://itpotok.ru/wp-content/uploads/2026/10/snipping-delay-ru.png

Два узких кадра имеют ссылки увеличения в статье. Наблюдавшаяся Windows: DisplayVersion 26H2, сборка 26300.9457; канал выпуска не определялся. Кадр плавающей панели захвата не снят и не подменяется снимком окна приложения.

Файлы не копировались в GitHub или медиатеку. 2 октября оба удалены из актуального текста и заменены собственными кадрами.
