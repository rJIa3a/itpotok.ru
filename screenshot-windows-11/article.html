Чтобы сделать скриншот части экрана в Windows 11, нажмите Win + Shift + S, выделите область и вставьте снимок через Ctrl + V либо откройте уведомление «Ножниц» для сохранения. Весь экран сразу в файл снимает Win + PrtSc, а одно активное окно в буфер обмена — Alt + PrtSc. Ниже — шаги для каждого способа, поиск файлов и настройка клавиши PrtSc.

Снимок части экрана: Win + Shift + S

После сочетания откроется панель выбора. На кадре Microsoft показана та же панель с раскрытым списком режимов; подписи интерфейса на английском.

  1. Подготовьте экран и нажмите Win + Shift + S. Сверху появится панель выбора.
  2. Выберите прямоугольник, произвольную форму, окно или весь экран. Для прямоугольника выделите область мышью; для окна щёлкните нужное окно.
  3. Вставьте снимок в документ или сообщение сочетанием Ctrl + V. Чтобы обрезать или подписать его, откройте уведомление о снимке и используйте «Ножницы».

Проверка: вставьте снимок в Paint и посмотрите, что попала нужная область. В актуальных «Ножницах» изображение также может автоматически сохраняться в папку «Снимки экрана»; это зависит от настроек приложения. Если нужен файл с выбранным именем, нажмите в «Ножницах» «Сохранить как» или Ctrl + S. Ограничение: сочетание захватывает видимую часть страницы, а не всю страницу с прокруткой. Отмена: до выбора области нажмите Esc; ненужный файл удалите обычным способом.

Весь экран сразу в файл: Win + PrtSc

  1. Нажмите Win + PrtSc. На некоторых ноутбуках клавишу PrtSc нужно нажимать вместе с Fn.
  2. Откройте Проводник → «Изображения» → «Снимки экрана». Найдите последний файл и откройте его.

Проверка: перед отправкой откройте файл и убедитесь, что на нём нет лишних окон, уведомлений и личных данных. Если папка «Изображения» перенесена или синхронизируется, её фактический путь может отличаться. При нескольких мониторах полный снимок может включать всю виртуальную область дисплеев. Чтобы показать только один экран, выделите его через Win + Shift + S. Отмена: удалите лишний файл из папки «Снимки экрана».

Только активное окно: Alt + PrtSc

  1. Щёлкните окно, которое хотите снять.
  2. Нажмите Alt + PrtSc; при необходимости добавьте Fn.
  3. Откройте Paint, нажмите Ctrl + V, затем Ctrl + S и выберите папку. Если файл не нужен, вставьте изображение сразу в сообщение или документ.

Проверка: после вставки видно только выбранное окно. Само сочетание не создаёт файл: новое скопированное содержимое может заменить снимок в буфере. Отмена: закройте изображение без сохранения или удалите созданный файл.

«Ножницы»: снимок с задержкой и разметка

Этот способ удобен для меню, которое исчезает при обычном захвате, и для изображения с пометками.

  1. Откройте «Пуск», введите Ножницы и запустите приложение.
  2. Выберите режим снимка. Для раскрывающегося меню установите доступное время в пункте «Задержка».
  3. Нажмите «Создать». При задержке откройте нужное меню до появления затемнения, затем выделите область.
  4. При необходимости добавьте пометки. Нажмите «Сохранить как» и выберите место сохранения. Настройку автоматического сохранения можно проверить через «…» → «Параметры».

Проверка: откройте файл и убедитесь, что меню и пометки видны. Длительность задержки и подписи кнопок могут отличаться между версиями приложения. Отмена: закройте снимок без ручного сохранения, удалите автоматически созданный файл, если он появился, и верните настройку автосохранения в прежнее положение.

В актуальных версиях «Ножниц» есть перо, маркер, обрезка и «Текстовые действия»: последняя функция распознаёт текст и может быстро скрыть обнаруженные адреса и телефоны. Перед отправкой всё равно проверьте изображение вручную: на нём могут остаться имена, вкладки, другие контакты и уведомления. Пометки можно отменить кнопкой «Отменить» до сохранения.

Почему PrtSc открывает «Ножницы»

В Windows 11 действие одиночной клавиши PrtSc зависит от настройки «Использовать клавишу Print Screen для открытия фрагмента экрана». В актуальных установках она часто открывает панель выбора. Поэтому утверждение «PrtSc всегда копирует весь экран» может не сработать.

  1. Откройте «Пуск» → «Параметры» → «Специальные возможности» → «Клавиатура».
  2. Найдите переключатель открытия фрагмента экрана клавишей Print Screen. Выключите его, если хотите копировать весь экран в буфер одиночным PrtSc.
  3. Нажмите PrtSc и попробуйте вставить результат в Paint сочетанием Ctrl + V.

Проверка: в Paint появится снимок всего экрана. Если снова открывается панель выбора, проверьте настройку и программы, перехватывающие клавишу. Отмена: включите переключатель обратно. Win + Shift + S продолжит открывать выбор области.

Где искать файл и что проверить, если снимка нет

  • Win + PrtSc: Проводник → «Изображения» → «Снимки экрана».
  • Win + Shift + S и «Ножницы»: вставьте результат из буфера. В современных версиях «Ножниц» проверьте автосохранение и папку через «…» → «Параметры». Для точного выбора места нажмите «Сохранить как».
  • Alt + PrtSc: вставьте из буфера через Ctrl + V; файла не будет, пока вы сами его не сохраните.

Если сочетание не работает, попробуйте Fn вместе с PrtSc, затем запустите «Ножницы» из меню «Пуск». После каждого шага сделайте пробный снимок несекретного окна и убедитесь, что его можно открыть или вставить. Если заранее включён журнал буфера, Win + V показывает сохранённые элементы; включение журнала — отдельная настройка Windows. Снимок из буфера вставляйте сразу: следующее копирование может его заменить.

Длинная веб-страница целиком

Системные сочетания снимают только видимую часть страницы. Для страницы с прокруткой используйте функцию браузера. Например, в Firefox она документирована как снимок всей страницы:

  1. Откройте страницу в Firefox, щёлкните правой кнопкой по пустому месту и выберите «Сделать скриншот». Можно также нажать Ctrl + Shift + S.
  2. Выберите «Сохранить всю страницу», затем скачайте изображение.
  3. Откройте файл и проверьте верх, середину и низ страницы: всплывающие блоки и динамические элементы могут мешать результату.

Отмена: закройте режим захвата клавишей Esc или удалите скачанный файл. Для прокрутки внутри других программ существует «Capture → Scrolling capture» в ShareX: она прокручивает выбранную область и склеивает кадры. Это дополнительный инструмент, а не обязательный шаг. Закреплённая шапка, анимация и наведение курсора могут вызвать ошибку склейки; проверьте итоговый файл. Перед использованием проверьте задачи после захвата, если не хотите отправлять изображение в онлайн-сервисы.

Снимок только одного монитора

Если к компьютеру подключено несколько дисплеев, Win + PrtSc может сохранить их общую виртуальную область. Для одного монитора нажмите Win + Shift + S и обведите его видимую область. Затем откройте снимок и проверьте края: при разном масштабе экранов легко захватить часть соседнего дисплея. Отмените выделение клавишей Esc или удалите неудачный файл.
