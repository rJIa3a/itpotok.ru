# Подобрать визуал по задаче

Применять на соответствующем этапе координатора article-workflow, в том числе при возврате после ошибки. Прочитать общую [политику](../../../editorial/policy.md) и [контракты](../../../editorial/contracts.md).

## Вход
План, проверенные данные, текст.
## Действия
Для интерфейса направить screenshot-capture; для процесса — Mermaid/SVG; для чисел — код из проверенной таблицы с единицами и источником; для обложки — генератор. Сохранить данные и код; сверить шкалы; назначить подпись, alt и место. Обложка 16:9, важное в безопасной зоне.
## Инструменты
Mermaid, SVG, Python, imagegen по его навыку. Проверить наличие и разрешения в текущей сессии; перечисление инструмента не создаёт интеграцию.
## Результат
visuals.json, illustrations.md, images/, data/, scripts/. Сохранить в папке статьи; контрольную точку — в workflow.json через команду checkpoint. Не заменять предыдущие свидетельства: новые прогоны получают отдельный ID.
## Качество
Изображение помогает конкретному фрагменту; график вычислен из данных.
## Остановка
Нет подтверждённых данных — не рисовать количественный график.
## Примеры
Хорошо: Диаграмма показывает развилку, которой нет в соседней таблице.

Плохо: Декоративная диаграмма с выдуманными процентами.
