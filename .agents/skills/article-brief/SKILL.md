# Определить задачу и формат

Применять на соответствующем этапе координатора article-workflow, в том числе при возврате после ошибки. Прочитать общую [политику](../../../editorial/policy.md) и [контракты](../../../editorial/contracts.md).

## Вход
Ключ, конкурент, контекст записи.
## Действия
Проверить дубли сайта; определить аудиторию, результат, границы, тип explanation/comparison/manual; записать критерии и исходные неизвестные. Для сравнения задать общую задачу и одинаковые критерии, не придумывать победителя.
## Инструменты
Поиск сайта, WordPress REST только чтение, web. Проверить наличие и разрешения в текущей сессии; перечисление инструмента не создаёт интеграцию.
## Результат
brief.md, workflow.json. Сохранить в папке статьи; контрольную точку — в workflow.json через команду checkpoint. Не заменять предыдущие свидетельства: новые прогоны получают отдельный ID.
## Качество
Задача наблюдаема; выбор записи однозначен.
## Остановка
Несколько подходящих опубликованных записей: уточнить выбор, исследование продолжать.
## Примеры
Хорошо: Читатель выбирает между двумя способами для своей редакции Windows.

Плохо: Статья обо всём, цель — 3000 слов.
