# Редакторская проверка
Два прохода: структура и язык. Отрывок описывает охват, начало отвечает на запрос, таблица сравнивает задачи. Сняты обещания навсегда, полной блокировки через лимитную сеть и универсального реестра Home. Возврат описан рядом со способом. Внешние ссылки nofollow.

Нерешённые существенные пункты: нет практического initial/rerun по текущему тексту; нет обязательных настоящих русских кадров; точные названия локализованной подпапки gpedit требуют кадра актуальной сборки. Справочные наименования могут отличаться от локализации, поэтому рядом есть английское имя.
Проверка тела REST, FAQ и шаблона записывается отдельно после доставки. Черновик не ready.
