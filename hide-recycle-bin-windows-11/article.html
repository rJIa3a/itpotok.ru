Чтобы убрать корзину с рабочего стола в Windows 11, откройте «Параметры» → «Персонализация» → «Темы» → «Параметры значков рабочего стола», снимите флажок «Корзина» и нажмите «ОК». Исчезнет только значок: содержимое корзины останется на месте, а настройка удаления файлов не изменится. Вернуть значок можно тем же флажком.

Как скрыть только значок корзины

  1. Нажмите Win + I, чтобы открыть «Параметры».
  2. Перейдите в «Персонализация» → «Темы».
  3. Найдите и откройте «Параметры значков рабочего стола». При необходимости прокрутите страницу вниз.
  4. В открывшемся окне снимите флажок «Корзина». Остальные флажки оставьте как есть, если хотите убрать только её.
  5. Нажмите «ОК» и проверьте рабочий стол: корзина должна исчезнуть, остальные значки — остаться.

Этот способ описан в справке Microsoft о значках рабочего стола. Для него не нужны сторонние программы или правка реестра.

Как открыть корзину после скрытия

Открыть её можно без возврата значка. В Проводнике нажмите Ctrl + L, введите в адресную строку shell:RecycleBinFolder и нажмите Enter. Должно открыться окно «Корзина».

Введите именно адрес в строку расположения, а не в поле поиска справа. Для этого не нужно включать отображение скрытых системных файлов или искать папку $Recycle.Bin на диске.

В открывшейся корзине можно просмотреть файлы. Если нужно вернуть конкретный файл, нажмите на него правой кнопкой мыши и выберите «Восстановить». Он вернётся в исходную папку, если доступен для восстановления из корзины.

Как вернуть корзину на рабочий стол

Снова откройте «Параметры» → «Персонализация» → «Темы» → «Параметры значков рабочего стола», установите флажок «Корзина» и нажмите «ОК». Проверьте, появился ли значок.

Если флажок установлен, но на рабочем столе нет вообще никаких значков, нажмите правой кнопкой мыши на его пустой области и выберите «Вид» → «Отображать значки рабочего стола». Этот переключатель управляет сразу всеми значками. Microsoft отдельно рассматривает эти два случая в инструкции по возврату корзины.

Если нужно временно скрыть все значки

Для чистого рабочего стола, например перед показом экрана, нажмите правой кнопкой мыши на пустом месте, откройте «Вид» и снимите флажок «Отображать значки рабочего стола». Вместе с корзиной исчезнут ярлыки, файлы и папки, отображаемые на рабочем столе. Сами объекты останутся на своих местах.

Чтобы вернуть их, включите этот же пункт. Если до этого корзина была отдельно скрыта через параметры значков, для её возврата потребуется также установить флажок «Корзина».

Скрытие значка, очистка и отключение корзины — разные действия

Что нужно сделатьЧто изменится
Скрыть значокКорзина исчезнет с рабочего стола; её содержимое и правила удаления сохранятся.
Очистить корзинуБудут удалены находящиеся в ней файлы; значок останется.
Не помещать новые удаляемые файлы в корзинуИзменится поведение удаления для выбранного диска; это не способ скрыть значок.

Для скрытия значка очищать корзину или отключать её не требуется. Если ваша задача решена, следующие действия выполнять не нужно.

Если вы хотите именно очистить корзину, сначала откройте её и восстановите нужные файлы. Затем выберите «Очистить корзину» и подтвердите действие. После очистки вернуть файлы обычной командой «Восстановить» из корзины уже не получится. Другие способы освобождения места разобраны в статье об очистке диска C в Windows 11.

Чтобы открыть свойства корзины, нажмите на её значок правой кнопкой мыши и выберите «Свойства». Отдельная настройка позволяет для выбранного диска включить «Уничтожать файлы сразу после удаления, не помещая их в корзину». Она нужна только тем, кто сознательно хочет изменить удаление файлов: новые удалённые объекты не получится вернуть из корзины. Перед изменением запомните прежний размер корзины. Для возврата включите «Задать размер», восстановите прежнее значение и примените настройку. Это вернёт использование корзины для последующих удалений, но не восстановит уже удалённые без неё файлы.

Если настройка недоступна или значок возвращается

  • Пропали все значки. Проверьте пункт «Вид» → «Отображать значки рабочего стола».
  • Не возвращается только корзина. Проверьте флажок «Корзина» в параметрах значков и подтвердите изменение кнопкой «ОК».
  • Изменение запрещено на рабочем компьютере. Обратитесь к администратору: политика Windows может скрывать корзину и в Проводнике. Это отличается от обычного снятия флажка.
  • Значок снова появляется после входа в систему. Проверьте, не восстанавливает ли его программа настройки рабочего стола или политика организации. Не удаляйте системную папку корзины ради скрытия значка.
